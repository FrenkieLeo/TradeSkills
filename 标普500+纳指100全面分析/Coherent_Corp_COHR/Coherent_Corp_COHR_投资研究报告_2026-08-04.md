# Coherent（COHR）投资研究报告

**研究日期：** 2026-08-04  
**数据截止：** 2026-08-04；最新可核验经营季度为 Q3 FY2026（截至 2026-03-31），Q4/FY26业绩安排在 2026-08-12 盘后。  
**AI偏差评级：** 极高——光子器件、激光和光互连直接受益于AI数据中心，但利润、资本开支、并购稀释和估值均处在高波动状态。  
**结论先行：** Coherent在光通信、激光、材料和数据中心光互连拥有重要技术资产，Q3收入同比增长21%、非GAAP EPS增长55%；但股价约$288.14，PE约120倍、Forward PE约38.5倍、EV/EBITDA约55倍，建议观察/等待，$180–240再评估。

## 第一步：核心数据总览

| 项目 | 数据/判断 |
|---|---|
| 核心业务 | 光纤通信、光收发器、激光、材料、工业与数据中心光子器件 |
| 股价/市值/企业价值 | $288.14 / $56.37B / $57.37B |
| TTM收入/净利润 | $6.60B / $400.61M；TTM EPS约$2.40 |
| 估值 | PE 120.28x；Forward PE 38.50x；P/S 8.54x；EV/EBITDA 55.06x |
| 资产负债 | 流动比率3.05；Debt/Equity 0.31；Debt/EBITDA 3.29x |
| ROIC/WACC | 6.05% / 14.87%，当前投入回报尚未覆盖资本成本 |
| 最新季度 | Q3收入$1.81B、同比+21%；GAAP EPS$0.97；非GAAP EPS$1.41 |

**事实：** Q3 GAAP毛利率37.7%、非GAAP毛利率39.6%，公司表示数据中心与通信需求强劲，正在扩大产能。股票数同比增加约17%，反映并购/融资后的稀释，不能只看调整后EPS增速。

**判断：** Coherent把激光、光学材料、封装和器件应用到通信、制造、医疗和国防。AI数据中心需要更高带宽和更长距离互连，光学成为功耗和吞吐瓶颈的解决方案，但客户、供应链和产能扩张会决定利润能否跟上收入。

## 第二步：生意本质分析

光通信产品需要在可靠性、带宽、功耗和成本之间平衡，客户验证和制造能力比单一零件设计更重要。Coherent拥有垂直材料与器件能力，可覆盖从激光源到收发器的多个环节，但业务组合复杂、周期差异大。

AI需求可能推动高速收发器和光互连快速增长，工业、显示和传统通信则提供周期性补充。Q3增长强劲，但高资本开支、库存、客户集中和稀释会决定“增长”是否转化为每股自由现金流。

## 第三步：护城河评估

| 护城河 | 强度 | 说明 |
|---|---|---|
| 光子技术与材料 | 强 | 激光、晶体、光学和制造工艺积累深 |
| 客户认证 | 强 | 通信和数据中心可靠性要求高，验证周期长 |
| 制造规模 | 中强 | 大规模产能有助满足需求，但需要重资本投入 |
| 产品组合 | 中强 | 通信、工业、医疗和国防分散周期 |
| 客户与供应链 | 中 | 高端客户黏性强，但大客户议价和供应约束明显 |

**护城河耐久性：** 7.5/10。技术和认证构成壁垒，但光模块代际切换快，客户集中与替代方案会持续挑战利润率。

## 第四步：逆向思考与风险清单

反方情景是：AI光互连需求被市场过度资本化，客户降价或自研；产能扩张先于订单，负债和稀释扩大，经营现金流无法覆盖资本开支。

- TTM PE约120倍，当前利润不足以支撑价格，必须依赖未来盈利兑现。
- ROIC约6.1%低于WACC约14.9%，说明并购/资本投入尚未创造足够回报。
- 股票数一年增加约17%，每股价值需要收入和利润更快增长。
- Q4业绩在8月12日盘后，研究日不能提前用市场预期替代。
- 供应链、产能良率、客户集中、光模块竞争和数据中心周期均有高波动。

**关键观察指标：** Q4收入/毛利、800G/1.6T产品需求、产能利用率、库存与应收、FCF、资本开支、股票数、客户集中、非GAAP与GAAP差异以及ROIC改善。

## 第五步：管理层评估

Jim Anderson和Sherri Luther在需求强劲时扩大产能、推动利润率改善，管理层评价为**产品方向正确、资本回报待验证**。

管理层的核心考题是将光互连需求转化为稳定高回报，而不是用大规模扩产和并购换取收入增长。若能降低成本、提高产能良率和实现稀释后的每股现金流，估值才有基础。

## 第六步：行业与文明趋势

AI数据中心的带宽和功耗约束推动电信号向光信号迁移，光子技术决定算力集群的连接效率。Coherent在材料和器件上的积累有助支持更高带宽、更低功耗的数字基础设施。

与此同时，AI建设也可能集中在少数云客户，光模块升级周期快、制造能耗和资本投入高。技术进步扩大TAM，也会加快旧产品淘汰，企业必须持续研发与控制库存。

## 第七步：估值与安全边际

以FY26未来盈利的Forward PE约38.5倍为起点，光子高增长公司在25–35倍的更谨慎区间对应约$188–263；以销售倍数8.54倍和当前低回报率折价，合理区间约$170–250。当前价格更接近乐观情景。

| 情景 | 核心假设 | 合理价格区间 | 行动含义 |
|---|---|---:|---|
| 悲观 | AI需求延迟、产能过剩、稀释与杠杆加剧 | $110–175 | 回避/减仓 |
| 基准 | 数据中心需求强、利润逐步改善 | $180–260 | 观察/等待 |
| 乐观 | 高速光互连持续超预期、ROIC跃升 | $280–390 | 需连续业绩确认 |

安全边际来自技术、认证和AI光互连需求；不足来自估值、资本回报、稀释与极高波动。$180–240更适合重新评估。

## 第八步：最终决策与行动清单

**建议：观察/等待。** Coherent可能是光子基础设施赢家，但当前价格要求利润和资本回报同步跃升。

- 新建仓：$180–240分三次；Q4前不因盘中波动追价。
- 已持有：控制仓位，关注稀释后的每股价值而非单一收入增速。
- 加仓条件：Q4收入/毛利兑现、FCF转正、ROIC超过WACC、产能利用率改善。
- 减仓条件：客户推迟、库存上升、毛利下滑、继续大额稀释或资本开支失控。
