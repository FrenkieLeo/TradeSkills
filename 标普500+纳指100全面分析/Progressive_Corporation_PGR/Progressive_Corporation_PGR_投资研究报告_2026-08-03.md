# Progressive Corporation（PGR）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。Progressive已公布 2026 Q2及6月经营结果，披露保费、净利润、综合成本率、保单数和分销渠道；独立统计补充收盘价、股本与估值。AI研究置信度高，投资确定性中高。

Q2净保费收入 $21.573B，同比增长 6%；净利润 $3.311B，摊薄每股收益 $5.67；综合成本率 87.3%，保单数同比增长 7%。结论：**HOLD（可小仓吸纳）；公司承保和数据能力优异，现价约10.6x TTM PE并不昂贵，但保险利润会随定价、事故频率和准备金周期波动。**

## 1. 最新业绩事实与关键问题

Progressive以个人车险、商业车险、房屋及特殊险为主，通过代理渠道和直接渠道获客，依靠精细定价、理赔管理和品牌规模获得承保利润。Q2净保费写入 $21.077B，同比增长 5%；净保费赚取 $21.573B，同比增长 6%；净利润 $3.311B，同比增长 4%；综合成本率 87.3%，较上年同期恶化 1.1个百分点。

6月单月净保费写入 $6.772B、净保费赚取 $7.100B、净利润 $779M、综合成本率 90.0%。6月末个人险保单数 38.860M，总保单数 40.086M，同比增 7%，其中直接车险和代理车险均增长。规模增长与承保纪律需要同时观察，不能把保单增长直接等同于价值创造。

**段永平追问：**客户选择 Progressive是因为报价、理赔和品牌形成真实信任，还是因为短期价格低于同业？

## 2. 财务趋势与商业本质

商业本质是以规模化保费、精细定价、投资浮存金和高效率理赔获得承保与投资利润。护城河来自海量定价与理赔数据、Snapshot等行为数据、品牌、代理网络和直接渠道规模；保险公司最重要的产品不是保单数量，而是风险筛选后产生的长期每单利润。

| 口径 | Q2 2026数值 |
|---|---:|
| 净保费写入 / 同比 | $21.077B / +5% |
| 净保费赚取 / 同比 | $21.573B / +6% |
| 净利润 / 摊薄EPS | $3.311B / $5.67 |
| 综合成本率 | 87.3% |
| 总保单数 / 同比 | 40.086M / +7% |

独立统计显示 TTM收入 $91.02B、净利润 $11.70B、EPS $19.93、ROE 34.94%、自由现金流 $16.42B，TTM PE约10.61x。保险公司的现金流受保费收取、理赔支付和投资组合影响，不能机械按普通工业企业 FCF估值；应同时看综合成本率、准备金发展和每股账面价值。

**巴菲特追问：**Progressive能否在整个保险周期保持低综合成本率，并把浮存金以审慎方式投资，而不是在竞争激烈时追求保费增长？

## 3. 护城河、管理层与逆向风险

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 事故频率/维修成本上升，综合成本率恶化 | 中高 | 高 |
| 降价竞争导致增长换利润 | 中 | 高 |
| 飓风、洪水等巨灾和准备金不足 | 中 | 高 |
| 监管限制费率与承保选择 | 中 | 中高 |
| 直接/代理渠道或数据模型失效 | 低至中 | 高 |

管理层持续公开月度经营数据，便于投资者观察增长与承保的先后变化；保单数增长和组合规模强，但 2026 Q2综合成本率较上年略差，提示增量业务不能只看数量。跟踪每辆车保费、事故频率/严重度、综合成本率、续保率、渠道利润、准备金发展和投资收益。

**芒格追问：**我是否把高 ROE当成永久优势，忽略保险资本和准备金估计在坏年份会迅速反转？

## 4. 行业与长期趋势

车辆维修成本、医疗成本、驾驶里程、天气和监管决定保险价格周期；ADAS、电动车、自动驾驶和远程定价会改变事故频率与赔付结构。AI和遥测扩大精细定价优势，也引发隐私、歧视和监管问题。Progressive的长期机会是用数据把复杂风险定价得更准确，而不是单纯通过涨价维持利润。

**李录追问：**车辆、家庭和商业风险长期数字化后，Progressive能否成为低成本、低损失率的风险数据平台？

## 5. 股价与估值

2026-07-31 收盘价 $211.42；股本 581.40M。Decimal计算：$211.42 × 581.40M = **$122.9196B**，与独立统计市值 $122.92B基本一致。独立统计 TTM PE约10.61x、Forward PE约13.10x、P/FCF约7.49x。

| 情景 | 正常化EPS | P/E | 目标价格 | 相对现价 |
|---|---:|---:|---:|---:|
| 悲观 | $18.00 | 10x | $180.00 | -14.9% |
| 中性 | $20.50 | 12x | $246.00 | +16.4% |
| 乐观 | $23.00 | 13x | $299.00 | +41.4% |

中性情景要求保单继续中个位数增长、综合成本率回到约 86%–88%区间，且没有重大巨灾或准备金不利发展。现价对优质保险公司并不贵，但市场已经期待承保恢复；$195以下更适合分批，若综合成本率连续恶化则不能只因 PE低而买入。

## 6. 四位大师视角与最终决策

巴菲特会看长期承保利润和浮存金；芒格会看事故、准备金、监管和周期；段永平会看客户留存和理赔体验；李录会看风险数据、数字化定价和长期保险需求。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 顶级财险平台，承保能力强 | 高 |
| 护城河 | 数据、定价、品牌、分销规模 | 高 |
| 管理层 | 月度披露和承保纪律较好 | 中高 |
| 最大风险 | 频率/严重度、巨灾、监管 | 高 |
| 估值 | 低倍数但依赖正常化承保利润 | 高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 可小仓观察；$195以下提高买入力度 |
| 持仓者 | 持有，跟踪综合成本率和保单质量 |
| 卖出信号 | 综合成本率持续高于 90%或准备金明显不利 |
| 加仓信号 | 保单增长稳定、综合成本率回到 86%–88%且价格低于 $195 |

综合决策：**HOLD（可小仓吸纳）**。AI分析置信度高；投资确定性中高，业务和数据护城河强，但保险盈利具有周期性和尾部风险。
