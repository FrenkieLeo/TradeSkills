# PayPal（PYPL）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。PayPal已公布 2026 Q2，披露 TPV、活跃账户、交易频次、交易利润、现金流、回购和全年指引；独立统计补充收盘价、股本与估值。AI研究置信度高，投资确定性中等。

Q2收入 $8.682B，同比增长 5%；TPV $486.4B，同比增长 10%；交易利润仅增长 1%，不含客户余额利息增长 3%；GAAP营业利润下降 5%，non-GAAP EPS $1.38。结论：**HOLD；估值便宜、回购和现金流强，但品牌结账增长与利润率尚未重新加速，等待转型兑现。**

## 1. 最新业绩事实与关键问题

PayPal连接消费者、商户、平台和金融服务，业务包括品牌结账、Braintree无品牌处理、Venmo、数字钱包、BNPL及支付服务。Q2 TPV为 $486.448B，支付交易 68亿笔，活跃账户 4.39亿，过去12个月每账户交易数升至 60.0；活跃账户基本停滞但交易频次增长。

GAAP营业利润 $1.427B、营业利润率 16.4%，non-GAAP营业利润率 17.4%，均同比收缩。经营现金流 $1.983B、自由现金流 $1.775B，公司回购约 3,300万股、返还股东约 $1.5B。管理层将 FY2026 non-GAAP EPS 指引提高至约 $5.38，但同时承认转型费用和下半年利润率压力。

**段永平追问：**消费者和商户选择 PayPal是因为真正的信任与便利，还是因为历史按钮、促销和暂时的网络惯性？

## 2. 财务趋势与商业本质

商业本质是以交易规模、商户服务、信用与金融服务及客户余额收益变现；护城河来自品牌信任、商户接入、风险数据、Venmo社交网络和全球合规体系。Braintree扩大了处理规模，却可能带来较低费率；PayPal要证明高质量的品牌结账和增值服务能够提升每笔交易价值。

| 口径 | Q2 2026数值 |
|---|---:|
| 净收入 / 同比 | $8.682B / +5% |
| TPV / 同比 | $486.448B / +10% |
| 交易利润 / 同比 | $3.900B / +1% |
| 交易利润（剔除客户余额利息）/同比 | $3.619B / +3% |
| GAAP EPS / non-GAAP EPS | $1.25 / $1.38 |
| 经营现金流 / 自由现金流 | $1.983B / $1.775B |

独立统计显示 TTM收入 $34.13B、净利润 $4.90B、EPS $5.30、自由现金流 $6.59B，TTM PE约10.78x、P/FCF约7.43x。低估值来自市场对增长、利润率和竞争的怀疑；不能只用高回购收益率证明核心业务已经反转。

**巴菲特追问：**未来十年 PayPal的每笔交易利润是否会随数字支付增长，还是被商户议价与钱包竞争持续稀释？

## 3. 护城河、管理层与逆向风险

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 品牌结账持续丢失份额或活跃账户下降 | 中高 | 高 |
| Braintree规模增长但低费率拖累TM$ | 高 | 中高 |
| 竞争加剧、商户自建钱包或账户支付替代 | 中 | 高 |
| 信用、BNPL、欺诈与监管损失 | 中 | 高 |
| 回购过快而转型投资不足 | 中 | 中高 |

新管理层强调品牌结账、Venmo、Braintree和金融服务三条业务线，并提高全年 non-GAAP EPS 指引；但 Q2 营业利润下降说明“增长”和“效率”仍在取舍。跟踪品牌结账TPV、ex-PSP交易频次、TM$ ex-interest、活跃账户、损失率、营销回报与每股现金流，而非只看总TPV。

**芒格追问：**我是否把低倍数误认为低风险，而忽略支付平台转换成本正在下降？

## 4. 行业与长期趋势

电商、移动钱包、跨境支付、即时支付、AI代理购物和稳定币扩大支付场景，但也把价值从钱包界面推向商户、银行和底层网络。PayPal的机会是把风险管理、身份、融资和支付编排做成基础设施；风险是品牌资产被手机系统、商户平台或实时账户支付截取。

**李录追问：**数字支付长期渗透是否会转化成 PayPal 的高质量利润，而不是只转化成更大但更低费率的处理量？

## 5. 股价与估值

2026-07-31 收盘价 $57.13；股本 855.46M。Decimal计算：$57.13 × 855.46M = **$48.8724B**，与独立统计市值 $48.94B相差约 0.14%。独立统计 TTM PE约10.78x、Forward PE约10.31x、P/FCF约7.43x。

| 情景 | 正常化EPS | P/E | 目标价格 | 相对现价 |
|---|---:|---:|---:|---:|
| 悲观 | $5.00 | 10x | $50.00 | -12.5% |
| 中性 | $5.80 | 11x | $63.80 | +11.7% |
| 乐观 | $6.50 | 13x | $84.50 | +47.9% |

中性情景要求 TM$ ex-interest 恢复中个位数增长、品牌结账稳定、回购降低股本，同时营业利润率不再恶化。现价已经反映部分悲观，但买入逻辑依赖转型而非单纯低 PE；$50以下才更适合明显加仓。

## 6. 四位大师视角与最终决策

巴菲特会看品牌、网络效应和自由现金流；芒格会看费率、竞争和信用损失；段永平会追问产品是否让消费者与商户形成真实习惯；李录会看全球数字商业长期扩张与支付接口重构。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 规模和现金流强，增长质量待修复 | 中高 |
| 护城河 | 品牌、商户、风险数据与合规 | 中高 |
| 管理层 | 转型方向清晰，执行仍在早期 | 中 |
| 最大风险 | 品牌结账与交易利润持续下滑 | 高 |
| 估值 | 便宜但有价值陷阱可能 | 高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 观察；$50以下分批，先看TM$与品牌结账 |
| 持仓者 | 持有但控制仓位，等待连续两个季度改善 |
| 卖出信号 | TM$ ex-interest负增长、活跃账户下降或利润率继续收缩 |
| 加仓信号 | 品牌结账增长恢复、TM$加速且价格低于 $50 |

综合决策：**HOLD**。AI分析置信度高；投资确定性中等，现金流和回购可靠，业务转型的长期竞争位置仍需验证。
