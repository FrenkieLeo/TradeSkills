# Analog Devices（ADI）投资研究报告

**研究日期：** 2026-08-04  
**数据截止：** 2026-08-04；最新已披露经营季度为 FY2026 Q2，Q3业绩预计 2026-08-19 披露。  
**AI偏差评级：** 高——ADI的模拟芯片护城河和AI电源机会强，但库存周期、并购整合和当前高估值仍是主要约束。  
**结论先行：** ADI在高性能模拟、混合信号、电源管理和工业芯片拥有深厚客户关系，Q2收入增长37%、调整后EPS增长67%、调整后经营利润率49%，并给出强劲Q3指引；但股价约$361.88，对应PE约53.9倍、远期PE约25.8倍、EV/EBITDA约29.7倍，且ROIC约9.1%低于WACC约10.4%。建议持有/等待，$300–335再评估。

## 第一步：核心数据总览

| 项目 | 数据/判断 |
|---|---|
| 核心业务 | 高性能模拟、混合信号、射频、接口、电源和嵌入式处理芯片 |
| 股价/市值/企业价值 | $361.88 / $176.27B / $181.54B |
| TTM收入/净利润 | $12.74B / $3.31B |
| 估值 | PE 53.88x；Forward PE 25.81x；P/FCF 38.61x；EV/EBITDA 29.74x |
| 现金/债务 | $3.44B / $8.71B；净债务约$5.27B |
| ROIC/WACC | 9.13% / 10.43% |
| Q2 FY26经营表现 | 收入$3.623B，+37%；GAAP EPS$2.40；调整后EPS$3.09 |

**事实：** Q2 GAAP经营利润率38.1%、调整后经营利润率49.0%，工业收入约$1.80B且仍为最大终端，通信增长突出。TTM经营现金流$5.1B、FCF$4.6B；Q3收入指引约$3.9B±$100M，GAAP EPS约$2.60、调整后EPS约$3.30。

**判断：** ADI卖的是长期可靠、低噪声、精确测量和电源管理能力。模拟芯片连接真实世界的温度、压力、声音、速度和电力，客户验证周期长、替换成本高，因而生命周期和毛利率通常优于短周期数字芯片。

## 第二步：生意本质分析

工业、汽车、通信和消费终端构成多元组合，产品可嵌入设备多年。ADI通过研发、应用工程、长期客户设计和并购扩展产品线。周期下行时库存调整会压低收入，但恢复时高经营杠杆可快速释放利润。

Q2所有终端增长、订单创新高，说明周期恢复广泛；但Q2同比基数、库存补库、AI电源需求和Maxim整合仍需区分。Empower Semiconductor收购增加AI时代高密度电源能力，但现金支出和整合回报需验证。

## 第三步：护城河评估

| 护城河 | 强度 | 说明 |
|---|---|---|
| 模拟技术与IP | 很强 | 精度、低噪声、可靠性和工艺经验长期积累 |
| 客户共同设计 | 很强 | 芯片嵌入系统，认证和重新设计成本高 |
| 产品组合 | 强 | 工业、汽车、通信和电源管理交叉销售 |
| 应用工程与分销 | 强 | 帮助客户解决系统级问题，而非只卖芯片 |
| 并购与制造 | 中强 | Maxim和电源并购扩展能力，但整合复杂 |

**护城河耐久性：** 8.5/10。模拟芯片替换慢、生命周期长；风险在于客户降本、内部设计、制造周期和高估值导致资本回报压力。

## 第四步：逆向思考与风险清单

反方情景是：库存补库结束后工业和通信回落，Q3高指引成为周期顶部；AI电源机会被市场过度定价；并购和资本开支使ROIC长期低于资本成本。

- ROIC低于WACC，当前增长尚未证明创造经济利润。
- PE约54倍、EV/EBITDA约30倍，估值要求长期高质量增长。
- 净债务约$5.3B，Maxim和Empower并购增加整合与利息压力。
- 模拟芯片周期可能滞后于终端需求，订单与收入存在时间差。
- 高分红和回购虽友好，但不能替代有机利润增长。

**关键观察指标：** 工业/汽车/通信收入、订单、库存天数、毛利率、调整后与GAAP差异、Maxim/Empower协同、资本开支、FCF、净杠杆、ROIC/WACC和Q3指引兑现。

## 第五步：管理层评估

管理层在Q2实现广泛增长、利润率扩张并给出强Q3展望，经营执行力评价为**中上**。其核心考题是把周期复苏、AI电源和并购能力转化为长期高ROIC，而不是在高景气顶部扩大资本投入。

Vincent Roche团队长期重视创新和客户问题，但投资者需要观察Empower的整合、Maxim的协同和资本纪律。若回报率重新超过WACC，估值可以消化；若只增长收入而回报下降，当前价格缺乏缓冲。

## 第六步：行业与文明趋势

工业自动化、电气化、汽车电子、通信升级、能源效率和AI数据中心提高模拟、电源和传感器的重要性。数字世界越复杂，对现实世界信号转换、测量和能源管理的需求越大。

ADI的文明趋势机会是让机器更精确、更节能、更安全；风险是AI资本开支周期和半导体库存波动把长期趋势变成短期高估值主题。

## 第七步：估值与安全边际

以Q3调整后EPS约$3.30作单季参考，不作机械年化；以TTM EPS$6.72、合理PE 32–42倍估算，合理价格约$215–282；以TTM FCF每股约$9.37、合理P/FCF 28–35倍估算，合理价格约$262–328。综合考虑周期恢复，合理区间约$270–335。

| 情景 | 核心假设 | 合理价格区间 | 行动含义 |
|---|---|---:|---|
| 悲观 | 补库结束、工业回落、并购回报不足 | $190–255 | 回避/减仓 |
| 基准 | 周期恢复、利润率稳定、AI电源逐步兑现 | $300–360 | 持有/等待 |
| 乐观 | 工业与通信持续超预期、ROIC回升 | $375–460 | 需现金流验证 |

安全边际来自模拟芯片护城河和FCF；不足来自高估值、ROIC/WACC倒挂和周期。$300–335更适合作为长期仓位的风险调整区间。

## 第八步：最终决策与行动清单

**建议：持有/等待回调。** ADI是高质量模拟芯片公司，但研究日价格已反映强劲复苏和AI电源预期。

- 新建仓：$300–335分三次；高于$360不追涨。
- 已持有：持有但跟踪ROIC、库存和FCF。
- 加仓条件：订单和收入同步、ROIC重新超过WACC、并购协同兑现。
- 减仓条件：库存上升、Q3指引下调、毛利率下降或并购导致资本回报恶化。
