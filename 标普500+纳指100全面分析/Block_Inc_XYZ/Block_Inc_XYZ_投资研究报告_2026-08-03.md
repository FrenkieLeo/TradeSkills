# Block（XYZ）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：B+。Block 的 Q2 2026 业绩将在 8 月 5 日美股收盘后披露，因此本报告以 Q1 2026、公司 Q2 指引、TTM 财务与独立估值统计为事实底座；Q2 实际结果为待披露，不用市场预期替代。

Block 把 Square 商户生态、Cash App 消费者金融和 Afterpay 等业务放在一个平台中，TTM 收入 $24.48B、毛利 $11.03B、净利润 $807M、自由现金流 $3.26B。公司 Q1 材料给出 Q2 毛利约 $3.04B、同比增约 20%，调整后经营利润约 $740M 的指引。结论：**WATCHLIST / 生意有平台价值，但当前 ROIC 低、波动大、Q2 待验证；$60–70 更有安全边际。**

## 1. 最新业绩事实与关键问题

截至截止日，Block 已公布 Q1 2026，下一次完整业绩预定 8 月 5 日盘后。Q1 的核心观察量不是比特币相关总收入，而是毛利、Cash App 贡献、Square 生态留存和调整后经营利润。Q2 指引为毛利约 $3.04B、同比约增 20%，调整后经营利润约 $740M；这些是公司指引而非已实现结果。

Block 的报表收入包含比特币买卖等低毛利、近似转手项目，直接用收入增长或 P/S 容易高估经济价值。应优先看毛利、调整后经营利润、自由现金流、每股价值和坏账/信贷损失。公司同时有 $7.32B 现金和 $8.13B 债务，净债务约 $0.81B；流动性尚可，但资产负债表并非纯软件公司。

**段永平追问：**Cash App 与 Square 是否形成真正的低成本网络，还是依赖补贴、信贷扩张和高波动交易收入？

## 2. 财务趋势与商业本质

| 口径 | 最新数值 |
|---|---:|
| TTM 收入 / 毛利 | 24.48 / 11.03 |
| TTM 经营利润 / 净利润 | 1.25 / 0.81 |
| TTM 经营现金流 / 自由现金流 | 3.41 / 3.26 |
| TTM EPS / FCF每股 | $1.32 / $5.42 |
| 现金 / 总债务 | 7.32 / 8.13 |

商业本质是连接小商户收款、软件、借贷与消费者支付的双边金融科技平台。Square 通过商户硬件、软件订阅、支付和贷款提高单户价值；Cash App 通过支付、卡、存款、借贷和投资提高用户变现。平台价值来自数据、分发和交叉销售，而不是单一支付费率。

| 护城河 | 判断 | 趋势 |
|---|---|---|
| 商户软件与支付集成 | 中高，迁移成本来自工作流和数据 | 中高 |
| Cash App 分发 | 用户规模和产品入口强 | 中高 |
| 数据与风险定价 | 能改善贷款与交叉销售，但受周期检验 | 中 |
| 品牌与产品速度 | 创新快，执行波动也较大 | 中 |
| 资本与合规能力 | 可支持金融产品，但资本成本上升 | 中 |

**巴菲特追问：**在不依赖持续融资和一次性会计收益的情况下，Block 能否把毛利增长稳定转换为每股自由现金流？

## 3. 护城河、管理层与逆向风险

管理层擅长产品整合、成本控制与资本回购；过去一年股本减少约 3.54%，说明回购具有一定支持。但公司业务横跨支付、消费金融、比特币和借贷，风险控制复杂，且 TTM ROE 3.74%、ROIC 4.07%，尚未达到高质量复利公司的证据标准。

| 失败路径 | 概率 | 影响 |
|---|---|---|
| Cash App/商户毛利增速放缓 | 中 | 高 |
| 消费信贷损失上升 | 中 | 高 |
| 比特币收入噪音掩盖核心经济性 | 中高 | 中 |
| 合规、反洗钱或监管成本上升 | 中 | 高 |
| 高波动与估值收缩 | 高 | 中高 |

空方会指出 TTM PE 约 61.7x、WACC 约 16.1%、Altman Z-score 2.5；多头则会强调 FCF $3.26B、回购和调整后利润增长。真正的反方验证是：若 Q2 毛利达到指引但 Cash App 信贷损失同步上升，增长是否只是把风险推迟到资产负债表。

**芒格追问：**Block 的复杂业务组合是否产生协同，还是让投资者难以判断每条业务的真实资本回报？

## 4. 行业与长期趋势

数字支付、商户软件、即时支付和嵌入式金融仍有长期渗透空间；但支付费率透明、监管趋严、银行与大型平台竞争强。Square 的机会在中小商户数字化和软件交叉销售，Cash App 的机会在从 P2P 入口扩展为主账户；风险是 Apple、PayPal、银行、Shopify、Toast 等在各环节加码。

长期跟踪应围绕：毛利增速是否超过费用增速、Cash App 活跃用户和每用户毛利、Square GPV 与订阅收入、贷款损失率、自由现金流和回购后股本。比特币交易量只能作为辅助指标，不能作为长期护城河替代品。

**李录追问：**这是一家能穿越金融周期的支付基础设施，还是一家在低利率和高风险偏好环境中更容易增长的金融科技组合？

## 5. 股价与估值

2026-07-31 收盘价 $81.08；独立统计股本 600.76M。精确计算：$81.08 × 600.76M = **$48.71B**，与独立统计市值 $48.81B 接近。TTM PE 61.71x、forward PE 19.37x、P/FCF 14.98x；forward PE 隐含的盈利预期明显高于 TTM，说明市场已提前计入利润释放。

由于比特币和支付总收入会扭曲收入倍数，本报告用估算调整后 EPS×PE；EPS 是研究情景，不是公司已发布业绩：

| 情景 | 估算EPS / PE | 每股价值 | 相对现价 |
|---|---:|---:|---:|
| 悲观 | $3.50 / 18x | $63.00 | -22.3% |
| 中性 | $4.20 / 21x | $88.20 | +8.8% |
| 乐观 | $5.00 / 24x | $120.00 | +48.0% |

中性价值只有约 9% 上行，尚不足以补偿高 beta、低 ROIC、信贷与监管风险。若 Q2 毛利和调整后经营利润同时达到指引、坏账不恶化，才可提高中性 EPS；若结果低于指引，估值应回到自由现金流而非 forward PE。

## 6. 四位大师视角与最终决策

巴菲特会要求核心支付和软件现金流可预测；芒格会拆分比特币转手收入、信贷损失和调整项；段永平会看回购是否提升每股价值以及管理层是否诚实披露；李录会把金融科技渗透与监管/信用周期放在一起评估。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 双平台有真实分发价值，但业务复杂 | 中 |
| 护城河 | 商户工作流、用户入口和数据形成中等护城河 | 中 |
| 管理层 | 产品与资本执行较强，风险控制待验证 | 中 |
| 最大风险 | 信用损失、监管、估值与平台竞争 | 高 |
| 长期趋势 | 数字支付和嵌入式金融支持增长 | 中高 |
| 估值 | TTM贵，forward口径依赖利润兑现 | 中高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 观望；$60–70 分批研究，等待 Q2 验证 |
| 持仓者 | 小仓持有，跟踪毛利、信贷损失与 FCF |
| 卖出信号 | 毛利增速显著放缓、坏账上升或资本回报恶化 |
| 加仓信号 | Q2 达到指引且每股 FCF持续增长、价格回落 |

综合决策：**WATCHLIST / 等待 Q2 与更宽安全边际**。AI 研究置信度中等，投资确定性中等。
