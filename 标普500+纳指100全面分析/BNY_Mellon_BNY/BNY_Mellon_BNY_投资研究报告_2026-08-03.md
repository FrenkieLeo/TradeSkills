# BNY Mellon（BNY）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。BNY Q2 2026 官方业绩于 7 月 15 日披露，涵盖托管资产、管理资产、手续费、净利息收入、资本比率和回购；独立数据补充估值。

Q2 总收入 $5.698B，同比增 13%；手续费收入 $4.036B，净利息收入 $1.446B，EPS $2.45，ROTCE 31.3%；托管/管理资产约 $62.6T，AUM $2.2T。结论：**HOLD / 资本市场基础设施质量高，但股价一年上涨约 53%，$130–145 更有安全边际。**

## 1. 最新业绩事实与关键问题

BNY Q2 2026 官方披露，净利润归属普通股股东 $1.696B，同比增 22%；非利息费用 $3.439B，税前经营利润率 39.8%。公司向股东返还 $1.5B，其中股息 $371M、回购 $1.1B；CET1 比率 11.0%，Tier 1 leverage 5.9%。手续费、证券服务、市场与财富服务以及投资管理均有增长。

BNY 的利润对客户资产、市场水平、资金流和短期利率敏感；独立统计给出 TTM EPS $8.57、ROE 14.12%，但金融机构的 FCF 口径不适合直接比较。重点是经常性手续费、客户资产增长、资本回报和技术投入的经营杠杆。

**段永平追问：**BNY 的增长是否来自稳定的托管/资产服务需求，还是来自市场上涨和短期利息收入？

## 2. 财务趋势与商业本质

| 口径 | 数值 |
|---|---:|
| Q2 AUC/A、AUM | 62.6T / 2.2T |
| TTM 收入 / 净利润 | 21.42 / 6.02 |
| TTM EPS | $8.57 |
| ROE / ROTCE（Q2） | 14.12% / 31.3% |
| 股息 / 回购收益率 | $2.12 / 3.97% |

BNY 的商业本质是全球资产托管、结算、抵押品、市场服务和财富/资产管理平台。护城河在监管许可、客户迁移成本、系统可靠性、数据和全球网络；它像金融基础设施而非传统银行，客户资产规模远大于自身资产负债表，但仍承担运营、流动性和网络安全风险。

| 护城河 | 判断 | 趋势 |
|---|---|---|
| 托管与结算网络 | 金融机构迁移成本高 | 高 |
| 监管与信任 | 关键基础设施资质形成壁垒 | 高 |
| 数据与技术 | 资产服务、抵押品和风险数据 | 中高 |
| AUM 与客户关系 | 规模支持交叉销售 | 中高 |
| 网络效应 | 市场参与者越多越有价值 | 中高 |

**巴菲特追问：**BNY 能否把资产服务规模转化为持续提高的每股利润，同时维持系统可靠性与资本纪律？

## 3. 护城河、管理层与逆向风险

管理层通过商业模式、平台和客户服务整合改善经营杠杆，Q2 的费用增长低于收入增长。主要风险不是信贷，而是系统中断、网络攻击、监管资本、客户流失和市场下跌。股价上涨后，回购价格也必须跟踪。

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 市场下跌导致 AUC/AUM 与费用下降 | 中 | 中高 |
| 网络安全或运营中断 | 中低 | 高 |
| 利率下降压低净利息收入 | 中 | 中 |
| 技术投入和费用失控 | 中 | 中高 |
| 高位回购与监管资本约束 | 中低 | 中 |

空方会说 forward P/E 16.28x、股价已大涨，利息收入可能回落；多头会说托管网络、长期客户和回购支持复利。投资者最容易把 AUC 当成可归属于股东的资产，忽略费率和经营杠杆。

**芒格追问：**若利率下降、市场横盘且客户费用率继续下滑，BNY 的经常性手续费能否维持高资本回报？

## 4. 行业与长期趋势

证券电子化、抵押品管理、私人市场、ETF、跨境结算和监管数据需求支持长期增长；云技术和 AI 可提升效率，也提高网络安全要求。托管业务的长期价值来自系统信任和客户迁移成本，增长上限则受费率竞争和客户集中约束。

**李录追问：**BNY 的长期复利是否来自金融资产持续增加及其复杂度提升，而非单纯市场 beta？

## 5. 股价与估值

2026-07-31 收盘价 $156.33；流通股约 678.50M。精确计算：$156.33 × 678.50M = **$106.07B**，与独立统计市值一致。trailing P/E 18.25x、forward P/E 16.28x、P/B 2.66x、P/TBV 6.01x；股息 $2.12/股、收益率约 1.36%，回购收益率约 3.97%。

以 $9.60 前瞻 EPS（$156.33 ÷ 16.28x）为基准，用 Decimal 计算情景价值：

| 情景 | 假设（EPS变化 / 终值PE） | 每股价值 | 关键变量 |
|---|---|---:|---|
| 悲观 | +5% / 14.5x | $146.20 | 利率、市场和费用率不利 |
| 中性 | +10% / 17x | $179.57 | 资产服务与经营杠杆稳定 |
| 乐观 | +14% / 19x | $207.99 | AUM、手续费与回购共振 |

现价低于中性情景，但安全边际受近期涨幅和利息收入周期限制。$130–145 更适合分批研究；若费用收入增长持续超过费用增长，估值可向中性靠拢。

## 6. 四位大师视角与最终决策

巴菲特会看客户迁移成本、监管护城河和资本回报；芒格会分离手续费、净利息收入、市场 beta和技术投入；段永平会看回购价格和平台是否真正为客户创造价值；李录会把金融资产数字化和系统复杂度纳入长期判断。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 资本市场基础设施质量高 | 高 |
| 护城河 | 监管、网络、系统和客户迁移成本高 | 高 |
| 管理层 | 经营杠杆与资本回报较强 | 中高 |
| 最大风险 | 运营、网络安全、市场和费率 | 高 |
| 长期趋势 | 资产数字化和复杂度支持 | 中高 |
| 估值 | 合理偏满 | 中高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 观望；$130–145 分批研究 |
| 持仓者 | 持有，跟踪手续费、AUC/AUM和资本比率 |
| 卖出信号 | 费用收入下降且费用失控或运营事故 |
| 加仓信号 | 经营杠杆、回购和客户资产增长持续 |

综合决策：**HOLD / 基础设施型金融平台等待价格**。AI 研究置信度高，投资确定性中高。
