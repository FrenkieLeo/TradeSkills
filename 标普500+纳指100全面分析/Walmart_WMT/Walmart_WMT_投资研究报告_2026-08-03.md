# Walmart（WMT）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为百万美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。Walmart 是全球披露最充分的零售企业之一，官方业绩、分部数据和市场统计齐全；主要研究难点不是信息不足，而是如何判断极低利润率、巨额资本开支与高估值是否匹配。

Walmart 的生意本质是以规模、低价、供应链和高频食品流量为底座，再叠加电商、广告、会员和平台业务。Q1 FY2027 以恒定汇率计总收入增长 7.3%，营业利润增长 5.9%，美国电商增长 26%。结论：**HOLD / 伟大的零售平台但价格偏贵；$90–100 才有更好安全边际，$111.20 不追高。**

## 1. 最新 Q1 FY2027 事实

Walmart 官方披露 Q1 FY2027 净销售约 $175.8B，调整后营业利润约 $7.9B，调整后 EPS $0.68；恒定汇率总收入增长 7.3%，营业利润增长 5.9%。Walmart US 电商增长 26%，Sam’s US 电商增长 23%，广告、会员和 Marketplace 等全球平台业务改善了收入结构。

公司对 Q2 指引为恒定汇率销售增长 4%–5%、营业利润增长 7%–10%、调整后 EPS $0.72–0.74；FY2027 销售增长指引仍为 3.5%–4.5%。Q2 业绩安排于 2026-08-20，当前状态标记为“待披露”，报告不把 Q2 结果写成事实。

**段永平追问：**Walmart 的核心价值是别人难以复制的低成本系统，还是仅仅把更多商品和流量放到一个低毛利平台上？

## 2. 财务趋势与商业本质

| 口径 | 数值 |
|---|---:|
| TTM 收入 | 725,310 |
| TTM 净利润 | 22,740 |
| TTM EBITDA | 44,840 |
| TTM 经营现金流 / FCF | 40,890 / 12,550 |
| 现金 / 总债务 | 10,730 / 75,550 |

Walmart 用巨量采购、门店和配送网络摊薄成本，以“价格信任”吸引高频食品和日用品流量，再让可选商品、电商、广告和会员提高客户价值。这个飞轮的优点是抗周期、频率高；缺点是商品零售本身利润率低，电商履约和扩张会消耗大量资本。广告、会员和 Marketplace 的增长能否持续快于核心零售，是估值上升的主要理由。

| 护城河 | 判断 | 趋势 |
|---|---|---|
| 规模与采购 | 全球采购、物流和门店密度带来结构性成本优势 | 变宽 |
| 价格品牌 | 低价信任与食品频率构成消费习惯 | 稳定 |
| 转换成本 | 单个消费者转换成本低，但综合便利性提高留存 | 中等 |
| 网络效应 | 电商、广告、Marketplace 和会员形成局部数据飞轮 | 变宽 |
| 技术壁垒 | 技术可购，真正壁垒是系统、规模和执行 | 稳定 |

**巴菲特追问：**十年后 Walmart 的规模优势能否继续抵消电商履约成本和低价竞争，还是增长越快资本回报越低？

## 3. 护城河、管理层与逆向风险

管理层的关键决策是把超大规模门店网络变成全渠道节点，并投资自动化、广告、会员和 Marketplace。Q1 的电商增速支持战略方向，但资本开支、库存和履约投入必须以每单经济性和自由现金流验证。由于估值高，管理层需要持续交出增长、利润和现金流三者兼顾的结果。

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 电商增长带来履约成本，利润率低于预期 | 中 | 高 |
| 关税、工资和供应链成本压缩商品利润 | 中高 | 高 |
| Amazon、Costco、Temu 等夺取流量或价格心智 | 中 | 中高 |
| 广告、会员和 Marketplace 货币化放缓 | 中 | 高 |
| 估值过高，稍有盈利 miss 即倍数压缩 | 高 | 高 |

空方会说：Walmart 是好公司，但 $884.94B 市值已经要求多年稳定增长；TTM P/FCF 约 70.5x，意味着现金流改善必须很快。投资者最容易犯的错误，是把平台业务的增长故事直接当成高毛利已实现。

**芒格追问：**如果电商和广告只改善收入、不改善每股自由现金流，当前估值是否仍然合理？

## 4. 行业与长期趋势

零售行业的结构趋势是线上线下融合、即时履约、零售媒体、会员化和自动化。Walmart 处在产业链最靠近消费者的位置，受益于食品和必需品防御性，但也承担库存、人工、运输和供应商议价的成本。AI 有助于预测、定价、补货和个性化，但低价承诺仍要靠实体网络和运营纪律。它更像消费基础设施，而不是高毛利软件平台。

**李录追问：**二十年后回看，Walmart 会是数字化时代的消费基础设施，还是被平台和新型供应链逐步商品化的庞大中间商？

## 5. 股价与估值

2026-07-31 收盘价为 $111.20；流通股约 7,960M。精确计算：$111.20 × 7,960M = **$885,152M（约 $885.15B）**，与独立数据源市值 $884.94B 的差异约 0.02%，属于股本口径/更新时间差异。TTM EV 约 $949.75B，TTM P/E 39.15x、Forward P/E 37.34x、P/FCF 70.50x、EV/EBITDA 21.18x、Debt/EBITDA 1.68x，股息 $0.99/股、收益率约 0.89%。

下表以 $2.978 的前瞻 EPS（$111.20 ÷ 37.34x）为基准，用 Decimal 计算三年情景价值；这不是公司指引。

| 情景 | 假设（3年 EPS 增长 / 终值 PE） | 3年每股价值 | 关键变量 |
|---|---|---:|---|
| 悲观 | 4% / 22x | $73.70 | 成本上升、平台货币化不足 |
| 中性 | 7% / 28x | $102.15 | 核心零售稳健，平台业务温和改善 |
| 乐观 | 9% / 35x | $134.98 | 电商、广告、会员持续高增长且利润率上行 |

当前价格高于中性三年价值，意味着市场已给了部分平台溢价。安全边际不能只看低债务或规模，而要看资本开支后 FCF、每股收益和估值倍数是否同时改善。

## 6. 四位大师视角与最终决策

巴菲特会认可规模、品牌和抗周期性，但会在高倍数上要求更高确定性；芒格会警惕低毛利业务在关税、工资和电商投入下的复杂性；段永平会看低价与便利是否形成真实用户习惯；李录会把 Walmart 视为消费基础设施，并追问平台化是否提高资本回报。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 极强规模和高频需求，利润率天然较低 | 高 |
| 护城河 | 采购、物流、门店和品牌构成宽护城河 | 高 |
| 管理层 | 平台化方向合理，执行和资本回报需跟踪 | 中高 |
| 最大风险 | 高估值叠加低利润率与巨额资本开支 | 高 |
| 长期趋势 | 全渠道、广告和会员有利 | 高 |
| 估值 | 明显偏贵，安全边际不足 | 高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 观望；$90–100 或盈利上修后再研究 |
| 持仓者 | 可持有高质量仓位，但不因业绩增长追高 |
| 卖出信号 | 电商/广告增长放缓且 FCF 不增，或全年指引下修 |
| 加仓信号 | 价格进入 $90–100，且资本开支后 FCF 和利润率改善 |

综合决策：**HOLD / 质量高但估值贵**。AI 研究置信度为高（数据充足），投资确定性为中高（生意清晰，但当前价格压缩回报）。
