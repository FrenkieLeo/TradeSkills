# Bank of America（BAC）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。BAC Q2 2026 已于 7 月 14 日发布，官方资料披露收入、净利润、EPS、ROTCE和分部趋势；独立统计补充估值与资产负债表。

Q2 收入（扣除利息费用）$31.6B、净利润 $9.1B、稀释 EPS $1.21、ROTCE 17.0%。TTM 净利润 $32.13B、EPS $4.33、ROE 11.20%，forward P/E 12.51x。结论：**HOLD / 规模、存款和资本市场业务强，但股价已反映利率与盈利修复；$52–58 更有安全边际。**

## 1. 最新业绩事实与关键问题

BAC 官方 Q2 结果显示盈利保持强劲，净利润 $9.1B，ROTCE 17.0%；公司继续受益于投资银行、交易、存款和信用卡等多业务。公司近期宣布拟收购英国网络安全咨询公司 MDSec，预计 2026 Q4 完成，体现对数字风险的投入，但该交易不是短期利润主驱动。

银行应重点看净息差、存款成本、贷款增长、信贷损失准备、资本比率和费用效率。TTM FCF 与银行的监管资产负债表不具可比性，估值以正常化 EPS、P/TBV 和 ROTCE更合适。

**段永平追问：**BAC 的盈利修复是否来自长期客户与存款优势，还是来自利率、投资银行和信用周期的阶段性顺风？

## 2. 财务趋势与商业本质

| 口径 | 数值 |
|---|---:|
| Q2 收入 / 净利润 | 31.6 / 9.1 |
| TTM 收入 / 净利润 | 113.93 / 32.13 |
| TTM EPS / ROE | $4.33 / 11.20% |
| 每股账面价值 | $39.34 |
| 股息 / 回购收益率 | $1.28 / 3.72% |

BAC 的商业本质是通过庞大存款、消费金融、商业银行、财富管理和资本市场网络赚取利差与手续费。护城河在低成本存款、分支与数字渠道、客户数据、监管资本和全球交易能力；规模同时带来系统、合规和信用风险。

| 护城河 | 判断 | 趋势 |
|---|---|---|
| 存款与客户关系 | 个人、企业和机构存款规模大 | 高 |
| 数字与分支网络 | 支付、消费和财富服务交叉销售 | 中高 |
| 资本市场平台 | 投行、交易和研究形成能力 | 中高 |
| 监管与资本 | 大银行牌照和风险系统高壁垒 | 高 |
| 网络效应 | 支付和金融网络有规模效应 | 中高 |

**巴菲特追问：**在完整信用周期中，BAC 能否保持高于资本成本的 ROTCE，并把存款优势转成每股价值？

## 3. 护城河、管理层与逆向风险

管理层通过费用纪律、资本回报、数字化和业务分散改善盈利。最大风险是信用卡/商业贷款损失、商业地产、存款迁移、监管资本和利率变化。Q2 的强势不能替代跨周期验证。

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 信用卡、消费或商业贷款损失上升 | 中 | 高 |
| 存款成本上升、净息差收缩 | 中 | 中高 |
| 商业地产和杠杆客户风险 | 中 | 高 |
| 监管资本要求提高 | 中 | 中高 |
| 投资银行收入周期回落 | 中 | 中 |

空方会说股价一年上涨近 30%，forward P/E 12.5x 并不极低，ROE仍低于顶级银行；多头会说资本、存款和回购推动 EPS 复利。投资者最容易把单季投资银行收入当成持续盈利。

**芒格追问：**若利率下降、失业上升且信贷损失超预期，BAC 仍能否保持股息与回购而不削弱资本？

## 4. 行业与长期趋势

数字支付、财富管理、跨境资本市场和企业融资支持长期需求；AI 和网络安全提高技术投入，监管增加合规成本。大型银行的长期优势是低成本存款和客户网络，长期风险是金融科技、监管、周期和资产负债表杠杆。

**李录追问：**BAC 的长期复利来自规模与低成本存款，还是来自一次利率与资本市场周期？

## 5. 股价与估值

2026-07-31 收盘价 $61.95；流通股约 6.99B。精确计算：$61.95 × 6.99B = **$433.03B**，与独立统计市值 $433.20B 的差异主要来自股数四舍五入。trailing P/E 14.31x、forward P/E 12.51x、P/B 1.57x、P/TBV 2.09x；股息收益率约 2.07%，回购收益率约 3.72%。

以 $4.95 前瞻 EPS（$61.95 ÷ 12.51x）为基准，用 Decimal 计算情景价值：

| 情景 | 假设（EPS变化 / 终值PE） | 每股价值 | 关键变量 |
|---|---|---:|---|
| 悲观 | +5% / 11.5x | $59.80 | 信贷损失与净息差压力 |
| 中性 | +10% / 13.5x | $73.54 | ROTCE、回购与费用效率稳定 |
| 乐观 | +15% / 15.5x | $88.27 | 资本市场、存款与信用均改善 |

现价接近悲观与中性之间，安全边际一般。$52–58 可提高回购和信用周期缓冲；若 ROTCE 继续上升且净冲销稳定，估值可向中性靠拢。

## 6. 四位大师视角与最终决策

巴菲特会看低成本存款、贷款质量和跨周期 ROTCE；芒格会拆分净息差、投行、信用损失和资本要求；段永平会看回购价格与客户价值；李录会把银行数字化、监管和信用周期纳入长期判断。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 全能银行平台，规模和存款强 | 高 |
| 护城河 | 存款、网络、监管和数据高 | 高 |
| 管理层 | 资本回报与费用纪律改善 | 中高 |
| 最大风险 | 信用、利率、资本和监管 | 高 |
| 长期趋势 | 财富、支付和资本市场支持 | 中高 |
| 估值 | 合理偏满 | 中高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 观望；$52–58 分批研究 |
| 持仓者 | 持有，跟踪 ROTCE、净息差和净冲销 |
| 卖出信号 | 信贷损失上升同时仍高位回购 |
| 加仓信号 | ROTCE 上升、存款稳定且价格回落 |

综合决策：**HOLD / 全能银行等待价格**。AI 研究置信度高，投资确定性中高。
