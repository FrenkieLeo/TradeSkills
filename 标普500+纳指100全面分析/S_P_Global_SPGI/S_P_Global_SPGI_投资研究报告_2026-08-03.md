# S&P Global（SPGI）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。S&P Global已公布 2026 Q2，并完成 Mobility Global分拆；官方披露分拆后 pro forma、评级、指数、市场情报、能源与AI，独立统计补充股价与估值。AI研究置信度高，投资确定性中高。

Q2 GAAP收入 $4.146B，同比增长 10%；剔除 Mobility的 pro forma收入 $3.678B，同比增长 11%；调整后 EPS $4.83，同比增长 23%，调整后营业利润率 54.3%。结论：**HOLD；评级、指数和数据资产的护城河极强，但约25x TTM PE与分拆后转型、AI定价和资本市场周期仍需留安全边际。**

## 1. 最新业绩事实与关键问题

SPGI通过信用评级、指数、市场情报、能源数据和分析软件为发行人、资产管理人、银行、企业和政府提供决策基础设施。Q2 GAAP营业利润 $1.812B、净利润 $1.217B、摊薄 EPS $4.12；剔除 Mobility后的 pro forma净利润 $1.205B、EPS $4.08；调整后营业利润 $1.998B。

公司于 7 月 1 日完成 Mobility分拆，当前重点更集中于 Ratings、Indices、Market Intelligence和Energy四个核心部门。Q2回购 $500M，全年回购预期超过 $7B；2026指引为收入增长 5.9%–7.9%、有机固定汇率增长 6.0%–8.0%、调整后 EPS $17.50–$17.75。

**段永平追问：**客户购买 S&P Global是因为评级、指数和数据真正进入决策流程，还是只是因为行业惯性与采购锁定？

## 2. 财务趋势与商业本质

商业本质是把高可信评级、指数许可、基准数据、能源信息和工作流软件转化为经常性订阅/许可费，并在债券发行和市场活跃时获得评级与交易相关收入。护城河来自品牌信任、监管认可、历史数据库、指数生态和高切换成本；AI可以降低信息获取成本，也可能压低部分数据价值。

| 口径 | Q2 2026数值 |
|---|---:|
| GAAP收入 / 同比 | $4.146B / +10% |
| Pro forma收入（剔除Mobility）/同比 | $3.678B / +11% |
| GAAP净利润 / 摊薄EPS | $1.217B / $4.12 |
| 调整后营业利润 / 调整后EPS | $1.998B / $4.83 |
| 调整后营业利润率 | 54.3% |

独立统计显示 TTM收入 $16.12B、净利润 $4.92B、EPS $16.42、自由现金流 $5.57B，TTM PE约25.09x、Forward PE约21.80x、P/FCF约21.79x。分拆后应以 pro forma而非含 Mobility的历史增长评估，且并购摊销、资本结构和回购会影响表观 EPS。

**巴菲特追问：**评级与指数的品牌定价能力能否在 AI和开放数据时代保持，而不是被客户要求更低费率？

## 3. 护城河、管理层与逆向风险

| 失败路径 | 概率 | 影响 |
|---|---|---|
| AI替代部分研究、数据和分析工作流 | 中 | 高 |
| 债券发行与资本市场周期下滑 | 中 | 中高 |
| 评级失误、诉讼或监管处罚 | 低至中 | 极高 |
| 分拆后成本、协同和组织调整失控 | 中 | 中高 |
| 并购和高回购导致杠杆或资本错配 | 中 | 中 |

管理层完成 Mobility分拆、提高回购指引并扩大AI产品，资本配置积极。关键不是单季利润率，而是 Ratings/Indices的品牌、Market Intelligence的留存与净扩张、Energy的数据深度，以及AI是否提高客户价值而不是仅降低服务成本。跟踪有机固定汇率增长、续约/净扩张、评级发行量、指数资产规模、调整后利润率、FCF和回购价格。

**芒格追问：**我是否把过去的垄断式信息优势外推到AI降低搜索成本的未来？

## 4. 行业与长期趋势

全球债务增长、被动投资、ETF、私募市场、能源转型和企业风险管理支持评级、指数与数据需求；AI、开放金融数据和客户自建分析则带来替代。SPGI最重要的长期变量是把可信基准嵌入更多自动化工作流，保持“标准制定者”而非普通数据供应商。

**李录追问：**金融市场复杂度和长期数据积累，能否让 S&P Global 在AI时代继续复利，而不是只提高短期效率？

## 6. 四位大师视角与最终决策

巴菲特会看评级、指数和数据许可的高回报资产；芒格会看AI替代、监管和高估值；段永平会看客户是否真正依赖基准和工作流；李录会看全球资本市场复杂化与长期数据复利。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 顶级金融信息与基准平台 | 高 |
| 护城河 | 信誉、标准、数据和生态 | 高 |
| 管理层 | 分拆和回购执行积极 | 中高 |
| 最大风险 | AI替代、周期、评级监管 | 高 |
| 估值 | 质量高但需安全边际 | 高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 当前观察；$380以下分批 |
| 持仓者 | 持有，跟踪核心业务有机增长 |

综合决策：**HOLD**。AI分析置信度高；投资确定性中高，护城河强，但分拆后的基准和AI经济学需要数季验证。
