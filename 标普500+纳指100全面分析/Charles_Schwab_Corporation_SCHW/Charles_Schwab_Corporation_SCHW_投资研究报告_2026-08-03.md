# Charles Schwab Corporation（SCHW）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。Schwab 的 Q2 2026 已于 7 月 21 日公布，官方业绩同时提供净收入、GAAP/调整后 EPS、客户资产、净新增资产、交易量和净息差；独立统计补充股价、股本、FCF与估值。

Q2 净收入 $7.072B、同比增 21%；净利润 $2.8B、GAAP EPS $1.54，调整后 EPS $1.62。核心净新增资产约 $119.8B，6 月单月 $62.7B；日均交易 11.9M，客户总资产 $13.08T。结论：**HOLD / 低费率经纪与财富平台质量高，但价格已反映部分增长；$90–100 更适合加仓。**

## 1. 最新业绩事实与关键问题

Schwab 的收入来自净利息收入、资产管理和行政费、交易收入、银行存款与保证金融资。Q2 净息差升至 3.00%，交易收入约 $1.2B、同比增 28%，资产管理和行政费约 $1.8B、同比增 16%。这些数据说明平台既受利率和现金余额影响，也受客户资产与交易活动驱动。

公司新增 140 万经纪账户，推出面向零售客户的加密交易，并继续向财富管理、RIA、银行和保证金服务扩展。关键问题是：客户资产增长是否转化为经常性费用和存款，而不是靠一次性市场上涨与交易波动；银行业务扩张是否增加流动性和信用风险。

**段永平追问：**Schwab 的低价入口和品牌是否足以让客户把更多资产长期留在平台，而不是只在交易活跃时产生收入？

## 2. 财务趋势与商业本质

| 口径 | TTM/最新数值 |
|---|---:|
| TTM 收入 / 净利润 | 26.03 / 9.72 |
| TTM EPS / FCF每股 | $5.49 / $5.59 |
| 现金 / 总债务 | 73.60 / 37.10 |
| 账面价值 / 每股账面价值 | 50.10 / $28.88 |
| Q2 GAAP / 调整后 EPS | $1.54 / $1.62 |

商业本质是以低成本获客和广泛产品分发聚集客户资产，再通过现金管理、交易、资产管理、保证金和银行服务变现。护城河来自规模、品牌、客户迁移成本、RIA生态、技术与资产负债表；零佣金使单一交易费不再是核心，客户资产和钱包份额才是核心。

| 护城河 | 判断 | 趋势 |
|---|---|---|
| 客户资产与品牌 | 高，信任与账户迁移提高留存 | 中高 |
| RIA与财富生态 | 专业客户黏性强 | 高 |
| 规模与低成本 | 支撑定价和技术投入 | 稳定 |
| 现金/银行能力 | 提高变现但引入利率风险 | 中高 |
| 数据与产品入口 | 适合交叉销售，竞争激烈 | 中 |

**巴菲特追问：**若市场交易量和利率都回到常态，Schwab 是否仍能以客户资产和费用收入维持高回报？

## 3. 护城河、管理层与逆向风险

管理层在低费率、账户增长、财富管理和资本回报之间保持了较好的平衡。Q2 调整后税前利润率 54.3%，调整后有形普通股权益回报率 44%，但业务仍受利率、客户现金配置和监管资本影响。加密交易和保证金融资提高产品吸引力，也扩大运营与风险边界。

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 利率下降、客户现金迁移 | 中 | 高 |
| 交易量回落、市场估值下降 | 中 | 中高 |
| 保证金融资或银行资产信用恶化 | 中低 | 高 |
| 产品竞争导致费率持续下降 | 中 | 中 |
| 技术、网络安全或合规事故 | 低 | 极高 |

空方会指出 P/B约 3.64x、客户现金和净息差敏感；多头会指出资产规模、净新增资产、经常性费用和高 ROTCE。反方验证应看资产净流入、客户现金余额、净息差、交易收入、费用收入和回购后的每股收益。

**芒格追问：**Schwab 是资产平台，还是在低利率与高交易活跃环境下被周期暂时放大的银行/券商混合体？

## 4. 行业与长期趋势

退休资产、ETF、指数化投资、RIA独立化和财富管理需求支持长期资产增长；数字化开户和智能投顾扩大覆盖，但零佣金、Robinhood、银行和大型资管平台压低收费。加密与 AI 工具提高客户互动，却不是确定的护城河。

长期跟踪：核心净新增资产、客户总资产、账户数、资产管理费、客户现金和净息差、日均交易、保证金借款、银行贷款、调整后利润率、资本回报和回购。若费用收入增速继续快于成本，质量高于单季交易量激增。

**李录追问：**Schwab 是否能把美国长期储蓄和财富迁移变成不依赖市场方向的每股复利？

## 5. 股价与估值

2026-07-31 收盘价 $105.24；股本约 1.74B。精确计算：$105.24 × 1.74B = **$183.12B**，与独立统计市值 $183.03B 接近。TTM PE 19.17x、forward PE 15.07x、P/FCF 18.82x、P/B 3.64x。估值不属于低倍数，但平台质量和资本回报可支撑中高倍数。

| 情景 | 估算EPS / PE | 每股价值 | 相对现价 |
|---|---:|---:|---:|
| 悲观 | $6.20 / 15x | $93.00 | -11.6% |
| 中性 | $7.00 / 18x | $126.00 | +19.7% |
| 乐观 | $7.80 / 21x | $163.80 | +55.6% |

情景 EPS为研究假设；中性情景要求客户资产、费用收入和净息差共同保持增长。当前价格与悲观价值的距离不大，若利率下降导致现金迁移，估值可能向 15x靠拢；$90–100 更能提供风险缓冲。

## 6. 四位大师视角与最终决策

巴菲特会看客户资产、低成本和长期现金流；芒格会拆分券商手续费、净息差、银行风险与资本回报；段永平会看客户信任和管理层是否长期克制费用；李录会把退休资产、RIA迁移和数字化财富管理放入长期复利框架。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 高质量财富与资产平台 | 高 |
| 护城河 | 品牌、规模、客户与 RIA生态高 | 高 |
| 管理层 | 执行稳健，周期管理需跟踪 | 中高 |
| 最大风险 | 利率、现金迁移、竞争与信用 | 中高 |
| 长期趋势 | 财富资产与退休储蓄支持 | 高 |
| 估值 | 合理偏满 | 高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 观望；$90–100 分批研究 |
| 持仓者 | 持有，跟踪净新增资产与净息差 |
| 卖出信号 | 资产流出、费用收入停滞或银行风险上升 |
| 加仓信号 | 价格回落而客户资产、费用和资本回报仍增长 |

综合决策：**HOLD / 高质量财富平台等待安全边际**。AI 研究置信度高，投资确定性中高。
