# ONEOK（OKE）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A-。ONEOK 的分部、吞吐量、资本开支和指引披露充分，但 Q2 在截止日尚未披露，且并购后杠杆和现金流口径需要持续观察。

ONEOK 是覆盖 NGL、天然气处理、天然气管道以及成品油/原油运输的中游基础设施平台。Q1 2026 净利润 $776M、调整后 EBITDA $1.997B，同比各增 12%/13%；公司把全年调整后 EBITDA 指引提高至 $8.0–8.5B，EPS 中点 $5.53。结论：**HOLD / 现金流较稳但杠杆和估值限制上行；$80–88 更有安全边际。**

## 1. 最新 Q1 FY2026 事实

ONEOK 官方 Q1 发布显示，NGL 原料吞吐量同比增 15%，成品油运输量增 12%，天然气处理量增 5%。公司完成一座 150 MMcf/d 处理厂搬迁，并把 2026 年资本开支指引维持在约 $2.7–3.2B。Q1 还包括一项 $60M 的合资投资减值，影响约 $0.07/股，需与经营趋势分开。

Q2 2026 计划于 8 月 3 日收盘后发布；截至报告截止时不预先使用 Q2 数据。ONEOK 的投资逻辑在于长期合同和规模网络，而非单季 NGL 价差或优化收益。

**段永平追问：**ONEOK 的增长来自不可替代的管网和处理能力，还是来自并购后的财务杠杆与周期优化？

## 2. 财务趋势与商业本质

| 口径 | 数值 |
|---|---:|
| TTM 收入 | 35.20 |
| TTM 净利润 / EBITDA | 3.53 / 7.46 |
| TTM 经营现金流 / FCF | 5.63 / 2.24 |
| 现金 / 总债务 | 0.17 / 33.65 |

ONEOK 的商业本质是把生产区、分馏、储运和终端连接起来，收取处理、运输和储存费用，同时通过优化活动增加利润。资产规模和客户连接形成黏性，但整合 EnLink/Magellan 后债务、利息和资本开支不能忽略。

| 护城河 | 判断 | 趋势 |
|---|---|---|
| 管网与处理设施 | 区域覆盖、客户连接和长期合同 | 稳定偏宽 |
| NGL 网络 | 生产、分馏、出口一体化 | 中高 |
| 资产密度 | 新建替代成本高，选址与许可难 | 中高 |
| 并购整合 | 规模协同存在，执行复杂 | 中性 |
| 网络效应 | 物流节点越多越有利，但非软件网络效应 | 中高 |

**巴菲特追问：**在维护资本开支和利息后，ONEOK 的可分配现金流是否足以支持 3–4% 的股息增长？

## 3. 护城河、管理层与逆向风险

管理层提高全年指引并推进项目建设，显示运营执行不错；但并购后的股本增长、债务和低现金余额使股东回报对利率更敏感。当前 P/FCF 较高，不能把调整后 EBITDA直接当成股东现金流。

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 并购协同低于预期 | 中 | 高 |
| 利率、再融资和杠杆压力 | 中高 | 高 |
| NGL 价差与优化利润回落 | 中高 | 中高 |
| 项目延期、成本超支 | 中 | 中高 |
| 分配增长低于市场预期 | 中 | 中高 |

空方会说 OKE 是高杠杆管网资产、收益率不够补偿估值；多头会强调网络密度、长期合同和 NGL 增长。投资者最容易犯的错误是用 EBITDA 增长忽略债务服务和维护资本开支。

**芒格追问：**如果 NGL 周期变弱且利率维持高位，ONEOK 是否仍能同时投资、降杠杆和提高股息？

## 4. 行业与长期趋势

天然气发电、LNG、出口、化工和数据中心用能支持中长期基础设施需求；能源转型也可能增加天然气调峰价值。风险是管道项目监管、客户破产、替代能源和能源生产区增速放缓。

**李录追问：**ONEOK 的基础设施是长期能源转型的桥梁，还是被新技术和需求迁移锁住回报的重资产？

## 5. 股价与估值

2026-07-31 收盘价 $90.81；流通股约 630.15M。精确计算：$90.81 × 630.15M = **$57.22B**，与独立市值 $57.22B 差异约 0.01%。TTM EV $90.70B，P/E 16.21x、Forward P/E 15.42x、P/FCF 25.52x、EV/EBITDA 12.16x、Debt/EBITDA 4.51x；股息 $4.28/股、收益率约 4.71%。

以下以 $5.889 前瞻 EPS（$90.81 ÷ 15.42x）为基准，用 Decimal 计算三年情景。

| 情景 | 假设（3年 EPS 增长 / 终值 PE） | 3年每股价值 | 关键变量 |
|---|---|---:|---|
| 悲观 | 2% / 13x | $81.24 | 杠杆、利息和价差压制 |
| 中性 | 6% / 16x | $112.22 | 资产利用率和协同兑现 |
| 乐观 | 8% / 19x | $140.95 | NGL、管网和项目同步增长 |

当前价格接近悲观与中性区间之间，$80–88 更适合作为分批研究区间。

## 6. 四位大师视角与最终决策

巴菲特会看长期合同和可分配现金流；芒格会重点审视杠杆、资本开支和并购复杂度；段永平会追问资本回报是否在高估值时仍理性；李录会把天然气基础设施的过渡期价值与监管风险一起折现。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 区域基础设施强，资本密集 | 高 |
| 护城河 | 管网、处理和终端网络较宽 | 高 |
| 管理层 | 运营和指引执行良好，并购整合待验 | 中高 |
| 最大风险 | 杠杆、利率、分配覆盖 | 高 |
| 长期趋势 | 天然气/NGL 支撑，监管和转型并存 | 中高 |
| 估值 | 合理偏满 | 中高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 观望；$80–88 分批研究 |
| 持仓者 | 持有并跟踪债务、利息覆盖和分配增长 |
| 卖出信号 | 分配覆盖恶化或并购协同低于预期 |
| 加仓信号 | Q2 证明 EBITDA 增长而杠杆下降 |

综合决策：**HOLD / 中游现金流观察**。AI 研究置信度高，投资确定性中高但受杠杆约束。
