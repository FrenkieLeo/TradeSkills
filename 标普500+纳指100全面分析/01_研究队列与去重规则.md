## 一、数据来源

成分股名单采用公开指数成分数据建立，并在每个批次开始前复核：

| 指数 | 主要来源 | 说明 |
|---|---|---|
| S&P 500 | S&P Dow Jones Indices 官方页面、Wikipedia 成分股表 | S&P 500 是 500 家公司、约 503 个普通股证券，部分公司存在多股权类别 |
| Nasdaq-100 | Nasdaq 官方页面、Slickcharts Nasdaq-100 成分表、Wikipedia Nasdaq-100 页面 | Nasdaq-100 约 100 家非金融公司，实际证券数量会因 share class 与调整而略有差异 |

## 二、去重原则

1. 研究对象以“公司主体”为单位，而不是证券代码数量。
2. 同一公司多股权类别只做一家公司研究，但在索引文件中标注对应 ticker。
3. 例：Alphabet 的 `GOOG` 与 `GOOGL` 合并为 `Alphabet_Inc_GOOG_GOOGL`。
4. 例：Fox、News Corp 等双股权公司同样合并研究。
5. 若同一公司同时属于 S&P 500 与 Nasdaq-100，只研究一次，并在 `指数归属` 字段同时标注两个指数。
6. 若 ADR、外资公司、特殊上市主体出现在 Nasdaq-100 中，但不在 S&P 500 中，仍单独纳入研究。
7. 每批开始前复核新增/删除成分，变动记录写入本文件。

## 三、批次安排

优先顺序不是投资推荐，只是执行调度：

| 优先级 | 范围 | 原因 |
|---|---|---|
| P0 | 两个指数共同重仓、权重最高、用户过往重点关注公司 | 对组合和指数解释力最大 |
| P1 | Nasdaq-100 主要科技、半导体、AI 基础设施公司 | 与用户当前 AI/价值投资研究主线相关 |
| P2 | S&P 500 各行业龙头 | 建立行业横向比较基准 |
| P3 | 其余 S&P 500 公司 | 完成遍历性研究 |

## 六、每家公司准出 checklist

| 检查项 | 要求 |
|---|---|
| 阶段文件 | 17 个正式 Markdown 文件齐全 |
| Skill 原文 | earnings-review、income-investment、investment-team、investment-research 完整保存 |
| Checklist/Screen | investment-checklist 与 quality-screen 完整保留在盈利持续性评分文件中 |
| 数据来源 | 公司披露 + 至少一个第三方交叉验证 |
| 估值 | DCF、相对估值、SOTP 如适用、Bear/Base/Bull、反向 DCF、安全边际 |
| 反方验证 | 明确失败路径与 thesis 否决条件 |
| 最终结论 | Buy / Hold / Watchlist / Avoid / Sell |
| 持续跟踪 | 明确下一财报、关键 KPI、触发阈值 |

## 七、状态定义

| 状态 | 含义 |
|---|---|
| 未开始 | 已进入 manifest，但尚未分配研究 |
| 研究中 | 已分配 agent 或正在人工整理 |
| 补写中 | 已重新分配补写 agent，等待远端文件落库 |
| 待校验 | 阶段文件已生成，等待准出检查 |
| 已完成 | 通过准出 checklist，最终报告与阶段文件均已落库 |
| 需补写 | 内容已生成或部分生成，但远端文件未完整落库 |
| 需返工 | 数据不足、skill 输出不完整或结论证据链不足 |
