# 03_财务质量分析

## 核心结论

Microsoft 的利润质量仍然很高，但 FY2026 出现一个必须重视的变化：经营现金流大幅增长，然而 AI 与云基础设施资本开支增长更快，导致自由现金流没有跟上净利润。会计利润是真利润，但可自由分配现金被再投资需求显著占用。

## 损益表质量

| 指标 | FY2026 | FY2025 | 变化 | 来源 |
|---|---:|---:|---:|---|
| 收入 | $331.839B | $281.724B | +18% | Microsoft FY26 Q4 release |
| 毛利 | $225.465B | $193.893B | +16% | Microsoft FY26 Q4 release / FY25 Annual Report |
| 毛利率 | 67.9% | 68.8% | -0.9ppt | 计算 |
| 经营利润 | $155.237B | $128.528B | +21% | Microsoft FY26 Q4 release |
| 经营利润率 | 46.8% | 45.6% | +1.2ppt | 计算 |
| 净利润 | $133.749B | $101.832B | +31% | Microsoft FY26 Q4 release |
| 稀释 EPS | $17.95 | $13.64 | +32% | Microsoft FY26 Q4 release |

利润率没有被 AI 投资击穿，说明 Microsoft 365、Azure 效率提升和软件经营杠杆仍能抵消部分基础设施成本。但 FY2026 净利润包含投资相关影响，分析持续盈利能力时应同时看 non-GAAP 与 FCF。

## 股权激励与稀释

FY2026 期末流通股 7.427B 股，FY2025 为 7.434B 股；FY2025 年报披露 SBC 为 $11.974B、FY2026 为 $12.405B。回购能够抵消稀释，但在 P/FCF 高企时，回购效率不如低估区间。

## 结论

Microsoft 不是“会计利润好看但现金流差”的公司；相反，它的经营现金流极强。真正的问题是 AI 基础设施进入重投入期，FCF 转化率阶段性降低。财务质量评级：**A-**。扣分项不是偿债或盈利，而是 CapEx 回收不确定性。
