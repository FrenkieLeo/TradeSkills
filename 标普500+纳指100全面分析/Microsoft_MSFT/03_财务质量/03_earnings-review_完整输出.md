## 二、本期最重要的 3 个变化

1. **Azure 与 AI 需求强于市场担忧**：FY2026 Q4 Azure and other cloud services revenue +43%，FY2026 Azure 年收入首次超过 $100B；Microsoft Cloud Q4 收入 $59.3B，全年超过 $214B。
2. **AI CapEx 成为财务质量核心变量**：FY2026 PPE additions $115.948B，较 FY2025 的 $64.551B 大幅增加；CFO 增长很快，但 FCF 从 $71.611B 降至 $66.987B。
3. **商业 RPO 暴增但也意味着履约压力**：商业 remaining performance obligation 增至 $678B。电话会说明，RPO 包含 OpenAI，平均期限 2.3 年，约 30% 将在未来 12 个月确认收入；若剔除 OpenAI，RPO 增长为 25%。

## 八、与投资 thesis 的关系

这份财报**强化商业质量 thesis**：Microsoft 的企业分发、Azure、Copilot、RPO 和经营杠杆仍强。  
这份财报**削弱轻资产现金流 thesis**：FY2026 FCF/净利润仅约 50%，AI CapEx 让传统软件公司的资本轻属性下降。  
综合判断：**强化长期平台 thesis，削弱短期 FCF 估值安全边际**。

## 九、结论

1. 这份财报相对市场预期：**超预期**。
2. 对投资论文影响：**强化增长与护城河，削弱 FCF 质量与估值安全边际**。
3. 下一个催化剂：FY27 Q1 Azure 增长、Microsoft Cloud gross margin、CapEx、RPO 剔除 OpenAI 后增长。
4. 持有者：可持有；新买入者：等待价格或 FCF 转化改善确认。
