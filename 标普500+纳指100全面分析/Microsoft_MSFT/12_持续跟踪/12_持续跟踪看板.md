# 12_持续跟踪看板

## 当前评级

**Hold / Watchlist**  
**核心 thesis**：Microsoft 的企业软件与云平台护城河仍强，AI 能提高长期收入天花板；但必须证明高 CapEx 能转化为高 FCF 回报。

## 关键指标看板

| 类型 | 指标 | 当前值 | 目标 / 警戒线 | 频率 |
|---|---|---:|---|---|
| 财报 | 收入增速 | FY2026 +18% | 低于 +10% 需复盘 | 季度 |
| 财报 | 经营利润增速 | FY2026 +21% | 低于收入增速且持续两季需警惕 | 季度 |

## Thesis 漂移信号

| 颜色 | 条件 |
|---|---|
| 绿色 | Azure 高增、RPO ex-OpenAI 健康、FCF 转化改善 |
| 黄色 | CapEx 继续高增但毛利率稳定，FCF 未恢复 |
| 红色 | Azure 放缓、Cloud 毛利率下降、FCF/NI 低于 50%、RPO 质量下降 |

## 催化剂日历

| 时间 | 事件 | 要看什么 |
|---|---|---|
| FY2027 Q1 earnings | 下季财报 | Azure 增速、CapEx、Cloud margin、Q1 指引 |
| FY2027 10-K / Annual Report | 年报 | 租赁承诺、采购承诺、OpenAI 相关披露、SBC |
| 每季 dividend declaration | 分红公告 | 分红增速是否与 FCF 匹配 |
| 监管进展 | EU / US 反垄断、数据隐私 | 捆绑销售、云合同、AI 合规影响 |

## 复盘问题

1. AI 收入是否只是 Azure 计算收入，还是提升了 Microsoft 365 / GitHub / Dynamics 的 ARPU？
2. RPO 增长是否来自广泛客户，而非少数 frontier model 公司？
3. CapEx 增长是否开始低于 CFO 增长？
4. Copilot 是否证明用户愿意为 AI 工作流长期付费？
5. 如果股价上涨到 $500+，FCF 是否足以支撑估值？
