## Guidance Accuracy

FY2026 Q4 电话会中管理层明确称，当剔除 Anthropic 投资收益、OpenAI 投资影响、VRP 费用低于预期、Xbox 减值与遣散等离散项目后，公司收入、经营利润和 EPS 均超过此前指引。说明短期运营执行强，但也提示 EPS 含一次性项目，需要看 non-GAAP 与 FCF。

## 并购兑现

| 标的 | 战略逻辑 | 当前兑现 |
|---|---|---|
| LinkedIn | 职业图谱 + 企业广告 + 招聘 | FY2025 收入 $17.812B，FY2026 Q4 +12%，兑现较好 |
| GitHub | 开发者入口 + Copilot | GitHub Copilot 使用增长，战略价值强 |
| Activision Blizzard | 游戏内容与订阅生态 | Xbox Q4 下滑，短期兑现不足 |
| OpenAI partnership | AI 模型与 Azure 独占能力 | Azure 与 Copilot 获益明显，但伙伴依赖和会计波动上升 |

## 结论

管理层不是只会讲 AI 故事，至少到 FY2026 为止，大部分核心承诺都有经营数据支持。最大未兑现风险不在收入，而在未来 2-3 年 AI CapEx 是否能转化成高 ROIC 和恢复 FCF 增长。
