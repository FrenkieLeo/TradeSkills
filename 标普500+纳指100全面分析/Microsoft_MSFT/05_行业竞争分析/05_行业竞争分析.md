# 05_行业竞争分析

## 结论

Microsoft 所在行业仍在变好：企业软件云化、AI 工作流、数据中心和开发者平台会继续扩大技术支出。但利润池不是平均分配的，真正赢家必须同时拥有分发、数据、算力、模型接入、企业信任和高利用率基础设施。Microsoft 是少数具备完整组合的公司。

## 价值链

| 环节 | 代表公司 | 利润池特征 | Microsoft 位置 |
|---|---|---|---|
| 芯片 / 服务器 | NVIDIA、AMD、Broadcom、ODM | 当前最稀缺，议价权强 | 买方，也在自研芯片 |
| 云基础设施 | AWS、Azure、Google Cloud | 规模经济强，但 CapEx 重 | 核心玩家 |
| 基础模型 | OpenAI、Anthropic、Google DeepMind、Meta | 技术迭代快，商业模式仍变动 | 伙伴+投资者+分发方 |
| 开发者平台 | GitHub、AWS、Google、GitLab | 工作流粘性高 | 强 |
| 企业应用 | Microsoft 365、Salesforce、ServiceNow、Adobe | 分发与数据入口最关键 | 强 |
| 安全 / 身份 | Microsoft、Palo Alto、CrowdStrike、Okta | 捆绑与平台化趋势 | 强 |

## 竞争格局

| 公司 | 云/AI 位置 | 优势 | 对 Microsoft 威胁 |
|---|---|---|---|
| AWS | 最大独立云平台之一 | IaaS 深度、开发者心智、企业规模 | Azure 基础设施竞争 |
| Google Cloud | AI 技术与数据强 | TPU、Gemini、搜索数据、云增长快 | AI 原生云和模型竞争 |
| Salesforce / ServiceNow | 企业流程应用 | 垂直业务流程深 | Copilot 与 Dynamics 竞争 |
| OpenAI / Anthropic | 模型层 | 模型能力与开发者关注度 | 伙伴也可能成为议价方 |
| Apple / Google | 消费端入口 | 移动操作系统与应用分发 | 个人 AI 入口竞争 |
| Sony / Nintendo / Steam | 游戏 | 内容与平台 | Xbox 盈利修复压力 |

## 云竞争对比

| 指标 | Microsoft | AWS | Google Cloud |
|---|---:|---:|---:|
| 最新披露云收入 | Microsoft Cloud FY2026 全年 >$214B；Azure FY2026 >$100B | AWS 2025 年报与 2026 季报继续高利润增长 | Google Cloud 2025 收入与利润大幅增长，2026 Q2 继续高增 |
| 增速 | Q4 FY2026 Azure +43% | AWS 增速稳健但基数大 | Google Cloud 增速更快但基数较小 |
| 利润率 | Intelligent Cloud FY2026 经营利润率约 41.3% | AWS 是 Amazon 主要经营利润来源 | Google Cloud 盈利能力提升 |
| 风险 | CapEx、OpenAI、毛利率 | 增速相对 Azure/GCP 压力 | 规模与企业分发不如 Microsoft |

## 行业五力

| 力量 | 判断 |
|---|---|
| 供应商议价权 | GPU、先进封装、数据中心电力和土地短期强 |
| 客户议价权 | 大客户强，但迁移成本高 |
| 新进入者 | 极低，资本和生态门槛极高 |
| 替代技术 | 开源模型、本地推理、客户自研可能改变部分价值分配 |
| 现有竞争 | 极强，但前三强仍享受规模经济 |

## 长期趋势

AI 不只是模型替代搜索，而是把企业 IT 支出从“软件席位”推向“软件席位 + 计算消费 + 自动化工作流”。Microsoft 最有利的位置是把 Copilot 嵌入 Microsoft 365、GitHub、Security、Dynamics 和 Azure，而不是只卖模型 API。

## 核心风险

行业变好不等于每一美元 AI CapEx 都有好回报。如果模型价格快速下降、客户把模型部署转向多云或私有云、或算力供给过剩，云厂商的新增投资回报率会下降。
