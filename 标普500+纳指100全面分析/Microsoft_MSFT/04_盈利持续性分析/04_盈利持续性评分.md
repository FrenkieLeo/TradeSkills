# 04_盈利持续性评分

## 总评分

**盈利持续性评分：8.4 / 10**  
扣分点集中在 AI 基础设施资本强度、OpenAI / frontier model 客户相关集中风险、云毛利率压力和监管风险。

## 评分表

| 维度 | 权重 | 得分 | 证据 |
|---|---:|---:|---|
| 收入复购与可预测性 | 20% | 9.5 | Microsoft 365、Azure、Dynamics、Security、GitHub、LinkedIn 均具备订阅或消费型重复收入 |
| 护城河 | 20% | 9.0 | 企业身份、文档格式、办公入口、云迁移、开发者生态构成组合护城河 |
| 经营利润率 | 15% | 9.0 | FY2026 经营利润率约 46.8% |
| 现金流转化 | 15% | 6.5 | FY2026 FCF/净利润约 50.1%，受 CapEx 压缩 |
| 资产负债表 | 10% | 9.0 | FY2026 净现金约 $36.5B |
| 资本配置 | 10% | 8.0 | 回购+分红可覆盖，但高估值回购效率一般 |
| 反脆弱性 | 10% | 8.0 | 多业务组合强，但 AI 投资周期可能放大波动 |

## Quality-screen 去劣筛选

| 指标 | Microsoft 数据 | 是否通过 |
|---|---:|---|
| 10年平均 ROE | 长期高于 20%，FY2026 约 30.2% | 通过 |
| 5年累计 FCF | 为正，且规模极大 | 通过 |
| 利息覆盖 | FY2026 经营利润远高于利息费用 | 通过 |
| 长期毛利率 | FY2026 约 67.9% | 通过 |
| CFO / 净利润 | FY2026 约 136.8% | 通过 |
| 长期净利率 | FY2026 约 40.3% | 通过 |
| 股本膨胀 | FY2026 期末股本较 FY2025 下降 | 通过 |

**去劣结论**：Microsoft 明确通过，不属于劣质公司。唯一需要解释的是 FCF 被 CapEx 压缩，但这不是经营现金流差，而是战略再投资强。

## 核心问题回答

Microsoft 能持续赚钱吗？大概率能。  
Microsoft 能持续把利润转化为自由现金流吗？可以，但 FY2026 说明转化率不稳定。  
Microsoft 的盈利持续性依赖什么？企业软件续费、Azure 利用率、AI 产品变现、CapEx 回收、监管可控。
