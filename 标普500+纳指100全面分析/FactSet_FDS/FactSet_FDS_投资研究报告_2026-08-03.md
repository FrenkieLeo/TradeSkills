# FactSet（FDS）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。FactSet 最新可用业绩为 FY2026 Q3（截至 5 月 31 日，7 月 1 日披露），官方/SEC资料提供收入、ASV、留存、AI 产品、利润率、EPS、FCF和全年指引；独立统计补充股价、股本、债务和估值。

Q3 收入 $622.9M，同比增 6.4%，有机收入增 7.0%；有机 ASV $2.4856B，同比增 7.1%，ASV留存率仍高于 95%。调整后 EPS $4.53，GAAP EPS $3.50，FCF $254M；FY2026 调整后 EPS指引 $17.25–17.75。结论：**HOLD / 订阅数据平台的留存和现金流强，但利润率承压、AI转型与估值仍需验证；$220–240 更适合加仓。**

## 1. 最新业绩事实与关键问题

FactSet 向机构买方、财富管理、投行、企业和资产所有者提供数据、研究、分析、工作流和 AI 工具，收入以订阅和 ASV为核心。Q3 ASV加速且企业续约期延长，说明客户黏性仍强；但 GAAP经营利润率降至 26.7%，薪酬、技术投入、CEO成本和转型投入压制短期利润。

公司强调超过 90% 的 Top 50客户已使用四个或以上 AI产品，AI可提高产品价值和客户留存，但也可能要求更高数据授权、算力和研发支出。长期价值来自 ASV、续订、每客户收入和毛利，而不是一次性专业服务。

**段永平追问：**FactSet 的数据与工作流是否足以成为客户长期基础设施，并支撑高留存下的价格增长？

## 2. 财务趋势与商业本质

| 口径 | TTM/最新数值 |
|---|---:|
| TTM 收入 / 净利润 | 2.44 / 0.57 |
| TTM EPS / FCF每股 | $15.19 / $19.92 |
| TTM FCF / 现金与总债务 | 0.708 / 0.304 / 1.57 |
| Q3 收入 / 有机 ASV | 0.623 / 2.486 |
| Q3 GAAP / 调整后 EPS | $3.50 / $4.53 |

商业本质是把金融市场数据、研究、组合分析和工作流打包成高续费企业订阅。护城河来自数据覆盖、历史数据库、客户工作流、集成、合规和转换成本；Bloomberg、S&P Global、MSCI、Morningstar及内部工具构成竞争。数据授权成本、AI工具和客户预算决定利润率。

| 护城河 | 判断 | 趋势 |
|---|---|---|
| 数据与历史数据库 | 高，构建和维护成本大 | 稳定 |
| 客户工作流与集成 | 高，迁移成本明显 | 中高 |
| ASV与续订 | 收入可见度高 | 高 |
| AI与产品扩展 | 提高价值但需投入 | 中高 |
| 品牌与企业销售 | 机构关系稳固 | 中高 |

**巴菲特追问：**在客户压缩数据供应商和 AI降低分析成本时，FactSet能否保持续费与定价权？

## 3. 护城河、管理层与逆向风险

管理层通过产品整合、AI、客户续约和回购维持每股价值；Q3 回购约 $203M、FCF $254M。短期风险是利润率下滑，长期风险是数据提供商被大型平台或客户自建工具替代。债务/EBITDA约1.69x、ROIC18.4%，资本结构尚可。

| 失败路径 | 概率 | 影响 |
|---|---|---|
| ASV增速降至低个位数 | 中 | 高 |
| AI工具压低数据/研究价格 | 中 | 高 |
| 薪酬、算力与技术投入压利润 | 中高 | 中高 |
| 数据授权成本上涨 | 中 | 中 |
| CEO交接和产品执行失误 | 中 | 中高 |

空方会指出股价一年跌约 36%、GAAP利润率下降和 P/B4.63x；多头会指出 ASV留存、FDS数据网络、AI渗透和 FCF。反方验证应看有机 ASV、续约率、每客户 ASV、调整后利润率、FCF转换和回购后股数。

**芒格追问：**AI会扩大FactSet产品价值，还是最终让金融数据和研究变成可替代的低价商品？

## 4. 行业与长期趋势

机构资产管理复杂度、监管报告、私人资产、风险管理和 AI工作流支持金融数据需求；但客户整合、被动投资、成本控制和自建数据平台压价。FactSet 的机会在把公共/私人资产、组合、交易和风险工作流统一起来。

长期跟踪：ASV增长与留存、客户续约期、财富/买方/企业客户、AI产品采用、数据授权成本、调整后经营利润率、FCF、回购和净债务。只要 ASV增速高于费用增速，利润率短期下行可接受；若 ASV也放缓，估值应下降。

**李录追问：**FactSet 是否拥有足够的数据与工作流网络，把 AI周期转化为长期客户价值，而不是增加成本？

## 5. 股价与估值

2026-07-31 收盘价 $263.20；股本 35.57M。精确计算：$263.20 × 35.57M = **$9.36B**，与独立统计市值 $9.36B一致。TTM PE 17.33x、forward PE 13.77x、P/FCF 13.22x；FY2026调整后 EPS指引中点约 $17.50。以调整后 EPS×PE做三情景。

| 情景 | 调整后EPS / PE | 每股价值 | 相对现价 |
|---|---:|---:|---:|
| 悲观 | $17.25 / 15x | $258.75 | -1.7% |
| 中性 | $17.50 / 18x | $315.00 | +19.7% |
| 乐观 | $17.75 / 21x | $372.75 | +41.6% |

中性价值上行约 20%，但前提是 FY2026 指引兑现且利润率稳定。当前价格已低于 50/200日均线附近的部分历史水平，风险收益改善；若 GAAP利润率持续下滑、AI投入无法带来 ASV加速，悲观倍数更合理。$220–240 更适合加仓。

## 6. 四位大师视角与最终决策

巴菲特会看订阅续费、数据资产和现金流；芒格会看客户迁移成本、数据成本与 AI替代；段永平会看产品是否真正解决客户问题；李录会把机构数字化、私人资产与长期数据网络放在一起评估。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 高留存的金融数据/工作流平台 | 高 |
| 护城河 | 数据、集成、客户关系高 | 高 |
| 管理层 | 现金回报与产品转型并行 | 中高 |
| 最大风险 | AI替代、利润率和客户预算 | 高 |
| 长期趋势 | 数据、风险和 AI工作流支持 | 中高 |
| 估值 | 合理，等待利润率证据 | 中高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 观望；$220–240 分批研究 |
| 持仓者 | 持有，跟踪 ASV、留存和利润率 |
| 卖出信号 | ASV放缓、续约率下降或 FCF转化恶化 |
| 加仓信号 | ASV加速、AI采用提高且利润率企稳 |

综合决策：**HOLD / 订阅数据平台等待利润率与 AI回报验证**。AI 研究置信度高，投资确定性中高。
