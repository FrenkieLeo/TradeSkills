# EOG Resources（EOG）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。EOG 的产量、单位成本、资本开支、现金流和储量资料充分；但 Q2 结果安排于 2026-08-05，当前报告只使用 Q1 和 TTM，避免把待披露季度写成事实。

EOG 是以美国和 Trinidad 多盆地资源、低成本运营、技术和资本纪律为核心的上游公司。Q1 2026 净利润 $1.98B、调整后净利润 $1.825B、FCF $1.493B，产量和单位成本好于指导中点；TTM P/E 14.66x、Forward P/E 8.96x。结论：**HOLD / 高质量上游但商品周期仍在；$125–140 才有安全边际，$148.69 暂不追高。**

## 1. 最新 Q1 FY2026 事实与待披露事项

EOG 官方披露 Q1 收入 $6.921B、GAAP 净利润 $1.980B、EPS $3.70；经营现金流 $2.966B，调整后 CFO $3.129B，自由现金流 $1.493B。公司支付普通股息 $544M、回购 $402M，油、气和 NGL 产量好于指导中点，并在资本预算不变的情况下重新分配资本以提高油和 NGL 产量。

Q2 2026 结果和电话会安排在 2026-08-05，当前状态标记为“待披露”。Q1 的重要信号不是单季利润，而是现金成本、DD&A、产量和资本开支同时受控；但实现价格和现金流仍受油气价格影响。

**段永平追问：**EOG 的优势是可持续的低成本文化和库存，还是优秀周期管理带来的暂时利润？

## 2. 财务趋势与商业本质

| 口径 | 数值 |
|---|---:|
| TTM 收入 | 23.57 |
| TTM 净利润 / EBITDA | 5.50 / 11.77 |
| TTM 经营现金流 / FCF | 10.72 / 3.97 |
| 现金 / 总债务 | 3.85 / 8.31 |

EOG 把多盆地库存、地质技术、垂直整合和运营文化转化为产量和 FCF。相较行业平均，公司更强调每桶现金成本、库存质量和项目回报，而不是追求最大产量；这让资本回报更好，但仍然需要持续开发来对冲页岩递减。

| 护城河 | 判断 | 趋势 |
|---|---|---|
| 资源与库存 | 多盆地高质量库存与高级定价区域有价值 | 稳定 |
| 低成本文化 | 单位成本、DD&A和执行能力形成差异 | 变宽 |
| 技术与垂直能力 | 地质、钻完井、基础设施和营销提高回收率 | 稳定 |
| 转换/网络效应 | 商品买方易切换，网络效应弱 | 弱 |
| 资本纪律 | 股息、回购和可选资本配置有记录 | 中高 |

**巴菲特追问：**十年后 EOG 能否在中周期价格下持续拥有高回报库存，而不是用更高资本开支换产量？

## 3. 护城河、管理层与逆向风险

管理层在 Q1 展现了调整资本到高回报液体资产、保持预算不变、控制单位成本和返还现金的能力。公司还保留回购授权，体现资本配置弹性；但回购平均价格和商品周期决定最终回报，不能简单把历史纪律外推为未来结果。

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 油气价格回落，FCF和回购下降 | 中高 | 高 |
| 页岩递减或库存质量不如预期 | 中 | 高 |
| 资本重新分配后产量/成本失衡 | 中 | 中高 |
| 管输、天然气定价或国际项目风险 | 中 | 中高 |
| 排放、甲烷和能源转型监管 | 中 | 中高 |

空方会说：8.96x Forward P/E 已反映低成本优质生产商溢价，且 P/FCF 约 20x；若油价回落，股息和回购的弹性会下降。投资者最容易犯的错误，是把 Q1 的高现金流归因于管理层，而忽略商品价格贡献。

**芒格追问：**我能否区分“公司做得好”和“市场价格帮了公司”这两个因素？

## 4. 行业与长期趋势

美国能源安全、出口、天然气发电和工业需求支撑 EOG 的中期市场；长期转型、资本成本和排放政策限制高成本资源。EOG 位于上游，但多盆地和产品组合使其比单一油田更有韧性。AI 可改善地质、钻井、设备维护和价格管理，却不能消除资源耗竭和油气波动。

**李录追问：**二十年后，EOG 会是能源转型中仍能产生现金的低成本资产，还是被长期需求与资本退出折价的上游企业？

## 5. 股价与估值

2026-07-31 收盘价为 $148.69；流通股约 532.63M。精确计算：$148.69 × 532.63M ÷ 1,000 = **$79.20B**，与独立数据源市值 $79.20B 一致。TTM EV $83.65B，P/E 14.66x、Forward P/E 8.96x、P/FCF 19.97x、EV/EBITDA 7.11x、Debt/EBITDA 0.71x；股息 $4.08/股、收益率约 2.74%。

下表以 $16.595 的前瞻 EPS（$148.69 ÷ 8.96x）为基准，用 Decimal 计算三年终值；这不是 Q2 指引。

| 情景 | 假设（3年 EPS 增长 / 终值 PE） | 3年每股价值 | 关键变量 |
|---|---|---:|---|
| 悲观 | -8% / 7x | $90.46 | 油气价格和现金回报下降 |
| 中性 | 3% / 9x | $163.20 | 低成本、产量和资本纪律稳定 |
| 乐观 | 7% / 12x | $243.95 | 产量/成本改善且商品环境友好 |

当前价格接近中性价值，回报不够厚地覆盖商品误判。$125–140 更能提供安全边际；Q2 后应重算实现价格、产量、现金成本、CAPEX和回购。

## 6. 四位大师视角与最终决策

巴菲特会认可低成本、强现金流和资本纪律，但按中周期价格估值；芒格会检查商品价格与回购时点；段永平会看管理层文化和真实的单位经济；李录会将能源安全与转型风险并置。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 上游中质量较高，仍受商品周期支配 | 高 |
| 护城河 | 资源、技术、成本和文化有差异 | 中高 |
| 管理层 | Q1执行与资本配置良好，需跨周期验证 | 中高 |
| 最大风险 | 油气价格、递减率和转型折价 | 高 |
| 长期趋势 | 能源安全支撑，转型限制长期倍数 | 中 |
| 估值 | 合理偏满，价格需安全边际 | 中高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 观望；$125–140 分批，先看 Q2现金流和产量 |
| 持仓者 | 持有但不追高，跟踪回购与单位成本 |
| 卖出信号 | FCF、产量或成本连续恶化，回购/股息失去覆盖 |
| 加仓信号 | Q2继续证明低成本高回报，且价格进入 $125–140 |

综合决策：**HOLD / 低成本上游观察**。AI 研究置信度为高，投资确定性为中高；公司质量清晰，但商品周期和 Q2待披露仍影响回报。
