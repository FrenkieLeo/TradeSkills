# 05 行业竞争分析：亚马逊（AMZN）

## 价值链位置

云计算、AI 训练/推理、电商广告和全球电商渗透仍是长期增长方向，但资本密集度正在上升。 的利润池通常流向拥有客户关系、技术壁垒、品牌、数据、分销或规模效率的一方。亚马逊 的位置是：消费者为低价、选择、配送速度和 Prime 权益付费；商家为流量、仓储履约和广告转化付费；企业客户为 AWS 的计算、存储、数据库和 AI 服务付费。

## 行业结构

| 维度 | 判断 |
|---|---|
| TAM | 长期空间存在，但不能直接等同公司收入 |
| 行业增速 | 取决于宏观、技术周期和客户预算 |
| 竞争对手 | 强竞争存在，需看差异化是否持续 |
| 供应商议价权 | 对毛利率和交付稳定性有影响 |
| 客户议价权 | 大客户集中时尤其重要 |
| 替代技术 | 反垄断监管 |

## 竞争优势

规模经济、Prime 会员习惯、物流密度、第三方卖家网络、广告闭环和 AWS 技术生态叠加。护城河仍在，但 AI 资本开支让 FCF 质量短期承压。

## 核心问题

这家公司不是只要行业增长就一定赚钱。巴菲特式问题是：行业变好以后，利润池由谁拿走？段永平式问题是：客户为什么不用别人家的东西？
