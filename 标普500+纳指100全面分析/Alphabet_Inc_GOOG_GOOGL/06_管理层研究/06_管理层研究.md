**研究口径**：公司主体合并研究；GOOG 为 Class C 无投票权股份，GOOGL 为 Class A 一股一票股份，二者经济权益同等。  


## 1. 核心管理层

| 人物 | 职务 | 评价 |
|---|---|---|
| Sundar Pichai | CEO, Alphabet and Google | 产品与组织型 CEO，擅长规模化运营、Android/Chrome/AI/Cloud 协调 |
| Ruth Porat | President & CIO / former CFO | 资本纪律和披露质量贡献大 |
| Anat Ashkenazi | CFO | 负责当前 AI CapEx、融资、股东回报平衡 |
| Larry Page / Sergey Brin | Co-founders, directors / Class B 控制权 | 技术愿景强，治理上外部股东投票权受限 |
| John Hennessy | Chair | 技术与学术声誉强，董事会稳定器 |

## 2. CEO 评估

Sundar Pichai 的优点是稳：他把 Google 从广告公司运营成多平台公司，Google Cloud 从亏损走向高增长盈利，Gemini/TPU/AI 基础设施形成全栈布局。弱点是：面对 OpenAI 引爆生成式 AI 后，Google 曾被市场认为反应偏慢；组织复杂、产品线众多，创新速度和监管协调成为挑战。

## 3. 资本配置能力

| 资本动作 | 评价 |
|---|---|
| Cloud 投入 | 正在兑现，Q2 2026 Cloud revenue +82%、margin 35.6% |
| TPU / AI infrastructure | 战略必要，但金额巨大，需用 backlog/FCF 回报验证 |
| Waymo | 长期期权，资金需求高，短期拖累利润 |
| 回购 | 过去有力抵消稀释；2026 Q2 暂停是负面变化 |
| 分红 | 小额、稳健，不影响主战略 |
| 债务与股权融资 | 资产负债表仍强，但从股东友好角度需提高审慎度 |

## 4. 治理结构

Alphabet 的治理最大特点是双/三股权结构。Class B 一股十票，创始人仍能显著影响董事选举和关键事项。对长期主义有好处：不容易被短期市场逼迫削减 AI 投入；对外部股东有坏处：若资本配置犯错，制衡能力较弱。

## 5. 薪酬与股东利益

SBC 是科技公司必要成本，但必须用回购抵消。2026 Q2 出现 ATM 计划用于员工股权税务义务，同时回购为 0，这要求后续持续观察：SBC 是否开始真实稀释外部股东，而不是被回购吸收。

## 6. 管理层结论

管理层整体优秀，执行力强，技术资产理解深。但 2026 年后的考题从“运营搜索现金牛”升级为“在 AI 资本开支超级周期中不毁掉股东回报”。因此管理层评分 4/5，不是因为能力弱，而是因为资本配置难度显著上升。

段永平追问：如果 Sundar Pichai 离开，Google 的产品和工程文化能否继续赢？如果 Larry/Sergey 仍通过 Class B 掌控方向，外部股东怎样判断他们不会过度烧钱追求技术理想？
