# 09 去重整合结论

**公司**：Alphabet Inc.  
**股票代码**：GOOG / GOOGL  
**交易所**：NASDAQ  
**研究日期**：2026-07-30  
**数据截止日**：2026-07-30  
**SOP 版本**：FrenkieLeo/TradeSkills `基本面分析/00_公司基本面分析SOP.md` v1.1  
**输出目录**：`标普500+纳指100全面分析/Alphabet_Inc_GOOG_GOOGL/`  
**研究口径**：公司主体合并研究；GOOG 为 Class C 无投票权股份，GOOGL 为 Class A 一股一票股份，二者经济权益同等。  


## 1. 双轨结论对照

| 来源 | 评级 | 核心理由 |
|---|---|---|
| investment-team | Hold | 四组均认可公司质量，但财务/风险组担心 FCF 与 CapEx |
| investment-research | Hold | 四大师框架下，好公司但价格安全边际不足 |
| 整合结论 | **Hold** | 持仓可持有，空仓等待 $285 以下或基本面验证 |

## 2. 去重后的核心 Buy 论点

1. Search & other Q2 2026 +17%，AI 功能并未立即破坏搜索商业化。
2. Cloud Q2 2026 +82%，operating margin 35.6%，backlog $514B，第二增长曲线质量显著提高。
3. YouTube 仍是全球视频注意力平台，FY2025 ads + subscriptions 超过 $60B。
4. Alphabet 资产负债表仍强，净现金 $129.718B。
5. Gemini、TPU、DeepMind、GCP、Workspace 形成 AI 全栈能力。
6. 经营利润率 32%-34%，说明核心平台仍有极强运营杠杆。

## 3. 去重后的核心 Bear 论点

1. AI assistant 可能重构搜索入口，使广告点击和流量分发模式变化。
2. FY2026 CapEx 上修至 $195-$205B，2027 仍预计显著增加。
3. Q2 2026 FCF 为 -$5.855B，TTM FCF yield 约 1.3%。
4. Q2 2026 GAAP EPS 被 $77.1B 税后投资收益显著放大。
5. 回购暂停、股权融资和 ATM 计划削弱旧有股东回报叙事。
6. EU DMA 和美国反垄断可能限制默认入口、自我优待和应用商店收费。

## 4. 冲突点

| 冲突 | 处理 |
|---|---|
| GAAP PE 很低 vs P/FCF 很高 | 采用正常化 EPS 和 owner earnings 双口径 |
| Cloud 高增长是否说明 AI CapEx 成功 | 暂定部分成功，但需要 4-8 个季度验证 |
| 融资是否负面 | 战略上可理解，股东回报上扣分 |
| GOOG/GOOGL 是否分开估值 | 不分开；经济权益同等，只在投票权上折价 |

## 5. 投资委员会最终表决

| 问题 | 结论 |
|---|---|
| 买入理由 | 卓越平台资产，Search/YouTube/Cloud/AI 多引擎 |
| 最大风险 | AI CapEx 回报不足和搜索入口迁移 |
| 当前价格 | 合理，不具明显安全边际 |
| 什么情况下可以买 | $285 以下，且 Search 与 Cloud 数据继续验证 |
| 什么情况下不能买 | FCF 被 CapEx 持续吞噬、回购不恢复、监管升级 |
| 什么情况下必须卖 | thesis 破坏：搜索商业化结构性下滑或 ROIC 中枢下移 |
| 仓位 | 轻到中等核心持仓；AI 暴露高的组合需控制 |
| 未来 3 年跟踪指标 | Search growth、Cloud backlog conversion、CapEx/Revenue、FCF、regulatory remedies |

## 6. 最终评级

**Hold**。这不是“公司一般”，而是“公司卓越但价格和资本配置不够舒服”。空仓者放入 Watchlist；持仓者继续持有并严密跟踪。
