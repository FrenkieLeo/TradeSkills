# Robinhood Markets（HOOD）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。Robinhood已公布 2026 Q2，披露交易收入、Gold订阅、净存款、事件合约和加密业务；独立统计补充股价、股本和估值。AI研究置信度高，投资确定性中低。

Q2收入创纪录 $1.31B，同比增长 32%；GAAP摊薄 EPS $0.62，但包含约 $129M与 Robinhood Ventures Fund I 去合并相关的收益；调整后 EPS约 $0.48。交易型收入同比增长 44%，Gold订阅用户达到 480万，但加密交易收入下降 38%。结论：**HOLD；产品扩张和用户货币化很强，但约38x TTM PE、交易周期和监管风险使现价不具备充分安全边际。**

## 1. 最新业绩事实与关键问题

Robinhood把股票、期权、加密、事件合约、现金管理、Gold订阅和退休账户整合到移动平台。Q2总收入约 $1.31B；交易型收入约 $776M，同比增长 44%，其中期权 $342M、股票 $129M、事件合约 $156M、加密约 $100M。净存款创纪录 $22B，Gold订阅用户 480万，同比增长约39%。

平台活跃度受市场波动、世界杯/事件交易和新产品影响明显；Q2经营费用增长约33%，反映产品、营销、合规和人员调整。AI代理交易已有接近10万用户、管理资产约 $100M，属于有潜力但尚未证明经济模型的业务。

**段永平追问：**用户真正留在 Robinhood是因为低摩擦金融服务和信任，还是只在市场热闹时回来交易？

## 2. 财务趋势与商业本质

商业本质是以用户资产、交易流量、净利息、订阅和新金融产品变现；护城河来自年轻用户品牌、移动体验、账户数据、产品迭代速度和跨业务交叉销售。交易收入的优点是高增长，缺点是高度周期性且受佣金、支付订单流、加密和监管影响。

| 口径 | Q2 2026数值 |
|---|---:|
| 总收入 / 同比 | 约$1.31B / +32% |
| GAAP摊薄EPS / 调整后EPS | $0.62 / 约$0.48 |
| 交易型收入 / 同比 | $776M / +44% |
| 净存款 | $22B |
| Gold订阅用户 | 4.8M |

独立统计显示 TTM收入 $4.93B、净利润 $2.07B、EPS $2.26，TTM PE约38.34x、Forward PE约36.63x、P/S约15.78x；TTM自由现金流仅约 $219M。Q2 GAAP利润包含 RVI去合并收益，估值必须更重视调整后盈利和可持续现金流。

**巴菲特追问：**Robinhood是否能在低波动、低加密、低投机的年份仍产生高质量订阅和资产管理现金流？

## 3. 护城河、管理层与逆向风险

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 交易热度回落，收入和利润剧烈下降 | 高 | 高 |
| 加密、事件合约引发监管限制 | 中高 | 高 |
| 用户资产和现金转向大型券商 | 中 | 中高 |
| 欺诈、系统宕机或合规事件 | 中 | 极高 |
| 新产品扩张带来费用与信用风险 | 中 | 中高 |

管理层快速推出Gold、事件合约、退休、AI代理和国际化产品，增长执行能力强；但员工、营销和合规成本同步上升，平台价值尚未完全从交易周期中脱离。跟踪净存款、用户留存、Gold ARPU、交易收入/用户、净利息收入、加密占比、事件合约监管和真实 FCF。

**芒格追问：**我是否被增长率和新产品叙事吸引，而忽略高倍数对波动性利润的放大？

## 4. 行业与长期趋势

年轻投资者、碎片化资产、加密、预测市场、AI交易和现金管理扩大零售金融场景；传统券商也能复制低费率和移动体验。长期赢家需要高信任、低欺诈、稳定现金管理与监管关系，而不只是更多可交易品种。

**李录追问：**Robinhood能否从“交易入口”升级为跨代际、跨资产的金融账户，而不被更强资本和合规能力的券商反超？

## 5. 股价与估值

2026-07-31 收盘价 $86.56；股本 899.08M。Decimal计算：$86.56 × 899.08M = **$77.8244B**，与独立统计市值 $77.82B基本一致。独立统计 TTM PE约38.34x、Forward PE约36.63x、P/S约15.78x、P/FCF约355x。

| 情景 | 正常化EPS | P/E | 目标价格 | 相对现价 |
|---|---:|---:|---:|---:|
| 悲观 | $2.00 | 25x | $50.00 | -42.2% |
| 中性 | $2.80 | 35x | $98.00 | +13.2% |
| 乐观 | $3.60 | 45x | $162.00 | +87.2% |

中性情景要求 Gold、净存款和股票/期权交易保持增长，事件合约成为稳定产品，同时加密低迷不再扩大、费用率得到控制。现价仍给了高增长溢价，$70以下才适合提高仓位；若调整后盈利不能转化成现金流，不能用一次性 GAAP EPS支撑估值。

## 6. 四位大师视角与最终决策

巴菲特会看品牌、用户资产和现金流；芒格会看交易周期、监管和激励；段永平会看产品是否让用户长期更简单地管理金融生活；李录会看零售金融数字化和新资产类别的长期迁移。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 高增长平台，现金流质量待验证 | 中 |
| 护城河 | 用户品牌、产品速度和数据 | 中高 |
| 管理层 | 产品执行强，风险边界需观察 | 中高 |
| 最大风险 | 周期、监管、合规与估值 | 高 |
| 估值 | 昂贵，依赖高增长 | 高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 当前观察；$70以下才考虑分批 |
| 持仓者 | 持有但控制仓位，等待现金流验证 |
| 卖出信号 | Gold/净存款停滞、交易收入骤降或监管收紧 |
| 加仓信号 | 调整后利润转化为现金流且价格低于 $70 |

综合决策：**HOLD**。AI分析置信度高；投资确定性中低，增长与产品创新很强，但利润周期和估值风险同样高。
