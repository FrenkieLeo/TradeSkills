## 商业本质

Nvidia 靠出售 AI 加速计算平台赚钱：GPU 是入口，CUDA 是锁定，NVLink/networking 是集群扩展，系统方案和软件生态把单卡竞争提升为整座数据中心竞争。

## 收入飞轮

| 环节 | 机制 |
|---|---|
| 模型更大、推理更多 | 客户需要更多计算 |
| 客户选择 Nvidia | 性能、供给、生态、上线确定性 |
| 开发者继续用 CUDA | 工具、库、框架和经验沉淀 |
| 集群规模扩大 | 网络和系统附加价值上升 |
| 现金流再投入 | 年度架构 cadence、供应链和软件栈更强 |

## 付费客户

Hyperscaler、AI 模型公司、Neocloud、企业、公共部门、游戏玩家、专业设计用户和车企。FY2026 两个直接客户分别贡献总收入 22% 和 14%，说明需求强，但客户集中风险也真实存在。

## 定价权

FY2026 GAAP 毛利率 71.1%，Q1 FY2027 GAAP 毛利率 74.9%。这不是普通硬件生意的利润率，说明客户支付的是系统级性能和工程确定性，而不只是硅片成本。

## 假护城河排查

| 说法 | 风险 |
|---|---|
| GPU 永远领先 | 单代性能可被追赶，真正护城河是系统+软件 |
| CUDA 永远不可替代 | 开源框架、compiler、客户自研会降低迁移成本 |
| AI 需求无限 | 单位 token 成本下降可能快于 token 需求增长 |
| 云厂永远外购 | Hyperscaler 有 ASIC 自研动机 |

结论：Nvidia 是极好的生意，但不是无风险垄断。长期胜负在于最低单位 token 成本、软件粘性和客户 ROI。
