# Blackstone（BX）投资研究报告

研究截止：2026-08-03；股价采用 2026-07-31 收盘。金额除每股数据外为十亿美元。

## 0. 信息丰富度与结论先行

信息丰富度：A。Blackstone Q2 2026 官方业绩已于 7 月 23 日披露，提供 AUM、FRE、DE、募资、部署、退出和股东分配；独立统计补充价格与资本结构。

Q2 AUM $1.346T、FRE $1.783B、DE $1.977B，DE每股 $1.52；过去 12 个月 DE $7.876B、DE每股 $6.15。Q2 募资 $68.3B、部署 $34.2B、退出 $31.8B。结论：**HOLD / 资产平台和募资能力强，但退出、私募信用和估值仍敏感；$105–120 更有安全边际。**

## 1. 最新业绩事实与关键问题

Blackstone 官方 Q2 披露，AUM同比增 11%，费生 AUM $961.6B；FRE $1.783B，同比增 22%，DE $1.977B，同比增 26%；Q2 分配股息 $1.29，每股 DE $1.52。总 AUM 增长来自 $68.3B 流入、$34.2B 部署和 $31.8B 实现。私募、房地产、信贷保险和多资产业务表现不同，不能只看总 AUM。

Blackstone 采用 DE 支付股息，GAAP 净利润受未实现收益和合并口径影响。长期价值取决于经常性管理费、客户留存、资产回报和退出市场；私募信贷的违约、估值和零售流动性是重要风险。

**段永平追问：**BX 的 DE增长是否能转化为长期每股价值，还是依赖退出市场、市场上涨和高额募资？

## 2. 财务趋势与商业本质

| 口径 | 数值 |
|---|---:|
| Q2 AUM / Fee-Earning AUM | 1,346.3 / 961.6 |
| Q2 FRE / DE | 1.783 / 1.977 |
| LTM DE / 每股 DE | 7.876 / $6.15 |
| LTM 收入 / 净利润 | 15.48 / 3.52 |
| 股息 / 收益率 | $4.74 / 3.71% |

BX 的商业本质是以全球房地产、私募股权、信贷、保险和多资产平台管理长期资本，收取管理费并分享业绩。护城河在品牌、募资、交易网络、资产规模和产品渠道；规模支持大型交易与永久资本，但也让退出和估值变得关键。

| 护城河 | 判断 | 趋势 |
|---|---|---|
| 全球募资与品牌 | 机构和财富渠道覆盖广 | 高 |
| 交易与资产平台 | 大型房地产、私募和信贷能力 | 高 |
| 永久资本 | 提高管理费可见度 | 中高 |
| 多策略组合 | 分散单一周期风险 | 中高 |
| 网络效应 | 交易、募资和人才形成网络 | 中高 |

**巴菲特追问：**在退出低迷和利率较高时，BX 仍能否用经常性管理费支撑股息和长期每股复利？

## 3. 护城河、管理层与逆向风险

管理层在募资、产品创新和资本部署方面优势突出，Q2 显示退出与流入均改善；但高分配率、合伙人份额、股本和债务口径需要持续监控。私募信用与房地产的底层资产质量不是 AUM 报表能完全揭示的。

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 退出市场冻结、DE下降 | 中 | 高 |
| 私募信用违约和估值减记 | 中高 | 高 |
| 房地产利率与出租率压力 | 中 | 高 |
| 零售渠道赎回或费率下降 | 中 | 中高 |
| 高分配和并购稀释每股价值 | 中 | 中高 |

空方会说股价一年跌约 27%，但 forward P/E 19.91x、P/FCF 35.9x仍不便宜；多头会说 AUM、FRE、DE和股息增长强。投资者最容易把 AUM和季度 DE当成永久利润，忽略 realizations 与市场周期。

**芒格追问：**如果未来三年退出收入和资产升值都低迷，FRE 是否足以维持分红与组织扩张？

## 4. 行业与长期趋势

养老金、保险资本、房地产再融资、基础设施和私募信贷支持另类资产需求；高利率、监管和流动性要求会淘汰低质量平台。BX 的长期优势是规模和募资品牌，长期风险是资本过度涌入、资产回报下降和低流动性产品赎回。

**李录追问：**BX 的长期复利来自长期资本和稀缺资产能力，还是来自资产价格与退出周期的顺风？

## 5. 股价与估值

2026-07-31 收盘价 $127.75；参与分配的普通股及单位折算约 1.244B。精确计算：$127.75 × 1.244B = **$158.92B**，与独立统计市值 $158.90B 接近。trailing P/E 28.60x、forward P/E 19.91x；LTM DE/股 $6.15，股息 $4.74/股、收益率约 3.71%。BX 应以 DE/FRE而非 GAAP EPS作为主要估值锚。

以 $6.15 LTM DE/股为基准，用 Decimal 计算 DE情景价值：

| 情景 | 假设（DE/股变化 / 终值DE倍数） | 每股价值 | 关键变量 |
|---|---|---:|---|
| 悲观 | -10% / 18x | $99.63 | 退出、信用和房地产承压 |
| 中性 | +10% / 22x | $148.83 | FRE、募资与退出恢复 |
| 乐观 | +15% / 25x | $176.81 | 永久资本、退出和高回报资产共振 |

现价低于中性但仍高于悲观安全区，$105–120 更适合分批研究。Q3 要看 FRE、DE、募资、退出和底层信用是否共同改善。

## 6. 四位大师视角与最终决策

巴菲特会看经常性管理费、资本分配和长期客户；芒格会分解 FRE、DE、未实现收益与退出收入；段永平会看分红和并购是否以合理价格执行；李录会把房地产、信用、养老金和资本周期放在长期框架。

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 | 全球另类资管平台强 | 高 |
| 护城河 | 品牌、募资、资产和交易网络高 | 高 |
| 管理层 | 执行强，周期与分配需跟踪 | 中高 |
| 最大风险 | 退出、信用、房地产和流动性 | 高 |
| 长期趋势 | 私募资本与实物资产需求支持 | 中高 |
| 估值 | 合理偏满 | 中高 |

| 策略 | 建议 |
|---|---|
| 空仓者 | 观望；$105–120 分批研究 |
| 持仓者 | 持有，跟踪 FRE、DE和底层资产质量 |
| 卖出信号 | FRE下降、DE分配失衡或信用恶化 |

综合决策：**HOLD / 另类资管平台等待安全边际**。AI 研究置信度高，投资确定性中高。
