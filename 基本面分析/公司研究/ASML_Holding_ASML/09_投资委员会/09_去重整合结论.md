# 09 去重整合结论：ASML（ASML）

## 双轨结论是否冲突

`investment-team` 与 `investment-research` 的核心判断一致：ASML 的商业质量和估值吸引力必须分开看。当前评级：**Hold**。

## 去重后的核心证据

| 维度 | 证据 | 投资含义 |
|---|---|---|
| 生意 | 客户是台积电、三星、英特尔、存储厂和先进制造厂。它们为 EUV/DUV 光刻机、维护服务和升级付费；ASML 的稀缺性来自光学、光源、精密机械、软件控制和供应链系统工程。 | 判断能否长期赚钱 |
| 护城河 | EUV 技术垄断、Carl Zeiss 等供应链绑定、客户工艺认证和几十年系统工程经验。护城河极深，但地缘政治决定可卖市场。 | 判断利润能否留住 |
| 管理层 | Christophe Fouquet 需要在需求扩产、组织效率和地缘政治限制之间平衡。公司回购计划和产能扩张显示中长期信心。 | 判断资本能否托付 |
| 财务 | FY2026 Q2 总净销售 EUR 9.3bn，毛利率 54.0%，净利润 EUR 2.9bn；公司提高 2026 展望至总净销售 EUR 43-45bn、毛利率 54%-56%。2025 年总净销售 EUR 32.7bn、毛利率 52.8%、basic EPS EUR 24.73。 | 判断 thesis 是否被强化 |
| 估值 | 当前 US$1582.95，买入区间 US$1050-1250，或 EUR 口径前瞻 PE 回到 25-30x | 判断是否有安全边际 |

## 投资委员会最终问题

1. 买入理由：好生意、护城河和长期现金流。
2. 最大风险：中国 DUV 国产化和出口限制。
3. 当前价格是否合理：Hold。
4. 可以买的情况：进入买入区间且 thesis 未破坏。
5. 不能买的情况：只因热门叙事或短期上涨买入。
6. 必须卖的情况：护城河变窄、现金流恶化、管理层失信。
7. 仓位：观察或轻仓研究，除非价格给出足够安全边际。
