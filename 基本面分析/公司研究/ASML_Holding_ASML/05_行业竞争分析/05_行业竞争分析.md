# 05 行业竞争分析：ASML（ASML）

## 价值链位置

AI、先进封装和先进制程推动光刻需求；但半导体设备天然周期性强，且被地缘政治直接影响。 的利润池通常流向拥有客户关系、技术壁垒、品牌、数据、分销或规模效率的一方。ASML 的位置是：客户是台积电、三星、英特尔、存储厂和先进制造厂。它们为 EUV/DUV 光刻机、维护服务和升级付费；ASML 的稀缺性来自光学、光源、精密机械、软件控制和供应链系统工程。

## 行业结构

| 维度 | 判断 |
|---|---|
| TAM | 长期空间存在，但不能直接等同公司收入 |
| 行业增速 | 取决于宏观、技术周期和客户预算 |
| 竞争对手 | 强竞争存在，需看差异化是否持续 |
| 供应商议价权 | 对毛利率和交付稳定性有影响 |
| 客户议价权 | 大客户集中时尤其重要 |
| 替代技术 | 客户集中于少数晶圆厂 |

## 竞争优势

EUV 技术垄断、Carl Zeiss 等供应链绑定、客户工艺认证和几十年系统工程经验。护城河极深，但地缘政治决定可卖市场。

## 核心问题

这家公司不是只要行业增长就一定赚钱。巴菲特式问题是：行业变好以后，利润池由谁拿走？段永平式问题是：客户为什么不用别人家的东西？
