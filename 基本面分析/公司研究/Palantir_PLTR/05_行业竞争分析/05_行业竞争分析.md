# 05 行业竞争分析：Palantir（PLTR）

## 价值链位置

AI 应用软件仍早期，真正稀缺的是把模型接入真实组织流程并产生审计结果的能力。Palantir 处于好赛道，但市场已经充分奖励。 的利润池通常流向拥有客户关系、技术壁垒、品牌、数据、分销或规模效率的一方。Palantir 的位置是：政府客户为情报、国防、执法和安全场景的数据融合付费；商业客户为 Foundry/AIP 带来的流程自动化、AI 决策和运营效率付费。Palantir 的模式更像高接触部署的软件平台，不是完全自助式 SaaS。

## 行业结构

| 维度 | 判断 |
|---|---|
| TAM | 长期空间存在，但不能直接等同公司收入 |
| 行业增速 | 取决于宏观、技术周期和客户预算 |
| 竞争对手 | 强竞争存在，需看差异化是否持续 |
| 供应商议价权 | 对毛利率和交付稳定性有影响 |
| 客户议价权 | 大客户集中时尤其重要 |
| 替代技术 | 高接触交付限制规模化 |

## 竞争优势

任务关键场景、部署深度、数据模型、客户信任和工程师嵌入形成转换成本。护城河在扩宽，但欧洲主权替代、开源/大模型平台和客户自建是反方重点。

## 核心问题

这家公司不是只要行业增长就一定赚钱。巴菲特式问题是：行业变好以后，利润池由谁拿走？段永平式问题是：客户为什么不用别人家的东西？
