# 05 行业竞争分析：万豪酒店（MAR）

## 价值链位置

全球旅游长期恢复、体验消费和高端酒店需求支持增长，但酒店需求高度周期化。利润池更多流向品牌和分销平台，而非单体物业业主。 的利润池通常流向拥有客户关系、技术壁垒、品牌、数据、分销或规模效率的一方。万豪酒店 的位置是：酒店业主出资本建酒店，万豪提供品牌、预订系统、会员流量、运营标准和管理能力，并收取基本管理费、激励管理费、特许经营费和授权费。

## 行业结构

| 维度 | 判断 |
|---|---|
| TAM | 长期空间存在，但不能直接等同公司收入 |
| 行业增速 | 取决于宏观、技术周期和客户预算 |
| 竞争对手 | 强竞争存在，需看差异化是否持续 |
| 供应商议价权 | 对毛利率和交付稳定性有影响 |
| 客户议价权 | 大客户集中时尤其重要 |
| 替代技术 | 高端酒店竞争 |

## 竞争优势

品牌组合、Bonvoy 会员、全球分销、业主管理经验和规模采购。护城河强于普通酒店资产，但弱于真正垄断型科技平台。

## 核心问题

这家公司不是只要行业增长就一定赚钱。巴菲特式问题是：行业变好以后，利润池由谁拿走？段永平式问题是：客户为什么不用别人家的东西？
