# 05 行业竞争分析：苹果（AAPL）

## 价值链位置

智能手机进入成熟周期，但高端机、服务订阅、端侧 AI、支付和健康设备仍能带来利润池。行业增长不快，苹果胜在用户价值密度和生态留存。 的利润池通常流向拥有客户关系、技术壁垒、品牌、数据、分销或规模效率的一方。苹果 的位置是：苹果卖的不只是 iPhone、Mac、iPad 和可穿戴设备，而是一个软硬件一体化生态。客户为顺滑体验、隐私、安全、品牌和跨设备协同付费；开发者、广告主和内容方则为 App Store、支付和分发能力付费。

## 行业结构

| 维度 | 判断 |
|---|---|
| TAM | 长期空间存在，但不能直接等同公司收入 |
| 行业增速 | 取决于宏观、技术周期和客户预算 |
| 竞争对手 | 强竞争存在，需看差异化是否持续 |
| 供应商议价权 | 对毛利率和交付稳定性有影响 |
| 客户议价权 | 大客户集中时尤其重要 |
| 替代技术 | AI 端侧体验若落后会削弱高端换机理由 |

## 竞争优势

品牌、生态转换成本、软硬件集成、开发者生态和供应链规模叠加。护城河仍宽，但监管对 App Store 抽成和默认设置的压力正在削弱一部分服务利润池。

## 核心问题

这家公司不是只要行业增长就一定赚钱。巴菲特式问题是：行业变好以后，利润池由谁拿走？段永平式问题是：客户为什么不用别人家的东西？
