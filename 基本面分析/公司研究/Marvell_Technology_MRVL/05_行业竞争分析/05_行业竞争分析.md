# 05_行业竞争分析

## 价值链位置

AI 数据中心的价值链可以简化为：算力芯片、内存、网络交换、光电互联、服务器/ODM、电力冷却、云服务。Marvell 不在利润最高的 GPU 核心位置，但在“让更多芯片组成更大系统”的互联和定制芯片位置。

| 环节 | 代表公司 | MRVL 相关性 |
|---|---|---|
| GPU / accelerator | NVIDIA、AMD、自研 ASIC | 既是生态受益者，也可能被垂直整合压制 |
| Custom ASIC | Broadcom、Marvell、部分自研团队 | MRVL 核心战场 |
| Ethernet / switch | Broadcom、Marvell、NVIDIA、Arista | MRVL 参与芯片层 |
| Optical / DSP | Marvell、Broadcom、Credo、Coherent、Lumentum | MRVL 重要战场 |
| PCIe / CXL | Astera Labs、XConn/Marvell、Broadcom | XConn 强化该方向 |
| Storage controller | Marvell、Phison、Silicon Motion | MRVL 传统能力 |

## 竞争格局

| 对手 | 强项 | 对 MRVL 的压力 |
|---|---|---|
| Broadcom | custom ASIC、交换芯片、客户关系、规模 | 最大直接竞争者，利润池控制力强 |
| NVIDIA | GPU 生态、NVLink/InfiniBand/Ethernet、系统控制 | 可能把互联价值内化到自家生态 |
| AMD / Intel | accelerator + networking / x86生态 | 对 custom silicon 和平台整合构成替代 |
| Credo / Astera | 高速连接细分、PCIe/CXL、低功耗互联 | 在细分环节抢份额和估值叙事 |
| Arista | 数据中心网络系统层 | 不是芯片直竞，但影响客户网络架构选择 |

## 行业趋势

1. AI 集群从单机架扩展到多机架、多数据中心，互联带宽和功耗成为瓶颈。
2. hyperscaler 自研芯片趋势增强，custom silicon 需求上升。
3. 光互联向 800G、1.6T、CPO、LPO、silicon photonics 演进。
4. 网络架构存在 Ethernet、InfiniBand、NVLink 等路线竞争。
5. 若推理成本大幅下降或模型架构变轻，AI capex 增速可能回落。

## 结论

行业确实在变大，但价值捕获并不平均。MRVL 的机会在于“非 GPU 但不可或缺”的互联和定制芯片；风险在于 Broadcom 与 NVIDIA 更靠近大客户和系统控制点。
