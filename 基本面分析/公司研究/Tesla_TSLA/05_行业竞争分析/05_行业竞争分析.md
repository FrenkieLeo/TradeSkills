# 05 行业竞争分析：特斯拉（TSLA）

## 价值链位置

电动车渗透继续提高，但汽车行业竞争和资本密集属性没有消失。AI 机器人和自动驾驶可能是文明级机会，但投资上必须区分愿景和可分配现金流。 的利润池通常流向拥有客户关系、技术壁垒、品牌、数据、分销或规模效率的一方。特斯拉 的位置是：短期靠汽车销售、监管积分、能源存储、服务和软件变现；长期叙事押注自动驾驶网络、机器人和 AI 基础设施。客户为电动车体验、品牌、充电网络和软件能力付费。

## 行业结构

| 维度 | 判断 |
|---|---|
| TAM | 长期空间存在，但不能直接等同公司收入 |
| 行业增速 | 取决于宏观、技术周期和客户预算 |
| 竞争对手 | 强竞争存在，需看差异化是否持续 |
| 供应商议价权 | 对毛利率和交付稳定性有影响 |
| 客户议价权 | 大客户集中时尤其重要 |
| 替代技术 | 高 capex 造成持续负 FCF |

## 竞争优势

品牌、充电网络、制造经验和软件数据是优势；但电动车本身竞争显著加剧，真正决定估值的是 FSD/Robotaxi 是否从功能演示变成高毛利现金流。

## 核心问题

这家公司不是只要行业增长就一定赚钱。巴菲特式问题是：行业变好以后，利润池由谁拿走？段永平式问题是：客户为什么不用别人家的东西？
