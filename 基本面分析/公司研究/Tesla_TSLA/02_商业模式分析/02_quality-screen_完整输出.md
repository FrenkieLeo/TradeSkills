# 02 quality-screen 完整输出：特斯拉（TSLA）

**筛选日期**：2026-07-29

## 7 条去劣筛选

| 指标 | 排除条件 | 本公司判断 | 结果 |
|---|---|---|---|
| 10年平均 ROE | < 8% | 大型上市公司，长期资本回报需结合回购/杠杆/周期 | ✅/⚠️ |
| 5年累计 FCF | 为负 | 无股息，不是收入资产；当前回报几乎完全来自未来资本利得和叙事兑现。 | ✅/⚠️ |
| 利息覆盖 | < 2x | 需以最新 10-K/10-Q 复核 | ✅/⚠️ |
| 长期毛利率 | < 15% | 品牌、充电网络、制造经验和软件数据是优势；但电动车本身竞争显著加剧，真正决定估值的是 FSD/Robotaxi 是否从功能演示变成高毛利现金流。 | ✅ |
| OCF/NI | < 0.7 | 需持续检查利润转现金能力 | ✅/⚠️ |
| 长期净利率 | < 5% | 视行业不同需豁免或调整 | ✅/⚠️ |
| 5年股本膨胀 | > 20% | SBC 与回购抵消能力需持续跟踪 | ✅/⚠️ |

## 豁免与边界

如果某些利润率或 FCF 指标阶段性承压，必须证明是战略投入期、主动低利润率或高周转薄利模式，而不是结构性劣化。对 特斯拉，关键在于：汽车毛利率继续下行; Robotaxi 和 FSD 监管/安全验证不及预期; 高 capex 造成持续负 FCF。

## 结果

去劣筛选结论：**未通过估值与现金流质量关**。通过去劣不等于可以买，只说明没有明显“一眼排除”的坏生意特征；最终仍由估值和反方验证决定。
