# 02_商业模式分析/02_商业模式分析.md

# 02 商业模式分析：亚马逊（AMZN）

## 一句话说清楚怎么赚钱

消费者为低价、选择、配送速度和 Prime 权益付费；商家为流量、仓储履约和广告转化付费；企业客户为 AWS 的计算、存储、数据库和 AI 服务付费。

## 谁付钱，为什么付钱

| 付费方 | 购买内容 | 付费原因 | 是否重复 |
|---|---|---|---|
| 核心客户 | 主产品/服务 | 解决关键业务或消费需求 | 是，取决于切换成本和复购 |
| 生态伙伴 | 平台、渠道、服务或技术能力 | 获得分发、效率或确定性 | 是 |
| 股东视角 | FCF、回购、分红和再投资 | 现金流复利 | 取决于资本配置 |

## 这是不是好生意

规模经济、Prime 会员习惯、物流密度、第三方卖家网络、广告闭环和 AWS 技术生态叠加。护城河仍在，但 AI 资本开支让 FCF 质量短期承压。

段永平式判断：好生意不是“故事大”，而是客户愿意持续付钱，公司还能保留一部分利润，并且不需要永远烧钱才能维持竞争力。亚马逊 的核心变量是：收入增长、利润率、FCF 转化、资本开支强度、客户/监管风险和估值。

## 专业名词解释

- **AWS**：Amazon Web Services，云计算平台，是亚马逊利润池核心。
- **履约网络**：仓库、物流、配送、库存和算法系统，规模越大单位成本越低。
- **FCF**：经营现金流减资本开支，AI capex 上升会压低短期 FCF。

## 假护城河检查

| 风险 | 为什么可能是假护城河 |
|---|---|
| AI 基建投入过大导致 FCF 长期低于利润 | 对收入、利润率、估值或护城河形成压力 |
| AWS 竞争加剧和价格压力 | 对收入、利润率、估值或护城河形成压力 |
| 反垄断监管 | 对收入、利润率、估值或护城河形成压力 |
| 零售劳动成本与物流资本开支 | 对收入、利润率、估值或护城河形成压力 |

## 结论

商业模式评分：★★★★★。亚马逊 的生意质量总体较高，但最终投资结论不能只看生意质量，还必须看价格。
