# 04 盈利持续性评分：亚马逊（AMZN）

| 维度 | 评分 | 解释 |
|---|---|---|
| 收入重复性 | ★★★★☆ | 消费者为低价、选择、配送速度和 Prime 权益付费；商家为流量、仓储履约和广告转化付费；企业客户为 AWS 的计算、存储、数据库和 AI 服务付费。 |
| 定价权 | ★★★★★ | 规模经济、Prime 会员习惯、物流密度、第三方卖家网络、广告闭环和 AWS 技术生态叠加。护城河仍在，但 AI 资本开支让 FCF 质量短期承压。 |
| FCF 可持续性 | ★★★★☆ | 无常规股息，不适合传统收入投资；股东回报主要依赖再投资复利和长期 FCF 释放。 |
| 资本开支压力 | ★★★☆☆ | 行业和增长阶段决定 capex 强度 |
| 周期敏感度 | ★★★☆☆ | 需在持续跟踪看板中观察 |

## 结论

盈利持续性不是看单季利润，而是看客户需求是否重复、价格是否有弹性、成本是否可控、现金是否留得住。亚马逊 的核心跟踪变量是：AI 基建投入过大导致 FCF 长期低于利润; AWS 竞争加剧和价格压力; 反垄断监管。
