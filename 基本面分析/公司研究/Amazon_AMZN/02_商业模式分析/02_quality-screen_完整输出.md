# 02 quality-screen 完整输出：亚马逊（AMZN）

**筛选日期**：2026-07-29

## 7 条去劣筛选

| 指标 | 排除条件 | 本公司判断 | 结果 |
|---|---|---|---|
| 10年平均 ROE | < 8% | 大型上市公司，长期资本回报需结合回购/杠杆/周期 | ✅/⚠️ |
| 5年累计 FCF | 为负 | 无常规股息，不适合传统收入投资；股东回报主要依赖再投资复利和长期 FCF 释放。 | ✅/⚠️ |
| 利息覆盖 | < 2x | 需以最新 10-K/10-Q 复核 | ✅/⚠️ |
| 长期毛利率 | < 15% | 规模经济、Prime 会员习惯、物流密度、第三方卖家网络、广告闭环和 AWS 技术生态叠加。护城河仍在，但 AI 资本开支让 FCF 质量短期承压。 | ✅ |
| OCF/NI | < 0.7 | 需持续检查利润转现金能力 | ✅/⚠️ |
| 长期净利率 | < 5% | 视行业不同需豁免或调整 | ✅/⚠️ |
| 5年股本膨胀 | > 20% | SBC 与回购抵消能力需持续跟踪 | ✅/⚠️ |

## 豁免与边界

如果某些利润率或 FCF 指标阶段性承压，必须证明是战略投入期、主动低利润率或高周转薄利模式，而不是结构性劣化。对 亚马逊，关键在于：AI 基建投入过大导致 FCF 长期低于利润; AWS 竞争加剧和价格压力; 反垄断监管。

## 结果

去劣筛选结论：**通过**。通过去劣不等于可以买，只说明没有明显“一眼排除”的坏生意特征；最终仍由估值和反方验证决定。
