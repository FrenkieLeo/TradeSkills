# 05 行业竞争分析：科磊（KLAC）

## 价值链位置

AI、先进逻辑、HBM 和先进封装提升检测步骤和复杂度。价值链中，过程控制设备是高毛利、少数寡头的关键环节。 的利润池通常流向拥有客户关系、技术壁垒、品牌、数据、分销或规模效率的一方。科磊 的位置是：客户是晶圆厂、存储厂和先进封装厂。它们为更高良率、更快爬坡、更低缺陷率付费；KLA 的设备价值不在机器本身，而在工艺数据、算法和长期服务关系。

## 行业结构

| 维度 | 判断 |
|---|---|
| TAM | 长期空间存在，但不能直接等同公司收入 |
| 行业增速 | 取决于宏观、技术周期和客户预算 |
| 竞争对手 | 强竞争存在，需看差异化是否持续 |
| 供应商议价权 | 对毛利率和交付稳定性有影响 |
| 客户议价权 | 大客户集中时尤其重要 |
| 替代技术 | 客户集中度 |

## 竞争优势

技术积累、算法/数据、客户认证、装机服务网络和工艺节点绑定。护城河深，但半导体 capex 周期会让订单波动。

## 核心问题

这家公司不是只要行业增长就一定赚钱。巴菲特式问题是：行业变好以后，利润池由谁拿走？段永平式问题是：客户为什么不用别人家的东西？
