# 09_去重整合结论

## 双轨结论是否冲突

`investment-team` 与 `investment-research` 结论一致：台积电是极高质量公司，但当前价格不提供充足安全边际，评级为 **Hold / Watchlist**。

## 去重后的投资委员会结论

| 问题 | 结论 |
|---|---|
| 买入理由 | 先进制程、良率、客户生态、规模、先进封装共同构成深护城河 |
| 最大风险 | AI 需求过热、CapEx 过度、地缘风险、海外扩产拖累 ROIC |
| 当前价格是否合理 | 对质量而言合理，对安全边际而言不足 |
| 什么情况下可以买 | 股价回落到 ADR US$280-320 且 thesis 未破坏 |
| 什么情况下不能买 | 只因为 AI 热度、股价创新高或市场共识追高 |
| 什么情况下必须卖 | 先进节点份额丢失、毛利率结构性下滑、客户大规模转单、地缘风险不可控 |
| 适合仓位 | 适合轻仓/中仓长期核心跟踪，不适合无安全边际重仓追高 |
| 未来 3 年指标 | 2nm ramp、HPC/AI 收入、先进封装产能、毛利率、CapEx/FCF、客户 CapEx |

## 最终评级

**Hold / Watchlist**。

台积电是值得长期跟踪的世界级公司，但投资动作应该由价格纪律驱动，而不是由“它很强”这个事实驱动。
