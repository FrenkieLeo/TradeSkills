# 05 行业竞争分析：博通（AVGO）

## 价值链位置

AI 网络、定制芯片、以太网交换和企业私有云改造是大趋势。利润池由拥有 IP、客户关系和供应链能力的少数厂商捕获。 的利润池通常流向拥有客户关系、技术壁垒、品牌、数据、分销或规模效率的一方。博通 的位置是：客户包括超大云厂商、网络设备商、服务器/存储厂商和大型企业软件客户。半导体卖的是高性能、低功耗、可定制和供应确定性；软件卖的是虚拟化、私有云和基础设施管理的锁定。

## 行业结构

| 维度 | 判断 |
|---|---|
| TAM | 长期空间存在，但不能直接等同公司收入 |
| 行业增速 | 取决于宏观、技术周期和客户预算 |
| 竞争对手 | 强竞争存在，需看差异化是否持续 |
| 供应商议价权 | 对毛利率和交付稳定性有影响 |
| 客户议价权 | 大客户集中时尤其重要 |
| 替代技术 | 高估值对增速放缓敏感 |

## 竞争优势

客户共同设计、专用芯片能力、规模采购、IP 组合、软件迁移成本和 Hock Tan 的并购整合纪律。护城河强，但 AI ASIC 客户集中度和并购债务需要盯紧。

## 核心问题

这家公司不是只要行业增长就一定赚钱。巴菲特式问题是：行业变好以后，利润池由谁拿走？段永平式问题是：客户为什么不用别人家的东西？
