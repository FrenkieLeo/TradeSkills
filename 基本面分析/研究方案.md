# 公司基本面研究方案

## 1. 研究目标

建立一套从数据验证、商业分析、行业竞争、管理层、估值、投资论文、反方校验到持续跟踪的公司基本面研究流程。该流程适用于单家公司深度研究，也适用于行业内多家公司横向比较。

核心问题：

- 这家公司如何赚钱，增长来自哪里，利润率和现金流是否可持续？
- 公司所在行业的结构、周期、竞争格局和关键变量是什么？
- 管理层是否可信、资本配置是否有效、激励是否与股东一致？
- 当前价格是否提供足够安全边际和合理的风险收益比？
- 哪些事实会证明投资论文错误，后续如何持续跟踪？

## 2. 阶段一：数据收集与交叉验证

使用 skills：`financial-data`、`yfinance-data`、`funda-data`、`fintel-data`

主要任务：

- 获取收入、毛利、营业利润、净利润、EPS、自由现金流、资产负债表和现金流量表数据。
- 拉取股价、市值、企业价值、估值倍数、分红和回购数据。
- 汇总机构持仓、空头数据、内部人交易和关键披露。
- 对同一指标至少使用两个来源交叉验证，记录差异和可能原因。

阶段产出：

- 标准化财务表。
- 数据来源索引。
- 异常值和口径差异说明。

质量门槛：

- 关键财务指标不能只依赖单一数据源。
- 必须标注最近一个财报期和 TTM 口径。
- 对一次性项目、会计变更、并购剥离影响做单独说明。

## 3. 阶段二：商业与基本面分析

使用 skills：`stock-eval`、`fundamental-analysis`、`financial-report-analyst`、`10k-digest`

主要任务：

- 拆解收入来源、客户结构、产品线、地区分布和增长驱动。
- 分析毛利率、费用率、经营杠杆、资本开支和营运资本变化。
- 阅读 10-K、10-Q、年报和管理层讨论，提取关键经营指标。
- 判断商业模式类型：订阅、交易、硬件、服务、平台、资源品、金融等。

阶段产出：

- 商业模式画布。
- 三表质量分析。
- 关键经营指标清单。
- 过去 3-5 年经营趋势。

质量门槛：

- 能用一句话解释公司如何赚钱。
- 能解释收入增长和利润增长是否来自同一驱动。
- 能指出现金流和利润之间的主要差异。

## 4. 阶段三：行业与竞争分析

使用 skills：`industry-map`、`industry-research`、`industry-funnel`、`competitor-analysis`

主要任务：

- 明确行业价值链、上游供应、下游客户和替代品。
- 估算 TAM、SAM、SOM，并区分真实市场扩张与口径包装。
- 建立主要竞争对手列表，比较规模、增长、利润率、技术、渠道和资产效率。
- 判断行业结构：集中度、进入壁垒、价格权力、监管、周期性和技术变迁。

阶段产出：

- 行业地图。
- 竞争对手矩阵。
- 行业关键变量清单。
- 公司护城河与脆弱点分析。

质量门槛：

- 不能只用公司口径定义市场空间。
- 至少包含 3 个直接竞争者或替代路径。
- 明确行业增长来自量、价、渗透率、周期还是监管变化。

## 5. 阶段四：管理层深度研究

使用 skill：`management-deep-dive`

主要任务：

- 梳理 CEO、CFO、董事会和关键业务负责人的履历。
- 分析历史承诺兑现率、资本配置、并购、回购、分红和股权激励。
- 阅读近年 earnings call，观察管理层对逆风、竞争和资本纪律的表达。
- 检查关联交易、治理结构、双重股权、内部人买卖和薪酬激励。

阶段产出：

- 管理层评分卡。
- 资本配置历史。
- 激励与股东一致性判断。

质量门槛：

- 必须包含具体历史行为证据。
- 区分管理层叙事能力和经营兑现能力。

## 6. 阶段五：估值与情景分析

使用 skills：`dcf-valuation`、`stock-valuation`、`company-valuation`

主要任务：

- 建立收入、利润率、税率、资本开支、营运资本和 WACC 假设。
- 使用 DCF、可比公司、历史倍数和反向 DCF 交叉验证。
- 设计 bear/base/bull 三种情景，明确每种情景的业务假设。
- 计算安全边际、预期收益、下行风险和关键敏感性。

阶段产出：

- 估值模型摘要。
- 情景分析表。
- 敏感性分析。
- 当前价格隐含预期。

质量门槛：

- 估值假设必须能回扣到业务和行业判断。
- 必须说明市场当前价格隐含了什么增长与利润率。
- 不允许只用单一估值倍数得出结论。

## 7. 阶段六：投资论文与团队审阅

使用 skills：`investment-research`、`investment-team`、`investment-checklist`

主要任务：

- 写出清晰的投资论文、关键假设、风险、催化剂和退出条件。
- 用投资 checklist 检查数据、业务、行业、管理层、估值和风险遗漏。
- 组织团队审阅，记录分歧点和需要补充验证的问题。

阶段产出：

- 投资论文草案。
- 审阅问题列表。
- 结论置信度评分。

质量门槛：

- 论文必须可证伪。
- 必须写明哪些事实出现后应降低仓位或退出。

## 8. 阶段七：反方与结果校验

使用 skills：`bear-case`、`result-validator`

主要任务：

- 主动构建反方观点，寻找最强的反对证据。
- 检查数据引用、估值公式、时间口径和逻辑链条。
- 识别确认偏误、叙事过拟合、短期噪音和遗漏变量。

阶段产出：

- Bear case 清单。
- 校验报告。
- 需要返工的假设列表。

质量门槛：

- 每个核心买入理由至少对应一个可跟踪的反证指标。
- 定稿前必须解决高优先级校验问题。

## 9. 阶段八：报告生成

使用 skills：`investment-memo-craft`、`full-report`、`report-generator`、`chart-master`

主要任务：

- 生成投资备忘录、完整报告和图表。
- 图表优先展示驱动因素，而不是堆砌指标。
- 报告结论需区分事实、假设、判断和行动建议。

阶段产出：

- 投资备忘录。
- 完整研究报告。
- 关键图表包。

质量门槛：

- 图表必须有标题、口径、时间区间和来源。
- 报告首页应直接呈现结论、估值区间、主要风险和下一步跟踪事项。

## 10. 阶段九：持续跟踪

使用 skills：`earnings-preview`、`earnings-review`、`earnings-recap`、`earnings-call-analysis`、`estimate-analysis`、`catalyst-calendar`、`news-pulse`、`thesis-tracker`、`thesis-drift`

主要任务：

- 财报前更新预期、关键指标和市场关注点。
- 财报后比较实际结果、管理层指引和原投资论文。
- 跟踪分析师预期变化、新闻、催化剂和竞争动态。
- 定期检查 thesis drift，判断观点是否被事实侵蚀。

阶段产出：

- 财报预览。
- 财报复盘。
- 催化剂日历。
- Thesis tracker。

质量门槛：

- 每次重大事件后更新原始投资论文。
- 不能只记录新闻，必须判断其对核心假设的影响。

## 11. 市场与组合维度

使用 skills：`technical-analysis`、`sector-analysis`、`economics-analysis`、`options-analysis`、`stock-liquidity`、`portfolio-review`

主要任务：

- 检查技术趋势、流动性、期权定价和市场情绪。
- 分析宏观、利率、行业轮动和风格因子对估值的影响。
- 将单家公司结论放入组合语境，评估相关性、仓位和风险暴露。

阶段产出：

- 市场环境摘要。
- 流动性与交易风险评估。
- 组合适配建议。

质量门槛：

- 市场信号不替代基本面结论，只用于入场节奏和仓位管理。
- 必须说明该标的在组合中的角色。
