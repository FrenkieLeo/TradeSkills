# 第七阶段：行业竞争与利润池

## 市场位置

公开可比统计显示，CY2025 Q2 AI加速器收入份额约为：NVIDIA 85.2%、Broadcom定制ASIC 10.3%、Marvell 2.1%、AMD 1.8%、其他0.5%。若计入Google TPU、AWS Trainium、Microsoft Maia和Meta MTIA，英伟达占全部AI加速器的合理估算约75%—85%；该数值是行业估算，不是审计数据。

## 竞争路线

| 竞争者 | 最可能替代的负载 | 威胁 |
|---|---|---|
| AMD Instinct/Helios | 通用训练、价格敏感推理 | 高 |
| Google TPU | Google内部及Google栈客户 | 高但集中 |
| AWS Trainium | AWS内部与Bedrock客户 | 很高 |
| Broadcom定制ASIC | 超大规模稳定负载 | 很高 |
| Microsoft Maia / Meta MTIA | 内部推理、广告和推荐 | 局部高 |
| 华为昇腾 | 中国政企与主权AI | 中国市场很高 |
| Cerebras | 低延迟Decode | 小而值得监测 |

## 核心判断

GPU份额下降的概率高于英伟达绝对收入下降的概率。英伟达可通过NVLink Fusion、Spectrum-X、InfiniBand、CPU/DPU、系统和软件提高每座AI工厂的钱包份额。未来必须同时观察GPU份额和网络、互连、系统收入能否补回失去的利润池。

AI长期发展并不意味着利润永远由同一家公司获取。稳定推理更可能流向定制ASIC；晶圆和封装利润流向TSMC；HBM利润流向SK hynix、Micron与Samsung；云服务利润流向Microsoft、AWS、Google和Oracle。
