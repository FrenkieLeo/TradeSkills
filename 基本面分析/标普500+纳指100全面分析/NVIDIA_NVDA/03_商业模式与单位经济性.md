## 六层平台

| 层级 | 产品 | 客户价值 |
|---|---|---|
| 处理器 | GPU、Grace/Vera CPU、BlueField DPU | 执行AI计算和数据处理 |
| 机内互连 | NVLink、NVSwitch | 让多颗GPU低延迟协同 |
| 集群网络 | InfiniBand、Spectrum-X、ConnectX | 提高GPU利用率、减少通信等待 |
| 系统 | HGX、DGX、GB200/GB300 NVL72 | 缩短部署、验证和交付时间 |
| 软件 | CUDA、TensorRT、Dynamo、NIM、NeMo | 降低开发、迁移和推理成本 |
| 行业平台 | DRIVE、Isaac、Omniverse、BioNeMo | 把通用计算转为行业方案 |

商业演进路径：卖芯片 → 卖板卡 → 卖服务器平台 → 卖整机架 → 卖AI工厂架构。

## 客户单位经济性

客户关注：

\[
\text{单位Token成本}
=
\frac{\text{硬件折旧+电力+网络+机房+运维}}
{\text{有效Token产量}}
\]

便宜50%的芯片，如果软件不成熟、利用率低、调试时间长，最终TCO可能更高。英伟达的定价权来自缩短训练时间、降低延期风险、提高每兆瓦Token产量、降低迁移与运维成本，以及更快让AI服务上线。

## 关键名词

| 概念 | 通俗解释 | 投资意义 |
|---|---|---|
| GPU | 可编程的大规模并行处理器 | 适应快速变化的模型 |
| ASIC | 为固定任务定制的专用芯片 | 稳定推理中可能更省电、更便宜 |
| CUDA | 编译器、库、运行时和工具组成的软件生态 | 构成开发者生态与转换成本 |
| NVLink | GPU之间的高速通信技术 | 决定大型模型的多GPU效率 |
| HBM | GPU旁的高带宽内存 | 核心交付瓶颈 |
| CoWoS | 先进封装技术 | 决定GPU与HBM能否大规模集成 |
