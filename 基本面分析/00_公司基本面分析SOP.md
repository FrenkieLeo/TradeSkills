# 公司基本面分析 SOP

版本：v1.1  
更新日期：2026-07-28  
适用范围：`基本面分析/公司研究/` 下所有公司研究  
优先原则：公司研究优先调用 ai-berkshire 系列 skills；只有当 ai-berkshire 没有覆盖某项能力时，才使用其他工具或通用分析补位。

## 一、目标

本 SOP 用于把公司研究从“临时写一篇报告”升级成可复用、可追踪、可复盘的研究系统。每家公司最终必须回答四个问题：

1. 这家公司到底靠什么赚钱？
2. 它未来还能不能持续赚钱？
3. 管理层是否值得托付资本？
4. 当前价格是否提供足够安全边际？

最终结论必须明确落到：Buy / Hold / Watchlist / Avoid / Sell。

## 二、总原则

1. 先事实，后观点。
2. 先商业，后估值。
3. 先现金流，后故事。
4. 先反方验证，再下结论。
5. 研究不是为了证明可以买，而是为了判断是否值得买。
6. 好公司不一定是好股票，价格永远重要。
7. 管理层不只看他说什么，更要看他兑现了什么。
8. 买入后必须持续跟踪 thesis 是否漂移。
9. 优先使用 ai-berkshire skills，且必须保留各 skill 的完整输出（特别是investment-research，investment-team，earnings-review，investment-checklist必须毫无保留完整输出）。
10. 除非用户明确要求简版，否则所有报告默认写成完整研究档案，不限制在一页纸。
11. 报告必须解释分析思路，不能只给结论。
12. 涉及商业模式、半导体、软件、金融、会计、产业链等专业名词时，必须解释概念、商业含义和应用场景。
13. 分析视角必须结合巴菲特和段永平的投资思维：用现金流、护城河、好生意、好价格、能力圈、管理层诚信和长期可持续性来做判断，估值的时候需要借鉴巴菲特的估值思想还有段永平的毛估估计算。
14. 所有数据必须标注来源；关键财务与估值数据必须交叉验证，来源冲突时优先使用公司公告、SEC/交易所披露、年报/季报原文。

## 五、执行流程

### 第一阶段：基础数据层 + 财报精读

目标：先建立事实底座，避免一开始就讲故事。  
优先使用：`financial-data`、`yfinance-data`、`funda-data`、`fintel-data`、`earnings-review`。  
输出目录：`03_财务质量/`。

强制要求：

1. 在获取到公司最新年报、季报、10-K、10-Q、8-K、业绩电话会纪要或投资者材料后，必须使用 `earnings-review` 进行财报精读。
2. `earnings-review` 的输出必须完整保存为 `03_earnings-review_完整输出.md`。
3. 不允许只摘录结论；必须保留该 skill 输出中的核心数据速览、管理层讨论、承诺追踪、附注信息、Q&A 精选、投资论文影响和数据抽检记录。
4. 财务质量分析文件可以在 `earnings-review` 基础上二次分析，但不得替代原始 skill 输出。

必须覆盖：

| 模块 | 必须分析 |
|---|---|
| 损益表 | 收入、毛利、毛利率、经营利润、经营利润率、净利润、EPS |
| 现金流 | CFO、CapEx、FCF、回购、分红、FCF/净利润 |
| 资产负债表 | 现金、短期投资、有息负债、净债务、商誉、无形资产 |
| 股东回报 | SBC、股权稀释、回购抵消稀释的能力 |
| 经营质量 | 应收、存货、递延收入、客户集中度、供应链风险 |
| 数据验证 | 公司原始披露 + 至少一个独立第三方来源交叉验证 |
| 资本回报 | ROE，ROA，ROIC多年的数据 |

核心问题：

> 过去赚到的钱是真钱、好钱，还是会计利润？这份最新财报强化、削弱还是推翻了投资 thesis？

### 第二阶段：商业模式理解 + 买入前质量检验

目标：搞懂公司卖什么、卖给谁、凭什么赚钱，然后立刻用价值投资标准排雷。  
优先使用：`stock-eval`、`fundamental-analysis`、`financial-report-analyst`、`10k-digest`、`investment-checklist`、`quality-screen`。  
输出目录：`02_商业模式分析/`、`04_盈利持续性分析/`。

强制要求：

1. 完成商业模式理解后，必须使用 `investment-checklist` 分析公司是否符合巴菲特式买入前检查（完整输出）。
2. 完成商业模式理解后，必须使用 `quality-screen` 进行去劣筛选（完整输出）。
3. `investment-checklist` 和 `quality-screen` 的完整输出必须保存，不得只保留评分（完整输出）。
4. 若 `quality-screen` 出现未通过项，必须解释是否存在豁免逻辑；没有充分证据时不能强行豁免（完整输出）。
5. 若 `investment-checklist` 中“能力圈、好生意、护城河、管理层、价格、纪律”任一项明显不通过，投资委员会阶段必须重新讨论，不能直接进入 Buy 结论（完整输出）。

必须回答：

| 问题 | 分析方式 |
|---|---|
| 这家公司一句话怎么赚钱？ | 用大白话定义商业本质 |
| 谁付钱？为什么付钱？ | 客户、需求、替代方案 |
| 钱是否会重复？ | 复购、长期合同、客户粘性、切换成本 |
| 是否有定价权？ | 毛利率、价格传导、竞品压力 |
| 是否是好生意？ | ROE、FCF、资本开支、利润质量 |
| 是否可能是假护城河？ | 技术迭代、客户自研、低转换成本、周期错觉 |

核心问题：

> 如果不能用大白话讲清楚这家公司怎么赚钱，就还没真正懂。懂完以后，还要问：这是否真是一门值得长期持有的好生意？

### 第三阶段：Income Investment 分析

目标：判断公司是否具备可分配现金流、股东回报和收入型投资价值。  
优先使用：`income-investment`。  
输出目录：`04_盈利持续性分析/` 或 `11_投资报告/` 的收入投资附录。

强制要求：

1. 第三阶段必须使用 `income-investment`。
2. 即使公司股息率很低、没有股息，或更偏成长股，也必须说明其收入投资属性：`CORE INCOME`、`OPPORTUNISTIC INCOME`、`WATCHLIST`、`HOLD - DO NOT ADD`、`REDUCE`、`REJECT / YIELD TRAP` 或 `INSUFFICIENT DATA`。
3. 不得把高股息率等同于好机会，也不得把低股息率简单等同于差公司；必须分析 FCF、回购、分红、再投资、SBC 稀释和资本配置。
4. 如果税务居住地、账户类型、持仓数量、成本价未知，不得估算个性化税后收入；只能列 gross income 或标注不可计算原因。

必须覆盖：

| 模块 | 必须分析 |
|---|---|
| 分红历史 | 频率、金额、增长、削减、暂停 |
| 可分配现金 | FCF、FCF payout、回购、SBC、资本开支 |
| 资产负债表 | 债务、利息覆盖、再融资风险 |
| 收入稳定性 | 周期、客户集中、业务质量 |
| 三情景 | Base、Adverse、Severe，必须测试分红削减或回购收缩 |
| 收入型结论 | 是否适合作为收入资产，或只是成长/资本利得资产 |

核心问题：

> 这家公司能不能持续把现金分给股东？如果不能，它把现金再投资出去的回报是否足够好？

### 第四阶段：行业竞争分析

目标：判断公司所在行业是否变好，以及公司是否在价值链中占据好位置。  
优先使用：`industry-map`、`industry-research`、`industry-funnel`、`competitor-analysis`。  
输出目录：`05_行业竞争分析/`。

必须覆盖：价值链、TAM、行业增速、竞争对手、供应商议价权、客户议价权、替代技术、行业集中度、份额变化。

核心问题：

> 这家公司是在一个越来越好的行业里，还是在一个越来越难的行业里？行业变好之后，利润池由谁拿走？

### 第五阶段：管理层研究

目标：判断管理层是否有能力、有诚信、有资本配置能力。  
优先使用：`management-deep-dive`。  
输出目录：`06_管理层研究/`。

必须覆盖：CEO 背景、管理层履历、战略判断、并购整合、资本配置、股东友好程度、薪酬激励、内部人持股、重大决策、失败案例。

核心问题：

> 这家公司是不是由一群值得托付资本的人在经营？
> 这家公司对管理层的依赖程度高不高，其商业模式是否能支撑一帮平庸的管理层管理？

### 第六阶段：管理层承诺兑现分析

目标：不只听管理层说什么，还要看他们过去说到做到没有。  
输出目录：`07_管理层兑现分析/`。

必须建立：

| 年份/季度 | 管理层承诺 | 原始出处 | 目标 | 实际结果 | 是否兑现 | 评价 |
|---|---|---|---|---|---|---|

必须覆盖：

1. Promise Tracker
2. Guidance Accuracy
3. Capital Allocation Review
4. 并购承诺兑现
5. 回购、分红、债务管理是否符合股东利益

核心问题：

> 管理层是会讲故事，还是能兑现故事？

### 第七阶段：估值分析

目标：判断当前价格是否便宜，是否有安全边际。  
优先使用：`dcf-valuation`、`stock-valuation`、`company-valuation`。  
输出目录：`08_估值/`。

必须覆盖：

1. DCF 估值
2. 相对估值
3. SOTP 分部估值
4. Bear / Base / Bull 三情景
5. 反向 DCF
6. 安全边际测算
7. 当前价格隐含的增长预期
8. 股价下跌 30%-50% 时的加仓/否决条件
9. 根据历史波动PE估值

估值结论至少包含：

| 情景 | 核心假设 | 合理市值 | 合理股价 | 相对当前价格 |
|---|---|---|---|---|
| Bear Case | 保守假设 |  |  |  |
| Base Case | 中性假设 |  |  |  |
| Bull Case | 乐观假设 |  |  |  |

核心问题：

> 好公司不等于好股票，关键是价格有没有给安全边际。

### 第八阶段：投资委员会双轨分析

目标：形成可以决策的投资结论，但不得牺牲原始分析深度。  
优先使用：`investment-team`、`investment-research`。  
输出目录：`09_投资委员会/`。

强制要求：

1. 第八阶段必须同时使用 `investment-team` 和 `investment-research`。
2. 两个 skill 的完整输出必须分别保存：
   - `09_investment-team_完整输出.md`
   - `09_investment-research_完整输出.md`
3. 不接受压缩原始内容。
4. 允许在 `09_去重整合结论.md` 中去重，但去重只用于整合重复观点，不得删除原始报告。
5. 若两个 skill 结论冲突，必须列出冲突点、证据差异和需要进一步验证的数据源。
6. 投资委员会最终结论必须引用两个完整输出中的证据，而不是凭空重新写一份简版摘要。

投资委员会必须回答：

1. 买入理由是什么？
2. 最大风险是什么？
3. 当前价格是否合理？
4. 什么情况下可以买？
5. 什么情况下不能买？
6. 什么情况下必须卖？
7. 这家公司适合重仓、轻仓，还是观察？
8. 未来 3 年最关键的跟踪指标是什么？
9. 巴菲特会关心什么？
10. 段永平会追问什么？
11. 芒格式反过来想，失败路径是什么？
12. 李录式长期文明趋势是否成立？

最终评级：

| 评级 | 含义 |
|---|---|
| Buy | 当前价格有吸引力 |
| Hold | 公司不错，但价格一般 |
| Watchlist | 值得跟踪，等待价格或验证 |
| Avoid | 风险收益比不合适 |
| Sell | 逻辑破坏或估值严重透支 |

### 第九阶段：反方验证

目标：主动攻击自己的投资结论，避免确认偏误。  
优先使用：`bear-case`、`result-validator`。  
输出目录：`10_反方验证/`。

必须回答：

1. 我是不是被热门叙事吸引了？
2. 增长是不是已经被市场充分定价？
3. 竞争对手是否更强？
4. 技术路线是否可能变化？
5. 客户是否可能自研？
6. 行业周期是否接近高点？
7. 利润率是否不可持续？
8. 管理层是否过度乐观？
9. 估值假设是否太激进？
10. 如果股价跌 50%，原因最可能是什么？
11. 哪些证据会直接推翻我的投资 thesis？

核心问题：

> 如果这笔投资最后失败，最可能是我现在错在哪里？

### 第十阶段：最终完整投资报告

目标：形成正式、可阅读、可复盘、可决策的完整报告。  
优先使用：`investment-memo-craft`、`full-report`、`report-generator`、`chart-master`。  
输出目录：`11_投资报告/`。

强制要求：

1. 最终投资报告不允许压缩成一页纸。
2. 报告必须详细呈现分析思路、关键证据、推理链条、反方观点和估值逻辑。
3. “一页纸结论”可以作为开头摘要，但不能替代完整报告。
4. 每个核心判断必须说明：事实是什么、为什么重要、如何影响估值或投资结论。
5. 涉及专业名词时必须解释：
   - 概念是什么
   - 在这个行业中如何应用
   - 对公司收入、利润、护城河或估值有什么影响
6. 必须结合巴菲特和段永平思维：
   - 巴菲特：现金流、护城河、管理层诚信、安全边际、长期持有
   - 段永平：好生意、好人、好价格、差异化、消费者/客户价值、能力圈
7. 报告末尾必须区分“AI 分析置信度”和“真实投资确定性”。

报告结构建议：

1. 一页纸结论
2. 数据来源与数据质量评级
3. 公司概况
4. 商业模式
5. 专业名词解释
6. 财报精读
7. 财务质量
8. 盈利持续性
9. Income Investment 分析
10. 行业竞争
11. 管理层
12. 管理层兑现
13. 估值
14. 投资委员会双轨分析
15. 反方观点
16. 风险因素
17. 买入区间
18. 跟踪指标
19. 最终评级
20. AI 分析置信度 vs 投资确定性
21. 附录：完整 skill 输出索引

### 第十一阶段：持续跟踪

目标：研究不是一次性动作，而是建立长期跟踪系统。  
优先使用：`earnings-preview`、`earnings-review`、`earnings-recap`、`earnings-call-analysis`、`estimate-analysis`、`catalyst-calendar`、`news-pulse`、`thesis-tracker`、`thesis-drift`。  
输出目录：`12_持续跟踪/`。

重点跟踪：

| 类型 | 跟踪内容 |
|---|---|
| 财报 | 收入、利润率、FCF、指引 |
| 行业 | 需求变化、竞争格局、技术路线 |
| 管理层 | 承诺兑现、资本配置 |
| 估值 | 股价、预期、反向 DCF |
| 风险 | thesis 是否漂移 |
| 催化剂 | 新产品、客户、并购、监管、周期 |
| 数据审计 | 旧数据是否需要重算，来源是否失效 |

核心问题：

> 买入之后，不是结束，而是进入验证期。

## 六、每家公司最终标准输出

每家公司完成后，应该形成以下成果：


## 七、数据源与准出要求

### 可靠性优先级

| 优先级 | 数据源 |
|---|---|
| 1 | 公司年报、季报、10-K、10-Q、8-K、DEF14A、投资者日材料、业绩电话会原文 |
| 2 | SEC、交易所、监管披露平台 |
| 3 | 公司 IR 新闻稿 |
| 4 | Macrotrends、StockAnalysis、Yahoo Finance、Koyfin、TIKR 等第三方数据 |
| 5 | 新闻、博客、卖方研报摘要 |

### 强制准出

1. 所有报告必须写明研究日期与数据截止日。
2. 财务数据至少使用两个来源交叉验证；若差异超过 1%，必须解释。
3. 市值、估值、FCF、股本、每股数据不得心算，必须用工具或明确公式复核。
4. 原始披露缺失时，必须标注“数据不足”，不得用推测填满。
5. 所有 skill 完整输出必须保存，最终报告只做引用、整合和解释，不得删除原始输出。
6. 如果报告未完成全部 12 阶段，必须在索引中标注“未完成阶段”和“下一步补强”。
