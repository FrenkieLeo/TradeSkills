# 公司基本面分析 SOP

版本：v1.2
更新日期：2026-07-30
适用范围：`基本面分析/公司研究/` 下所有新建或重做的公司研究
优先原则：公司研究优先调用 ai-berkshire 系列 skills；只有当 ai-berkshire 没有覆盖某项能力时，才使用其他工具或通用分析补位。

## 一、目标：从报告生产升级为资本配置决策

本 SOP 用于把公司研究从“临时写一篇报告”升级成可复用、可追踪、可复盘的投资决策系统。每家公司最终必须回答六个问题：

1. 这家公司到底靠什么赚钱，价值由谁创造、又由谁拿走？
2. 它未来还能不能持续赚钱，增长需要投入多少增量资本？
3. 管理层是否诚信、有能力，并值得托付未来现金流的处置权？
4. 当前价格隐含了什么预期，是否提供足够安全边际和预期回报？
5. 如果判断错误，永久损失资本最可能通过什么路径发生？
6. 相对于现金、指数和现有最佳持仓，它是否值得占用资金、占用多少资金？

研究的最终产物不是单一的 Buy / Hold，而是四层结论：

| 结论层次 | 标准选项 |
|---|---|
| 公司质量 | 卓越 / 优秀 / 普通 / 较差 / 不可投资 |
| 当前估值 | 显著低估 / 低估 / 合理 / 偏贵 / 严重高估 / 无法可靠估值 |
| 投资行动 | Buy / Add / Hold / Trim / Sell / Watch / Avoid |
| 组合建议 | 目标仓位范围、首次建仓比例、加仓/暂停/减仓条件 |

没有持仓时不得使用 `Hold`；公司质量、价格吸引力和持仓动作不得混为一谈。

## 二、总原则

1. 先事实，后观点；先一手资料，后第三方解释。
2. 先能力圈，后研究；看不懂是合格结论，不得为了完成流程强行估值。
3. 先商业，后估值；先单位经济性，后宏大叙事。
4. 先现金流和每股价值，后利润与规模增长。
5. 先独立反方验证，再形成投资委员会最终意见。
6. 研究不是为了证明可以买，而是为了排除错误、比较机会并决定仓位。
7. 好公司不一定是好股票，便宜公司也不一定值得买。
8. 管理层不只看他说什么，更要看承诺兑现和历史资本配置结果。
9. 护城河不是标签，必须有机制、量化证据、变化趋势和推翻条件。
10. 增长只有在增量资本回报高于资金成本且提升每股价值时才有意义。
11. 所有公司都必须与明确的机会成本比较，不允许孤立地下 Buy 结论。
12. 买入后必须用初始预测和阈值持续检验 thesis，不以股价涨跌代替基本面判断。
13. 优先使用 ai-berkshire skills，并完整保留被调用 skill 的原始输出。
14. skill 数量不等于研究质量；原始 skill 输出是研究底稿，不是唯一事实来源。
15. 正式报告不得压缩成一页纸；一页纸摘要只能作为完整报告的入口。
16. 报告必须呈现事实、假设、推理、反方证据和结论之间的链条。
17. 专业名词必须解释概念、行业应用及其对收入、利润、护城河或估值的影响。
18. 分析必须结合巴菲特和段永平的投资思维：能力圈、好生意、好人、好价格、差异化、现金流、护城河、安全边际和长期持有。
19. 所有数据必须标注来源；来源冲突时优先采用公司公告、监管披露和年报/季报原文。
20. 不能获得可靠证据时必须标记“数据不足”或“无法判断”，不得用 AI 推测补齐。

## 三、研究架构与唯一事实源

### 3.1 标准目录结构

每家公司在 `基本面分析/公司研究/` 下按公司名称和股票代码创建独立文件夹：

```text
基本面分析/
└── 公司研究/
    └── Company_Name_Ticker/
        ├── 00_Research_Index.md
        ├── 00_决策门记录.md
        ├── 01_公司概况与能力圈/
        ├── 02_商业模式分析/
        ├── 03_事实底座与财务质量/
        │   ├── 03_Canonical_Fact_Table.md
        │   └── 03_会计风险与财务取证.md
        ├── 04_资本配置与盈利持续性/
        ├── 05_行业竞争分析/
        ├── 06_管理层研究/
        ├── 07_管理层兑现分析/
        ├── 08_估值与预期回报/
        ├── 09_独立反方验证/
        ├── 10_投资委员会/
        ├── 11_投资报告/
        ├── 12_持续跟踪/
        └── Raw_Skill_Outputs/
```

既有 v1.0/v1.1 研究目录无须强制迁移，但重做或更新时必须在 `00_Research_Index.md` 标明执行的 SOP 版本和未补齐项目。

### 3.2 唯一事实表

`03_Canonical_Fact_Table.md` 是公司研究的唯一标准事实源。所有正式报告和 skill 整合结论必须引用该表，不得各自维护冲突的股本、FCF、净债务或估值口径。

唯一事实表至少包含：

| 字段 | 强制内容 |
|---|---|
| 时间与币种 | 财年口径、报告期、数据截止日、报告币种、汇率口径 |
| 市场数据 | 股价、稀释股本、市值、企业价值及时间戳 |
| 三大报表 | 至少 5 年历史；条件允许时使用 10 年数据 |
| 每股数据 | 稀释 EPS、每股 FCF、每股净资产、净股本变化 |
| 经营指标 | 公司披露的行业 KPI、口径定义及历史变化 |
| 调整项 | SBC、并购、重组、减值、一次性项目、资本化费用 |
| 来源 | 原始链接、页码/章节、获取日期、第三方复核来源 |
| 质量标记 | 已核验 / 待核验 / 口径冲突 / 数据不足 |

任何关键数字发生变化时，先更新唯一事实表，再更新正式结论，并在版本记录中说明影响。

### 3.3 完整 skill 输出与正式文件分层

所有被调用 skill 的完整输出保存在 `Raw_Skill_Outputs/<阶段>/`，不得压缩、覆盖或用摘要替代。正式报告只做引用、交叉验证、去重和投资解释。

必须维护 `Raw_Skill_Outputs/README.md`，记录：

| Skill | 调用日期 | 输入资料截止日 | 输出文件 | 是否纳入正式结论 | 冲突/限制 |
|---|---|---|---|---|---|

AI 输出之间形成共识不等于证据增强；多个 skill 引用同一原始来源时只能视为一份证据。

## 四、Skill 使用矩阵

### 4.1 核心必用

| 研究任务 | 核心 skill | 使用要求 |
|---|---|---|
| 财务事实与交叉验证 | `financial-data`、`earnings-review` | 完整保存财报精读；回填唯一事实表 |
| 买入前质量检验 | `investment-checklist`、`quality-screen` | 必须完整输出；使用行业适配口径解释结果 |
| 管理层 | `management-deep-dive` | 必须研究诚信、激励、决策和资本配置 |
| 综合投资研究 | `investment-research`、`investment-team` | 双轨完整输出，只在整合结论中去重 |
| 反方与校验 | `bear-case`、`result-validator` | 必须先于最终投资委员会独立完成 |
| 正式报告 | `investment-memo-craft` | 用于决策写作与可读性，不得改变事实口径 |

### 4.2 条件触发

| Skill/方法 | 触发条件 |
|---|---|
| `income-investment` | 有稳定分红、回购、可分配现金流，或用户明确关注收入投资时；无分红高再投资公司可用资本配置分析替代，但必须解释未调用原因 |
| `industry-funnel` | 需要从行业内筛选或比较多个候选公司时 |
| SOTP | 多业务板块价值驱动和估值方法明显不同，合并估值会失真时 |
| 技术分析 | 仅用于交易执行和建仓节奏，不得决定公司内在价值 |
| 催化剂日历 | 投资结论依赖明确事件、监管或产品节点时 |
| 宏观/行业周期工具 | 公司现金流对利率、商品、库存或经济周期高度敏感时 |

条件触发 skill 未调用时，必须在索引写明“不适用”及理由，不得默认为遗漏。

### 4.3 行业专用模板

通用阈值只能作为提示，不得用“毛利率低于 40%”“重资产”“ROE 不足 20%”直接否决所有行业。

| 行业 | 必须补充的核心指标 |
|---|---|
| SaaS | ARR、NRR、GRR、CAC 回收期、Rule of 40、SBC、递延收入 |
| 银行 | NIM、CET1、不良率、拨备覆盖、存款成本、流动性 |
| 保险 | 综合成本率、浮存金成本、准备金质量、偿付能力 |
| REIT | FFO、AFFO、出租率、同店 NOI、租约期限、债务到期表 |
| 半导体 | 库存周期、ASP、良率、产能利用率、客户集中度、资本强度 |
| 消费品/零售 | 同店增长、量价拆分、周转率、渠道库存、复购、品牌溢价 |
| 平台/市场 | GMV、Take Rate、留存、网络密度、供需匹配、单位经济性 |
| 周期/资源 | 中周期价格与利润、成本曲线、产能纪律、资产重置价值 |

若公司属于其他特殊行业，必须先定义行业特有 KPI 和估值口径再继续。

## 五、五道强制决策门

所有决策门记录在 `00_决策门记录.md`。未通过时必须执行对应动作，不得只写风险提示后继续给出 Buy。

### Gate 1：能力圈与资料可得性

通过条件：

1. 能在 200 字内用大白话讲清公司如何赚钱。
2. 能列出决定未来 10 年现金流的 3—5 个关键变量。
3. 能解释产业链中谁掌握议价权、谁拿走主要利润。
4. 能获得足够的一手资料并识别关键数据缺口。
5. 能明确列出自己不知道什么，以及哪些问题继续研究也难以验证。

结论：`能力圈内 / 可通过研究进入 / 暂时看不懂 / 信息不足 / 不值得继续投入研究资源`。

`暂时看不懂` 或 `信息不足` 时停止目标价和 Buy 结论，只能列入待研究清单。

### Gate 2：公司质量

必须同时检查正常化 ROIC、增量 ROIC、现金转化、护城河及趋势、再投资跑道、资产负债表、会计质量和管理层诚信。

以下事项原则上直接否决：

- 有充分证据支持的财务造假或系统性误导；
- 管理层诚信存在重大疑点；
- 无法承受的债务或再融资风险；
- 商业模式依赖持续伤害客户、监管套利或不可验证承诺；
- 每股价值长期被稀释且没有可信改善路径。

### Gate 3：估值与回报

必须输出：

- Bear / Base / Bull 内在价值；
- 当前价格隐含的增长、利润率和资本回报要求；
- 3 年和 5 年预期年化回报；
- 永久损失风险和主要下行路径；
- 与现金、相关指数及现有最佳持仓的机会成本比较。

未达到组合要求的最低预期回报时，即使公司优秀也只能 `Watch` 或 `Hold`。

### Gate 4：独立反方

反方分析必须在读取主报告事实底座后、知悉最终评级前独立完成，并强制给出：

1. 三条最可能造成永久损失的路径；
2. 一条市场可能忽略但具有致命性的风险；
3. 最脆弱的核心假设；
4. 可直接否决 Buy 的证据；
5. 主报告最可能出现的确认偏误和口径问题。

未解决的重大反方证据必须降低评级、降低仓位或停止投资。

### Gate 5：组合与执行

最终必须明确：

- 是否持有及行动建议；
- 目标仓位范围和单一公司仓位上限；
- 首次建仓比例与分批节奏；
- 加仓、暂停加仓、减仓和清仓条件；
- 基本面破坏卖出与纯估值卖出的区别；
- 与现有持仓的行业、因子和业务相关性；
- 若暂不买入，进入可执行区间所需的价格或基本面条件。

不得用“小仓位”掩盖管理层诚信、看不懂或不可控债务等硬性否决项。

## 六、十二阶段执行流程

### 第零阶段：能力圈与研究立项

目标：在投入大量研究资源前完成 Gate 1。
输出：`01_公司概况与能力圈/01_能力圈与研究立项.md`。

必须回答：赚钱模式、关键价值变量、资料可得性、不可知事项、继续研究的理由和提前终止条件。

### 第一阶段：基础数据层、财报精读与唯一事实表

目标：建立统一事实底座，避免一开始就讲故事。
优先使用：`financial-data`、`yfinance-data`、`funda-data`、`fintel-data`、`earnings-review`。
输出：`03_事实底座与财务质量/`、`Raw_Skill_Outputs/01_财务/`。

强制要求：

1. 获取最新年报、季报、10-K、10-Q、8-K、电话会纪要和投资者材料后，必须使用 `earnings-review` 财报精读。
2. `earnings-review` 完整输出不得压缩，必须包含核心数据、管理层讨论、承诺追踪、附注、Q&A、论文影响和抽检记录。
3. 所有正式数据回填 `03_Canonical_Fact_Table.md`；原始 skill 输出不得替代唯一事实表。
4. 财务数据至少采用公司原始披露和一个独立来源交叉验证；差异超过 1% 必须解释。

### 第二阶段：商业模式、单位经济性与买入前质量检验

目标：搞懂公司卖什么、卖给谁、为什么值钱，以及价值最终由谁拿走。
优先使用：`stock-eval`、`fundamental-analysis`、`financial-report-analyst`、`10k-digest`、`investment-checklist`、`quality-screen`。
输出：`02_商业模式分析/`、`Raw_Skill_Outputs/02_商业质量/`。

必须建立“商业经济引擎表”：

| 项目 | 必须回答 |
|---|---|
| 收入公式 | 收入由客户数、价格、使用量、门店、交易额还是其他变量驱动？ |
| 增长拆解 | 增长来自价格、销量、份额、并购、汇率还是会计口径？ |
| 单位经济性 | 单个客户、门店、产品、项目或交易能贡献多少现金？ |
| 获客与留存 | CAC、回收期、留存、复购、合同期限和客户终身价值 |
| 规模效应 | 规模扩大后利润率和资本效率为什么提高或下降？ |
| 利润池 | 产业链中谁拿走主要利润，未来会不会迁移？ |
| 议价权 | 客户、供应商、渠道、平台和监管中谁掌握定价权？ |

`investment-checklist` 和 `quality-screen` 必须完整输出。通用阈值必须结合行业解释，未通过项只能凭证据豁免，不得因公司知名而豁免。

每条护城河必须包含：

| 维度 | 要求 |
|---|---|
| 机制 | 为什么竞争对手难以复制或绕开 |
| 量化证据 | 市占率、留存、价差、利润率、转换时间等 |
| 趋势 | 过去 5 年变宽、稳定还是变窄 |
| 推翻条件 | 什么证据说明护城河不存在或正在失效 |

### 第三阶段：财务质量、会计取证与每股价值桥接

目标：判断利润是否真实、可持续并最终属于每一股股东。
输出：`03_事实底座与财务质量/03_财务质量分析.md`、`03_会计风险与财务取证.md`。

必须检查：

- GAAP 与 Non-GAAP 差异；
- 收入确认政策和合同资产变化；
- 应收、存货与收入增速背离；
- 费用资本化和一次性项目常态化；
- 重组、减值、商誉、并购增长与有机增长；
- 经营租赁、养老金、担保和其他表外义务；
- 税率异常、关联交易、审计机构更换和内控缺陷；
- SBC、回购和稀释后股本的真实变化。

必须建立每股价值桥接：

> 净利润增长 → CFO/FCF 增长 → 净股本变化 → 每股 FCF 增长 → 每股内在价值增长。

公司总利润增长但每股价值未增长时，不得把规模增长直接视为股东价值创造。

### 第四阶段：资本配置、增量 ROIC 与股东回报

目标：判断公司保留一美元利润，未来能创造多少美元增量价值。
优先使用：`income-investment`（条件触发）。
输出：`04_资本配置与盈利持续性/`、`Raw_Skill_Outputs/04_资本配置/`。

必须覆盖：

1. 正常化 ROIC、增量 ROIC 和计算口径；
2. 再投资率、可持续再投资跑道；
3. 有机增长与并购增长拆分；
4. 每增加一美元收入需要多少增量资本；
5. 内部再投资、并购、还债、回购、分红之间的优先顺序；
6. 回购发生时的估值，以及回购是否只抵消 SBC；
7. 管理层历史上最好和最差的资本配置决策；
8. 多余现金、低效资产和财务工程。

长期内在价值增长的核心近似关系：

\[
\text{长期内在价值增长} \approx \text{再投资率} \times \text{增量资本回报率}
\]

若调用 `income-investment`，必须完整保存输出，并分析分红、可分配现金、资产负债表、三情景收入压力和收入型结论；无分红高再投资公司重点评价留存利润回报，不得机械追求股息。

完成本阶段后执行 Gate 2。

### 第五阶段：行业结构、竞争与长期利润池

目标：判断行业是否值得长期留在其中，以及公司是否占据可持续的价值位置。
优先使用：`industry-map`、`industry-research`、`industry-funnel`（条件触发）、`competitor-analysis`。
输出：`05_行业竞争分析/`。

必须覆盖价值链、TAM 口径、渗透率、行业增速、竞争对手、供应商和客户议价权、替代技术、行业集中度、份额变化、产能纪律、监管及利润池迁移。

TAM 不得直接等同于公司收入机会；必须解释可服务市场、可获得市场和盈利能力。

### 第六阶段：管理层与治理

目标：判断管理层是否有能力、有诚信，并能否理性配置资本。
优先使用：`management-deep-dive`。
输出：`06_管理层研究/`、`Raw_Skill_Outputs/06_管理层/`。

必须覆盖 CEO 与核心团队履历、战略判断、激励机制、内部人持股、关联交易、董事会治理、继任计划、并购整合、失败案例、危机处理和股东沟通。

诚信问题是硬性门槛，不能以低估值或小仓位补偿。

### 第七阶段：管理层承诺兑现与资本配置复盘

目标：把管理层语言转化为可验证记录。
输出：`07_管理层兑现分析/07_管理层兑现分析.md`。

必须建立：

| 年份/季度 | 管理层承诺 | 原始出处 | 目标与期限 | 实际结果 | 是否兑现 | 偏差原因 | 评价 |
|---|---|---|---|---|---|---|---|

必须覆盖 Promise Tracker、Guidance Accuracy、并购协同兑现、回购/分红/债务管理及资本配置结果。

### 第八阶段：估值方法适配、反向 DCF 与预期回报

目标：选择适合公司的估值方法，而不是机械地把所有模型都做一遍。
优先使用：`dcf-valuation`、`stock-valuation`、`company-valuation`。
输出：`08_估值与预期回报/`。

估值方法适配：

| 公司类型 | 主要方法 |
|---|---|
| 稳定成熟企业 | Owner Earnings DCF、FCF Yield |
| 高增长企业 | 反向 DCF、情景估值、单位经济性 |
| 多业务集团 | SOTP |
| 周期企业 | 中周期盈利、成本曲线、资产重置价值 |
| 银行 | P/B、可持续 ROE、剩余收益模型 |
| 保险 | P/B、浮存金价值、正常化承保利润 |
| REIT | NAV、AFFO 倍数 |
| 尚未盈利企业 | 概率加权情景；不得强行使用 PE |

至少输出：

| 情景 | 核心假设 | 内在价值/股 | 3 年 CAGR | 5 年 CAGR | 永久损失风险 |
|---|---|---:|---:|---:|---|
| Bear |  |  |  |  |  |
| Base |  |  |  |  |  |
| Bull |  |  |  |  |  |

预期年化回报必须拆解：

\[
\text{预期年化回报}
= \text{每股盈利或 FCF 增长}
+ \text{股息率}
+ \text{净回购收益率}
+ \text{估值变化}
\]

必须进行反向 DCF，说明当前价格要求公司实现何种收入增速、利润率、再投资效率和持续年限；不得只输出单一点目标价。

完成本阶段后执行 Gate 3。

### 第九阶段：独立反方验证

目标：在投资委员会形成最终意见前主动攻击论文。
优先使用：`bear-case`、`result-validator`。
输出：`09_独立反方验证/`、`Raw_Skill_Outputs/09_反方/`。

除 Gate 4 要求外，还必须测试：

- 热门叙事和估值是否互相循环论证；
- 周期高点是否被误判为结构增长；
- 客户自研、替代技术和利润池迁移；
- 利润率、终值、折现率和股本假设的脆弱性；
- 数据源冲突、遗漏负债和幸存者偏差；
- 股价下跌 50% 时最可能对应的基本面事实。

完成本阶段后执行 Gate 4。反方未完成前不得写最终评级。

### 第十阶段：投资委员会双轨分析与机会成本比较

目标：在完整事实和反方证据基础上形成可执行决策。
优先使用：`investment-team`、`investment-research`、`portfolio-review`（涉及真实组合时）。
输出：`10_投资委员会/`、`Raw_Skill_Outputs/10_投资委员会/`。

强制要求：

1. 必须同时使用 `investment-team` 和 `investment-research`。
2. 两个 skill 的完整输出分别保存，不接受压缩。
3. 正式整合文件只能去除重复表述，不得删除原始输出。
4. 结论冲突时必须列出冲突点、证据差异和需要验证的数据。
5. 必须与现金、相关指数以及用户现有最佳持仓比较。
6. 必须输出公司质量、当前估值、投资行动和组合建议四层结论。

投资委员会必须回答：

1. 买入理由、最大风险和最脆弱假设是什么？
2. 什么价格和基本面条件下可以买、加仓、暂停或卖出？
3. 3 年和 5 年预期回报是否补偿不确定性？
4. 永久损失概率和回撤承受能力如何？
5. 为什么它比当前机会成本更值得占用一美元？
6. 巴菲特、段永平、芒格和李录分别会追问什么？
7. 未来 3 年最关键的 3—5 个验证指标是什么？

完成本阶段后执行 Gate 5。

### 第十一阶段：最终完整投资报告、执行与持续跟踪

目标：形成正式、可阅读、可复盘、可执行并可持续验证的完整档案。
优先使用：`investment-memo-craft`、`full-report`、`report-generator`、`chart-master`、`thesis-tracker`、`thesis-drift`。
输出：`11_投资报告/`、`12_持续跟踪/`。

最终报告不得压缩成一页纸，至少包含：

1. 一页纸决策摘要；
2. 能力圈结论与未知事项；
3. 数据来源、唯一事实表和数据质量评级；
4. 商业模式、单位经济性和专业名词解释；
5. 财报精读、财务取证和每股价值桥接；
6. 护城河机制、证据、趋势和推翻条件；
7. 增量 ROIC、再投资跑道和资本配置；
8. 行业结构、竞争格局和长期利润池；
9. 管理层、治理与承诺兑现；
10. 估值方法选择、反向 DCF 和 3/5 年预期回报；
11. 独立反方观点及主报告回应；
12. 机会成本和组合相关性；
13. 公司质量、当前估值、投资行动、仓位建议四层结论；
14. 建仓、加仓、暂停、减仓、卖出和 thesis 失效条件；
15. AI 分析置信度与真实投资确定性；
16. 完整 skill 输出索引和所有未解决问题。

持续跟踪必须先建立初始“投资论文台账”：

| 核心判断 | 初始预测 | 时间范围 | 验证指标 | 触发阈值 | 实际结果 | 论文影响 |
|---|---|---|---|---|---|---|

后续事件只允许归类为：

- `论文强化`：基本面超过原始预期；
- `正常波动`：不影响长期现金流；
- `论文削弱`：关键指标偏离但尚可修复；
- `论文破坏`：核心假设或否决阈值被触发。

股价上涨不证明论文正确，股价下跌本身也不构成论文破坏。

## 七、仓位与行动规则

仓位建议必须说明依据，不得只写“重仓/轻仓”：

| 因素 | 仓位影响 |
|---|---|
| 商业确定性 | 越高，仓位上限越高 |
| 安全边际与预期回报 | 越高，允许仓位越高 |
| 永久损失风险 | 越高，仓位越低或否决 |
| 证据质量 | 数据不足必须折价 |
| 行业周期性 | 周期越强，仓位和建仓节奏越保守 |
| 管理层诚信 | 重大疑点直接否决 |
| 组合相关性 | 与现有持仓高度同质时降低新增仓位 |
| 流动性与波动 | 影响执行节奏，不改变内在价值 |
| 机会成本 | 不优于现有最佳机会时不新增资金 |

行动建议必须使用以下口径：

| 行动 | 适用情形 |
|---|---|
| Buy | 无持仓，质量通过、价格和回报通过、风险可承受 |
| Add | 已持仓，论文未破坏且新增价格仍满足回报门槛 |
| Hold | 已持仓，质量仍好但新增资金回报不足 |
| Trim | 估值严重透支、组合集中度过高或机会成本明显上升 |
| Sell | 论文破坏、诚信问题、永久损失风险显著上升或存在更优资本用途 |
| Watch | 公司值得跟踪，但价格、证据或能力圈尚未通过 |
| Avoid | 公司质量、诚信、财务风险或可理解性不满足要求 |

## 八、数据源、审计与准出要求

### 8.1 可靠性优先级

| 优先级 | 数据源 |
|---|---|
| 1 | 公司年报、季报、10-K、10-Q、8-K、DEF 14A、投资者日材料、电话会原文 |
| 2 | SEC、交易所、监管披露平台及法院/专利等原始文件 |
| 3 | 公司 IR 新闻稿、产品文档和官方价格资料 |
| 4 | 可信第三方数据库及行业协会 |
| 5 | 新闻、卖方研报、专家访谈 |
| 6 | 博客、社交媒体和未验证二手信息 |

低优先级来源只能提供线索，关键结论必须尽量回溯到一手证据。

### 8.2 强制准出

1. 所有报告必须写明研究日期、数据截止日、价格时间戳、币种和财年口径。
2. 关键财务数据至少使用两个来源交叉验证；差异超过 1% 必须解释。
3. 市值、企业价值、FCF、净债务、稀释股本和每股数据不得心算，必须保留公式或工具复核。
4. 估值模型必须列出公式、假设、敏感性和适用限制。
5. 每项核心判断必须区分 `事实 / 管理层口径 / 分析假设 / 投资判断`。
6. 数据缺失必须标记“数据不足”；不得重建未披露数据并当成事实。
7. 每个被调用 skill 的完整输出必须保存，正式报告只做引用和整合。
8. 所有五道 Gate 必须有明确结论、证据和责任动作。
9. 未完成全部阶段时，索引必须标注未完成项、影响和下一步。
10. 正式发布前必须执行引用检查、数字一致性检查、评级一致性检查和反方覆盖检查。
