# 公司基本面分析 SOP

版本：v1.0  
固定日期：2026-07-28  
适用范围：`基本面分析/公司研究/` 下所有公司研究

## 一、目标

本 SOP 用于把公司研究从“临时写一篇报告”升级成可复用、可追踪、可复盘的研究系统。每家公司最终必须回答四个问题：

1. 这家公司到底靠什么赚钱？
2. 它未来还能不能持续赚钱？
3. 管理层是否值得托付资本？
4. 当前价格是否提供足够安全边际？

最终结论必须明确落到：Buy / Hold / Watchlist / Avoid / Sell。

## 二、标准目录结构

每研究一家公司，在 `基本面分析/公司研究/` 下按公司名称和股票代码创建独立文件夹：

```text
基本面分析/
└── 公司研究/
    └── Company_Name_Ticker/
        ├── 00_Research_Index.md
        ├── 01_公司概况/
        ├── 02_商业模式分析/
        ├── 03_财务质量/
        ├── 04_盈利持续性分析/
        ├── 05_行业竞争分析/
        ├── 06_管理层研究/
        ├── 07_管理层兑现分析/
        ├── 08_估值/
        ├── 09_投资委员会/
        ├── 10_反方验证/
        ├── 11_投资报告/
        └── 12_持续跟踪/
```

`00_Research_Index.md` 是总入口，必须记录公司名称、股票代码、行业分类、研究日期、数据截止日、当前股价、市值、核心结论、文件索引和当前评级。

## 三、执行流程

### 第一阶段：基础数据层

目标：先建立事实底座，避免一开始就讲故事。  
优先使用：`financial-data`、`yfinance-data`、`funda-data`、`fintel-data`。  
输出：`03_财务质量/financial-analysis.md`。

必须覆盖：收入、毛利率、EBIT、净利润、经营现金流、自由现金流、ROIC、负债、SBC、股权稀释、CapEx、并购。

核心问题：过去赚到的钱是真钱、好钱，还是会计利润？

### 第二阶段：商业模式理解

目标：搞懂公司卖什么、卖给谁、凭什么赚钱。  
优先使用：`stock-eval`、`fundamental-analysis`、`financial-report-analyst`、`10k-digest`。  
输出：`02_商业模式分析/`。

必须回答：产品和服务、客户、购买原因、收入持续性、成本结构、定价权、价值链位置、增长驱动。

核心问题：如果不能用大白话讲清楚这家公司怎么赚钱，就还没真正懂。

### 第三阶段：盈利持续性分析

目标：判断增长、利润和现金流是不是可持续。  
输出：`04_盈利持续性分析/`。

| 模块 | 要回答的问题 |
|---|---|
| 收入持续性 | 增长是真需求、周期反弹、客户集中，还是一次性订单？ |
| 利润持续性 | 毛利率是否能守住？产品结构是否改善？竞争是否压价？ |
| 现金流持续性 | FCF 是否稳定？营运资本和 CapEx 是否吞噬现金？ |

建立 `Earnings Durability Score`：

| 项目 | 分数 |
|---|---|
| 收入可持续性 | 1-5 |
| 利润率可持续性 | 1-5 |
| 现金流可持续性 | 1-5 |
| 客户稳定性 | 1-5 |
| 竞争壁垒 | 1-5 |
| 周期风险控制 | 1-5 |
| 总分 | 30 分制 |

### 第四阶段：行业竞争分析

目标：判断公司所在行业是否变好，以及公司是否在价值链中占据好位置。  
优先使用：`industry-map`、`industry-research`、`industry-funnel`、`competitor-analysis`。  
输出：`05_行业竞争分析/`。

必须覆盖：价值链、TAM、行业增速、竞争对手、供应商议价权、客户议价权、替代技术、行业集中度、份额变化。

核心问题：这家公司是在一个越来越好的行业里，还是在一个越来越难的行业里？

### 第五阶段：管理层研究

目标：判断管理层是否有能力、诚信和资本配置能力。  
优先使用：`management-deep-dive`。  
输出：`06_管理层研究/`。

必须覆盖：CEO 背景、战略判断、并购整合、资本配置、股东友好、薪酬激励、内部人持股、重大成功与失败案例。

核心问题：这家公司是不是由值得托付资本的人经营？

### 第六阶段：管理层承诺兑现分析

目标：不只听管理层说什么，还要看他们过去说到做到没有。  
输出：`07_管理层兑现分析/`。

| 文件 | 内容 |
|---|---|
| `promise-tracker.md` | 管理层承诺、目标、实际结果、是否兑现 |
| `guidance-accuracy.md` | 过去季度指引 vs 实际结果 |
| `capital-allocation-score.md` | 并购、回购、分红、融资、SBC 是否创造股东价值 |

核心问题：管理层是会讲故事，还是能兑现故事？

### 第七阶段：估值分析

目标：判断当前价格是否有安全边际。  
优先使用：`dcf-valuation`、`stock-valuation`、`company-valuation`。  
输出：`08_估值/`。

必须包含：DCF、相对估值、SOTP、Bear/Base/Bull 三情景、反向 DCF、安全边际。

| 情景 | 核心假设 | 合理市值 | 合理股价 | 相对当前价格 |
|---|---|---:|---:|---:|
| Bear Case | 保守假设 |  |  |  |
| Base Case | 中性假设 |  |  |  |
| Bull Case | 乐观假设 |  |  |  |

核心问题：好公司不等于好股票，关键是价格有没有安全边际。

### 第八阶段：投资委员会

目标：把研究压缩成可以决策的投资结论。  
优先使用：`investment-team`、`investment-checklist`、`investment-research`。  
输出：`09_投资委员会/`。

必须回答：买入理由、最大风险、当前价格是否合理、可以买的条件、不能买的条件、必须卖的条件、仓位建议、未来三年跟踪指标。

### 第九阶段：反方验证

目标：主动攻击自己的投资结论，避免确认偏误。  
优先使用：`bear-case`、`result-validator`。  
输出：`10_反方验证/`。

必须问：我是不是被热门叙事吸引？增长是否已经被市场充分定价？竞争对手是否更强？技术路线是否可能变化？客户是否可能自研？行业周期是否接近高点？利润率是否不可持续？管理层是否过度乐观？估值假设是否太激进？如果股价跌 50%，最可能原因是什么？

### 第十阶段：最终投资报告

目标：形成正式、可阅读、可复盘的完整报告。  
优先使用：`investment-memo-craft`、`full-report`、`report-generator`、`chart-master`。  
输出：`11_投资报告/`。

报告结构：一页纸结论、公司概况、商业模式、财务质量、盈利持续性、行业竞争、管理层、管理层兑现、估值、投资 thesis、反方观点、风险因素、买入区间、跟踪指标、最终评级。

### 第十一阶段：持续跟踪

目标：买入后进入验证期，而不是研究结束。  
优先使用：`earnings-preview`、`earnings-review`、`earnings-recap`、`earnings-call-analysis`、`estimate-analysis`、`catalyst-calendar`、`news-pulse`、`thesis-tracker`、`thesis-drift`。  
输出：`12_持续跟踪/`。

必须跟踪：财报、指引、行业变化、竞争格局、管理层承诺、估值、风险、催化剂、thesis 漂移。

## 四、最终标准输出

每家公司完成后必须有一句话结论：

```text
结论：Company 是 Buy / Hold / Watchlist / Avoid。
核心原因：
1. xxx
2. xxx
3. xxx

买入区间：xxx
核心风险：xxx
未来最重要跟踪指标：xxx
```

## 五、核心原则

1. 先事实，后观点。
2. 先商业，后估值。
3. 先现金流，后故事。
4. 先反方验证，再下结论。
5. 研究不是为了证明可以买，而是为了判断是否值得买。
6. 好公司不一定是好股票，价格永远重要。
7. 管理层不只看他说什么，更要看他兑现了什么。
8. 买入后必须持续跟踪 thesis 是否漂移。
