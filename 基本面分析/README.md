# 基本面分析

本目录用于沉淀公司基本面研究的标准流程、技能编排、报告模板和持续跟踪机制。目标是把一次性的公司研究，升级为可复用、可审计、可复盘的投资研究工作流。

## 目录结构

- `研究方案.md`：完整研究流程、阶段产出和质量门槛。
- `skills配置.yaml`：按研究阶段编排的 skills 使用清单。
- `投资备忘录模板.md`：单家公司研究报告模板。
- `跟踪清单.md`：财报、催化剂、新闻、估值与 thesis drift 的持续跟踪框架。

## 使用方式

1. 先在 `研究方案.md` 中确认研究范围、公司清单、行业边界和投资问题。
2. 按 `skills配置.yaml` 选择对应阶段的 skills，优先完成数据交叉验证和商业模型拆解。
3. 用 `投资备忘录模板.md` 输出初版结论，再交给反方与校验模块挑战假设。
4. 研究完成后，把关键假设、催化剂和风险转入 `跟踪清单.md`，用于后续财报和新闻复盘。

## 研究原则

- 先事实，后观点：所有关键判断必须有来源、日期和可复查路径。
- 先业务，后估值：估值只服务于商业质量、增长确定性和风险收益比判断。
- 先反证，后定稿：每份结论都必须经过 bear case 和 result validation。
- 研究不是一次性报告，而是持续更新的投资论文。
