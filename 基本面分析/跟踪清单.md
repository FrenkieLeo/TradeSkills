# 基本面分析跟踪清单

## 1. 固定节奏

| 频率 | 跟踪内容 | 推荐 skills | 输出 |
| --- | --- | --- | --- |
| 每周 | 重大新闻、股价异动、估值变化、催化剂更新 | `news-pulse`、`catalyst-calendar`、`technical-analysis` | 周度跟踪摘要 |
| 每月 | 分析师预期、行业数据、竞争动态、宏观变量 | `estimate-analysis`、`industry-research`、`sector-analysis`、`economics-analysis` | 月度 thesis 检查 |
| 财报前 | 市场预期、关键指标、管理层可能关注点 | `earnings-preview`、`estimate-analysis` | 财报预览 |
| 财报后 | 实际结果、指引、earnings call、假设变化 | `earnings-review`、`earnings-recap`、`earnings-call-analysis` | 财报复盘 |
| 重大事件后 | 并购、监管、产品、竞争格局、资本配置变化 | `thesis-tracker`、`thesis-drift`、`bear-case` | 投资论文更新 |

## 2. 核心假设跟踪

| 假设 | 当前判断 | 领先指标 | 反证指标 | 最新状态 | 动作 |
| --- | --- | --- | --- | --- | --- |
| 收入增长可持续 |  | 订单、流量、客户数、价格 | 增速放缓、客户流失、降价 |  |  |
| 利润率有上行空间 |  | 毛利率、费用率、产能利用率 | 竞争加剧、投入刚性、成本上升 |  |  |
| 现金流质量良好 |  | FCF 转换率、应收账款、库存 | 利润与现金流背离 |  |  |
| 管理层资本配置理性 |  | 回购、分红、并购 ROI | 高价并购、稀释、激励错配 |  |  |
| 估值有安全边际 |  | 隐含增长、相对倍数、DCF 敏感性 | 价格透支 bull case |  |  |

## 3. 财报前检查

- 本季度市场一致预期是什么？
- 关键经营指标预期是什么？
- 管理层上次指引和本次可能变化是什么？
- 市场最关注的问题是什么？
- 哪些结果会强化投资论文？
- 哪些结果会削弱投资论文？
- 期权市场是否隐含大幅波动？
- 当前仓位是否适合财报风险？

## 4. 财报后复盘

- 收入、利润、EPS、FCF 是否高于或低于预期？
- 增长来自价格、销量、汇率、并购还是一次性因素？
- 毛利率和费用率变化是否符合原假设？
- 管理层指引是否改变中长期判断？
- earnings call 中是否出现新的风险、机会或措辞变化？
- 分析师预期是否上修或下修？
- 估值模型需要调整哪些变量？
- 投资论文状态：增强 / 不变 / 削弱 / 失效。

## 5. Thesis Drift 检查

每次更新后给投资论文打分：

| 项目 | 评分 1-5 | 说明 |
| --- | --- | --- |
| 数据仍支持核心假设 |  |  |
| 行业结构未恶化 |  |  |
| 竞争优势仍存在 |  |  |
| 管理层仍可信 |  |  |
| 估值仍有吸引力 |  |  |
| 风险收益比仍合理 |  |  |

评分规则：

- 5：明显增强。
- 4：小幅增强。
- 3：基本不变。
- 2：开始削弱，需要复查。
- 1：核心假设受损，需要重新评级。

## 6. 行动规则

- 核心假设评分连续两次低于 3：重新跑 `bear-case` 和 `result-validator`。
- 估值隐含预期进入 bull case：降低预期收益或重新评估仓位。
- 财报后指引改变长期增长或利润率：更新完整估值。
- 管理层资本配置明显偏离股东利益：下调治理评分。
- 行业竞争格局发生结构变化：重做行业与竞争分析。
